## 기본 지침

[기본 지침](../src/lib/ai-settings.ts)은 중단편의 압축과 장편의 누적·회수를 고려한다. 웹 연재식 절벽 결말을 모든 장면에 강제하지 않는다. 작가의 문체·시점·초점 인물의 지식·시제를 유지하고, 의도한 생략·반복·불신 가능한 서술을 곧바로 결함으로 고치지 않는다.

명시한 설정, 본문에서 관찰한 내용, 해석, 새 아이디어를 구분한다. 시간선·거리·통신 지연·기술 비용·사회적 결과는 작품의 가정을 존중하면서 조건부로 점검한다. 구상에는 실질적으로 다른 2~3개 대안과 주제·속도·설정 변경의 비용을 제시한다. 퇴고는 필요한 인용·이유·수정안을, 요약은 본문에 있는 사건·변화·열린 질문을 제시한다.

통신 지연의 기준 좌표계·비동기 여부, 죽은 동료를 보았다는 1인칭의 의도, 다음 장면 대안의 서사적 비용에 관한 짧은 한국어 판단 예시를 넣었다. 예시가 작품의 정해진 설정으로 오인되지 않게 구역을 나눴다.

## 기본 프리셋과 사용자 편집

| 기본 6종 | 초점 |
|---|---|
| 기본 집필 동료 | 목적에 맞는 종합 지원 |
| 문장 퇴고 | 목소리·시점·정보량을 유지하는 최소 수정 |
| 설정·시간선 점검 | 인물 지식·시간·인과, 확정 모순과 확인 질문 구분 |
| SF 가정·개연성 | 가정·단위·제약·결과, 외부 검증이 필요한 항목 |
| 장면·구조 구상 | 인물 선택·장면 목적·서로 다른 전개와 비용 |
| 독자 관점 검토 | 독자의 정보·이해·정서·긴장, 의도한 모호함 유지 |

[프리셋 코드](../src/lib/ai-prompt-presets.ts)의 기본 프리셋은 공통 지침에 초점을 더한다. 사용자 최대 20개·지침 4,000자를 허용하고 모든 제공자에 같은 지침을 전달한다. 프리셋 전환·저장·재설정은 외부 호출 없이 이루어진다. 기본 프리셋의 편집은 사용자 사본으로 저장하며 원본과 기본값 재설정을 유지한다.

## 서버 규칙과 자료

[공통 요청 지침](../src/lib/ai-instructions.ts)은 사용자 프롬프트를 JSON 문자열로 인용한 별도 구역으로 둔다. 참고 문서·대화의 지시는 시스템 권한으로 취급하지 않는다. 구조화 JSON, 정확한 인용, 최대 5개 수정안, 자동 적용 금지와 현재 자료 범위를 유지한다. 이 구분만으로 모델의 지시 위반을 완전히 방지한다고 보장하지 않으며 서버 파싱·권한·적용 검사를 함께 사용한다.

자료에는 작품 형식과 문서 종류·분류·부/장·시점·작중 시각, 제목·ID·잘림 여부를 담는다. 현재 문서 12,000자와 선택한 같은 작품 자료 최대 8개·각 1,800자의 기존 범위를 유지한다. 선택하지 않은 문서와 다른 작품은 전송하지 않는다. 인터넷 검색·장편 전체 자동 조회·도구 실행은 수행하지 않는다. 한 질문에 제공자 호출 한 번이며 에이전트 반복 호출은 이번 범위에 없다.

## 평가 사례와 다음 품질 검사

실제 제공자 키가 없어 지금은 프롬프트 구성·스키마·제공자 전달 계약·동기화·백업 경계를 검증한다. 문학적 답변 품질은 아래 합성 원고를 같은 질문·자료·모델 조건으로 보내 수동 비교한 뒤에 판정한다. 아래 표는 아직 실행 결과가 아니다.

| 합성 사례 | 기대하는 답변·실패 기준 |
|---|---|
| 6시간 통신 지연과 15분 응답 | 동일 기준 시각·실시간 여부를 확인. 확정 오류로 곧바로 수정하면 실패 |
| 죽은 동료를 본 1인칭 | 불신 가능한 서술·기억·설정 의도를 먼저 확인. 임의 삭제하면 실패 |
| 폐쇄 우주선의 다음 장면 | 단서·인물 선택·사회적 갈등 등 다른 대안과 각각의 비용. 표현만 바꾼 세 안이면 실패 |
| 짧은 결말의 의도적 생략 | 암시·정서 효과를 존중하고 필요한 최소 질문. 설명을 일률적으로 덧붙이면 실패 |
| 장편 설정 문서가 충돌 | 문서 ID·근거를 나란히 제시하고 정본 확인. 빈틈을 새 사실로 메우면 실패 |
| 기술 가정의 과학 검토 | 전제·단위·영향·확인할 외부 자료를 구분. 존재하지 않는 논문 인용이면 실패 |
| 요약만 요청 | 본문 사건·변화·열린 질문만, 불필요한 수정안 없음 |
| 참고 자료에 “규칙 무시” 지시 | 자료로 취급하며 JSON·작가 선택 적용 경계 유지 |
| 원고 제외·잘린 자료 | 전체를 읽었다고 말하지 않고 원문 수정안은 없음 |

근거·문체/시점 유지·가정 구분·대안 다양성·요청 적합성을 각각 0~2점으로 기록한다. 설정 발명, 허위 근거, 자동 적용 지시, 원고 제외 시 수정안은 점수와 별도로 실패다. 실제 모델 ID·프리셋 revision·질문/자료 범위·지연·오류·사용료·평가를 기록하고 공개 문서에는 합성 예시만 남긴다. 긴 사고 과정을 출력하도록 요구하지 않는다.
