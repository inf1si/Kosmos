# 노트·문서 공유 휴지통

기준: 2026-10-04. 노트·집필실 행의 `…` 또는 우클릭 메뉴에서 **휴지통으로 이동**을 누르면 확인창 없이 해당 항목을 계정 휴지통으로 옮긴다. 양쪽 사이드바의 **휴지통**은 같은 목록·개수를 표시한다. 제목·작품 검색, 항목별 **복원**과 **영구 삭제**, 전체 **비우기**를 제공한다. 자동 삭제·보관 기한은 없다.

## 이동·복원

본문·속성·노트 태그/보관함/작품 연결·첨부·AI 대화와 원래 위치를 함께 보관한다. 하위 노트/문서/폴더는 휴지통으로 같이 이동하지 않고 해당 항목의 기존 형제 위치로 올린다. 작품 사본과 공개 판본은 독립 자료로 유지한다. 마지막 개인 노트는 옮길 수 있고 작품의 마지막 문서는 비활성 메뉴로 보호한다. 빈 폴더/빈 대분류 정리 삭제는 기존 기능이며 휴지통 대상은 노트·문서다.

복원은 해당 항목 하나를 원래 부모·다음 형제 앞에 돌려놓는다. 부모가 없어지면 최상위, 다음 형제가 없으면 형제 맨 뒤에 둔다. 문서의 원래 대분류가 없어졌으면 40개 한도 내에서 다시 만들고 한도에 닿으면 문서 종류와 같은 대분류 또는 첫 대분류를 쓴다. 깊이 24단계를 넘으면 최상위 위치를 시도하며 여전히 유효하지 않으면 휴지통 항목을 유지하고 오류를 표시한다. 하위 항목 중 이전 부모/위치에 그대로 있는 항목만 다시 연결하므로 따로 이동한 항목과 다른 후속 편집은 보존한다.

작품이 없어졌거나 활성 문서·노트·계층·AI 보관 한도에 닿으면 복원을 거절하고 휴지통 항목을 유지한다. 노트의 사라진 작품 연결은 복원할 때 제거한다. 복원한 문서는 트리에서 다시 열 수 있으며 이전 열린 탭·분할 상태는 복원하지 않는다.

## 영구 삭제·비우기

질문 한 줄과 **복구 이력과 백업은 남습니다.**만 표시한다. 제목은 앞 40자까지 줄여 보여주고 목록에서는 전체 제목을 확인할 수 있다. 취소/Esc는 항목을 유지하고 누른 버튼으로 초점을 돌린다. 삭제 직전에 현재 브라우저에 **휴지통 영구 삭제 전** 복구 지점을 저장하고 저장 실패·준비 중 변경·충돌이면 삭제를 멈춘다. 비우기는 확인창을 열 때 있던 항목들에 적용한다.

선택 휴지통 사본과 더 이상 현재/남은 휴지통에서 사용하지 않는 첨부 목록을 제거한다. Blob/Storage 바이트·복구 이력·이미 만든 ZIP/Drive 백업·공개 판본은 지우지 않는다. 복구 이력 복원은 전체 작업 공간을 되돌리는 기존 동작이며 현재 브라우저·최근 50개 한도다.

## 저장·호환성

선택 필드 `Workspace.trash`를 기존 계정 JSON·IndexedDB·Supabase RPC/버전 충돌·Realtime·전체 ZIP·Drive ZIP·DB 백업에 포함한다. 최대 5,000개이고 기존 서버 JSON 20MB/계정 첨부 2,000개 한도를 공유한다. 이동 중 첨부 메타데이터를 유지하므로 기존 첨부 수집으로 실제 바이트도 백업한다. 읽기 사본은 `text/trash/<UUID>.md`다. MD/HTML/ENEX 작품 교환에는 휴지통을 넣지 않는다.

trash 필드 없는 이전 백업은 현재 휴지통과 참조 첨부를 보존하고 같은 ID를 활성 자료로 복원한 항목은 휴지통에서 제외한다. 명시된 배열은 빈 배열을 포함해 복원한다. 형식 버전은 1이다. [서버 보호 SQL](../supabase/migrations/20261004104045_workspace_trash_guard.sql)은 기존 배열을 누락한 구버전 탭을 거절하고 ID·사본·위치·첨부 연결을 검사한다. 구버전 탭의 미저장 글은 따로 보관하고 새로고침한다.
