# 전체 검색

2026-10-26. 집필실·노트 사이드바 **전체 검색**이나 `Ctrl/Cmd+K`로 연다. 홈·문서·분할 편집·노트에서 같은 창을 쓴다. 다른 관리 대화상자가 열려 있으면 그 대화상자의 조작을 유지한다. 노트의 기존 검색칸과 보관함/태그 필터는 노트 목록을 거르는 용도로 남긴다.

## 범위와 결과

기본 **전체**는 모든 작품의 원고·설정집·메모와 독립 노트를 함께 찾는다. **현재 작품**은 이름을 함께 표시하고, 특정 작품 또는 **노트**로 좁힐 수 있다. 제목·일반 본문·작품/섹션/상위 폴더 경로·설정 분류·노트 태그를 찾으며 공백으로 나눈 검색어는 모두 일치해야 한다. 검색어는 최대 500자다. 정규식은 실행하지 않고 대소문자를 구분하지 않는다. 조합형/완성형 한글은 NFC로 비교하되 이동 위치는 원문의 문자 위치를 유지한다.

제목 전체 일치 → 제목 구절 일치 → 제목 단어 일치 → 제목/본문 혼합 → 본문 → 경로/태그 순이며 같은 순위에서는 최근 수정 순이다. 결과에는 종류 아이콘·제목·작품/폴더 경로와 일치 본문 주변 두 줄을 보여준다. 본문 발췌는 첫 일치 구절 주변에서 만들고 일치 부분을 강조한다. 50개씩 표시하며 **더 보기**로 이어 본다. 표시 개수는 전체 일치 개수다.

↑·↓로 결과를 고르고 Enter 또는 클릭으로 연다. 한글 조합 확정 Enter는 선택하지 않는다. 검색한 본문 구절을 선택·강조하고 편집 영역 안에서 그 위치로 스크롤한다. 제목·경로만 일치하면 문서 앞부분을 연다. 다른 작품·노트로 이동할 수 있고 분할 편집에서 골라도 대상은 주 편집기로 연다. Esc로 취소하면 원래 조작에 초점을 돌린다. 열린 글의 검색 강조는 Esc·선택 이동·본문 수정·문서 내 찾기로 지운다. 기존 `Ctrl/Cmd+F·H`는 현재 편집 문서의 찾기/바꾸기로 유지한다.

휴지통·과거 이력·템플릿·AI 대화·각주 설명·첨부 내용/이미지 문자 인식은 대상이 아니다. 비공개 `@` 참조의 제목·ID도 본문으로 색인하지 않는다. 폴더 경로는 결과의 글을 찾는 데 쓰며, 폴더 자체를 여는 메뉴는 `@` 멘션에서 제공한다.

## 저장과 구현

검색은 이미 불러온 계정 작업 공간에서 브라우저 안에서 계산한다. 서버 검색 API·외부 제공자·AI 요청을 추가하지 않는다. 검색어·범위·결과·이동 강조는 실행 중 메모리에만 있고 URL·기기 설정·원고 JSON·동기화/이력·백업·발행본에 넣지 않는다. 검색·결과 이동은 원고와 실행 취소 이력을 바꾸지 않는다.

대상 경로는 [참조 대상 트리](internal-references.md)를 재사용한다. 본문은 서식이 이어진 글자를 같은 구간으로 읽고 문단·표 셀·각주/참조 원자 경계를 넘겨 붙이지 않는다. 원고를 열 때 현재 편집기 내용으로 위치를 다시 찾고 실제 ProseMirror 위치에 선택을 둔다. 강조는 기존 검색 표현과 편집기 플러그인 상태만 사용한다. 검색·선택만으로 문서 끝에 빈 문단을 넣지 않는다. 목록/표 등 뒤의 편집용 문단은 본문을 실제 수정할 때만 추가한다. 본문 편집·가져오기/내보내기·백업·DB 스키마 계약은 유지한다.

## 검증

[단위 검사](../tests/workspace-search.test.ts)는 전체/작품/노트 범위·순위·문자 그대로 검색·한글 위치·서식/표/체크리스트/이미지/원자의 실제 편집기 좌표·늦은 구절 발췌·이력 보존을 확인한다. [브라우저 검사](../tests/browser/workspace-search.mjs)는 합성 자료에서 실제 키보드/클릭, 작품↔노트 전환, 선택·스크롤·취소 초점·더 보기·Ctrl F·분할·원고 보존과 54개 테마/1280·360px를 확인한다. 운영 실행도 인증/저장 요청을 가로채 실제 계정에 쓰지 않는다. 실행 결과와 미검증 범위는 [검증 기록](../VERIFICATION.md)에 구분한다.
