# 소설 사이트 디자인 레퍼런스와 설계 수정 방향

확인일: 2026-10-01 · 공식 제품 화면 연구 기록

공개 화면의 현재 선택은 **문학 서재**다. SF 아카이브는 설정집 표현 후보로 남긴다. 현재 집필실 화면은 [로컬 구현 캡처](assets/novel-studio-preview.png), 구현 범위는 [상태 문서](status.md)에서 확인한다. 아래는 원래 디자인 연구와 목표 패턴이며 모든 기능이 현재 구현되어 있다는 뜻은 아니다. 참고 캡처는 문서의 `assets/`에 함께 보관했다.

Muvel, Novela, Pensiv의 공식 스크린샷·소개 페이지 데모와 기능 가이드를 확인했다. 계정을 생성하거나 로그인 후 개인 프로젝트를 조작한 결과는 아니다. 아래 이미지는 공식 화면을 브라우저에서 확인한 참고 캡처다. 서비스 버전과 사용자 설정에 따라 실제 화면은 달라질 수 있다.

## 1. 앞선 시안에서 수정할 점

앞선 시안은 원고 트리·본문·정보 패널만 표현해 집필 도구의 실제 작업량과 탐색 방식을 반영하지 못했다. 공개 사이트의 홈·작품 소개·작품 목록도 생략해 전체 사이트의 인상이 전달되지 않았다.

기능은 기존 데이터·공개 판본 설계를 유지하되, 화면은 다음 세 용도에 맞춰 구체화한다.

- 공개 사이트: 작가의 작품을 발견하고 읽는 웹사이트. 작품 이미지·소개·목차·세계관 입구를 중심으로 구성한다.
- 집필실: 문서가 많아도 탐색·편집·비교할 수 있는 웹 편집기. 문서 트리·탭·분할·도구·속성을 갖춘다.
- 설정집: 작품별 지식을 검색하고 연결하는 웹 문서 공간. 분류·속성·목차·관계·등장 위치를 갖춘다.

## 2. Muvel

공식 소개: https://muvel.app/info

워크스페이스: https://guide.muvel.app/workspace

위젯: https://guide.muvel.app/widgets

설정집: https://guide.muvel.app/wiki

[뮤블 공식 소개의 편집 화면 캡처](assets/muvel-reference.jpg)

### 실제로 확인한 구성

공식 소개 이미지에는 작은 세로 메뉴, 작품 정보, 에피소드와 분류된 위키 문서를 함께 탐색하는 트리, 문서 탭, 원고 도구 영역이 있다. 본문 안의 설정 관련 표현도 눈에 구분된다.

공식 워크스페이스 가이드는 원고·위키·캔버스·메모·검색·위젯을 독립 영역으로 여는 방법, 경계 드래그로 크기 조절, 레이아웃 저장과 프리셋을 설명한다. 위젯 가이드는 작은 도구를 원고 좌우와 바닥에 배치하는 방식을 설명한다.

### 이 사이트에 가져올 요소

- 원고와 설정을 하나의 작품 트리에서 탐색한다.
- 문서 전체를 여는 분할 패널과, 짧은 정보만 확인하는 위젯을 구별한다.
- 집필·퇴고·설정 비교의 작업 배치를 저장한다.
- 글자 수·검색·메모는 본문을 바꾸지 않고 주변에서 확인한다.

공식 기본 편집 이미지: https://novela.so/images/novela/ko/hero-editor@2x.avif

[노벨라 공식 분할 편집 화면 캡처](assets/novela-split-reference.jpg)

### 실제로 확인한 구성

좌측에 작품명·검색·등장인물·플롯·원고와 자료의 폴더 트리를 두고, 본문 상단에 경로와 편집 도구를 둔다. 분할 화면 예시는 두 원고를 같은 화면에서 비교한다. 전체 검색 소개에는 원고·인물·플롯의 결과와 분할 화면으로 여는 동작이 함께 표현되어 있다.

### 이 사이트에 가져올 요소

- UI는 작은 고딕체로, 읽는 본문은 별도의 글꼴·폭 설정으로 다룬다.
- 폴더, 문서 행, 선택 상태, 구분선의 간격을 정돈한다.
- 글꼴·크기·정렬·문단 등 편집 기능을 작은 도구 모음에 모은다.
- 참고 문서를 열 때 현재 원고와 커서 위치를 유지한다.

## 4. Pensiv

공식 소개와 화면 데모: https://pensiv.so/ko

[펜시브 공식 원고와 플롯보드 화면 데모 캡처](assets/pensiv-reference.jpg)

### 실제로 확인한 구성

공식 데모는 프로젝트 탐색, 여러 문서 탭, 원고와 플롯보드 분할 화면을 보여준다. 플롯 카드는 관련 원고·인물·태그와 연결된다. 별도의 소개에는 캔버스·백링크·그래프·작업 관리·AI 리뷰가 있다.

### 이 사이트에 가져올 요소

- 장면을 원고 트리, 플롯 카드, 설정 문서에서 같은 대상으로 연결한다.
- 장면 요약·시점 인물·작중 시간·관련 설정을 카드에서 확인한다.
- 설정 문서에서 이 설정을 참조한 원고로 돌아갈 수 있게 한다.
- AI 검토를 원고 옆에 두고, 근거 문서와 수정 제안을 따라갈 수 있게 한다.

## 5. 세 도구에서 공통으로 참고할 구조

| 층 | 화면 구성 | 설계에 반영할 동작 |
|---|---|---|
| 프로젝트 | 작품명, 검색, 문서 종류와 폴더 | 작품 전환, 제목·본문 검색, 필터 |
| 탐색 | 원고·인물·설정·자료 트리 | 접기, 새 문서, 순서 변경, 고정 |
| 작업 공간 | 문서 탭, 경로, 분할 패널 | 여러 문서 유지, 다른 패널에서 열기 |
| 편집 | 도구 모음, 원고, 문서별 표시 설정 | 실제 입력·서식·찾기 및 바꾸기 |
| 보조 | 문서 정보, 참고 자료, AI, 작은 도구 | 필요한 패널만 열고 작업 배치 유지 |
| 연결 | 문서 링크, 백링크, 플롯의 원고 관계 | 현재 쓰는 내용의 근거와 등장 위치로 이동 |

‘비슷한 편집기’라는 관찰은 구조를 가리킨다. 세 제품이 같은 구현이나 같은 기능 범위를 가졌다는 뜻은 아니다. 세 제품의 시각 요소·브랜드·아이콘을 그대로 복제하지 않고 작업 패턴을 참고한다.

## 6. 공개 사이트용 별도 레퍼런스

### Reactor — 작품 목록의 웹사이트 구성

https://reactormag.com/fictions/original-fiction/

[Reactor 작품 목록 캡처](assets/reactor-reference.jpg)

큰 타이틀, 작품 이미지, 제목과 작가 정보가 중심인 목록을 확인했다. 개인 사이트에서는 이 위계를 참고해 대표 작품과 단편·중편·장편을 보여준다. 잡지 전체 메뉴나 댓글·뉴스레터 운영까지 가져올 필요는 없다.

### Standard Ebooks — 작품을 한 권의 책으로 소개

https://standardebooks.org/ebooks/h-g-wells/the-time-machine

[Standard Ebooks 작품 소개 캡처](assets/standard-ebooks-reference.jpg)

작품 이미지와 제목을 크게 배치하고 소개·목차·온라인 읽기·파일 제공을 이어가는 작품 소개 페이지를 확인했다. 개인 사이트에서는 ‘작품 소개 → 읽기 → 목차 → 세계관’의 진입 구조를 참고한다.

### Gwern — 주석과 링크를 읽는 흐름 안에서 확인

https://gwern.net/sidenote

https://gwern.net/design

원문 사이트의 주석 설계 설명은 여백 주석, 주석 팝업, 모바일의 펼침 등 다양한 방법을 다룬다. 이 사이트에서는 짧은 설명의 미리보기, 각주 이동과 복귀, 설정 문서 미리보기를 참고한다. 기술 문서의 모든 보조 정보까지 소설 본문에 상시 표시하지 않는다.

## 7. 추천 조합

집필실의 기본 위계와 간격은 Novela, 자유로운 문서 비교와 보조 도구는 Muvel, 원고·플롯·설정의 연결은 Pensiv를 우선 참고한다.

공개 서재는 작품 이미지와 제목의 위계가 있는 웹사이트로 설계한다. 독서 페이지는 본문에 집중하고, 주석·설정은 필요할 때 펼친다. 설정집은 집필실의 탐색 체계를 공유하되 독자용 문서만 조회한다.

SF 특화는 우주 배경이나 장식 색상보다 시간선·인물의 지식·기술 제약·리서치 출처를 관리하는 기능에 먼저 반영한다.

## 8. 다음 시안의 화면 범위

1. 공개 홈: 대표 작품, 작품 목록, 작가 소개.
2. 작품 소개: 표지·소개·목차·독서 시작·설정집.
3. 집필실 기본: 세로 메뉴·문서 트리·문서 탭·편집 도구·상태 표시.
4. 집필실 분할: 원고 + 설정 또는 이전 원고, 크기 조절과 탭 유지.
5. 구성 화면: 장면 카드·플롯·작중 시간과 서술 순서.
6. 설정 관리: 분류·속성 표·문서 본문·백링크·공개 설명.
7. 독서: 실제 문단 길이와 주석·설정 미리보기.
8. AI 검토: 검토 범위·근거·수정 비교를 원고 옆에서 확인.

이 문서는 새 시안 제작의 기준이다. 앞선 축약 시안의 색상 변경만으로 디자인을 완성한 것으로 판단하지 않는다.
