# 검색 노출·링크 미리보기·방문 통계

기준: 2026-11-15. 공개 페이지가 검색 엔진과 링크 미리보기에 어떻게 보이는지와 방문 통계·작품 조회수의 범위를 적는다.

## 페이지 제목과 소개

| 화면 | 제목 | 소개 |
|---|---|---|
| 홈 `/` | Orbis Tertius | 고정 문장 |
| 서재 `/library` | 서재 · Orbis Tertius | 공개한 필명과 작품 제목 목록 |
| 독서 화면 `/read/[작품]` | 작품 제목 · Orbis Tertius | 작품 소개 → 부제 → 본문 첫 문단 순으로 처음 있는 것 |
| 설정집 `/wiki/[작품]` | 작품 제목 설정집 · Orbis Tertius | 공개 설정 제목 목록 |
| 자기소개 `/about` | Who I Am · Orbis Tertius | 공개한 소개 글의 앞부분 |
| 데이터 이용 안내 `/privacy` | 개인정보 및 데이터 이용 안내 · Orbis Tertius | 고정 문장 |

소개는 한 줄 150자까지이고 넘치면 말줄임표로 끝난다. 작품 소개는 집필실 작품 정보의 **작품 소개**이며 다시 게시한 판본부터 반영된다. 각 화면은 자기 주소를 대표 주소(canonical)로 알리고, 설정집의 `?doc=` 주소는 설정집 주소 하나로 모은다.

게시하지 않은 작품 주소와 공개 설정이 없는 설정집, 집필실은 검색 제외(noindex)로 표시한다.

## 링크 미리보기

카카오톡·SNS에 주소를 붙이면 제목·소개·그림이 나온다. 독서 화면의 그림은 작품 제목·부제·필명을 서재 글자 표지와 같은 색(`#5f4b8b` 바탕)에 올린 1200×630 PNG이고, 다른 화면은 사이트 이름을 올린 같은 그림이다. 미리보기에는 독자가 고른 테마가 없으므로 기본 보라 표지 색으로 고정한다. 글꼴은 마루 부리(`@kfonts/maruburi`)다.

미리보기를 가져가는 서비스는 대부분 `<head>`만 읽으므로 제목·소개 태그는 항상 `<head>`에 넣는다([`next.config.ts`](../next.config.ts)의 `htmlLimitedBots`).

## sitemap과 robots

- `/sitemap.xml`: 홈·서재·자기소개와 공개 중인 작품의 독서 화면, 공개 설정이 있는 설정집. 게시일을 수정일로 적는다. 요청할 때마다 공개 판본을 읽는다.
- `/robots.txt`: 전체 허용, `/api/`·`/auth/` 제외, sitemap 주소 안내. 집필실은 noindex 표시를 읽을 수 있게 막지 않는다.
- 운영 배포가 아닌 곳(Vercel Preview·로컬)은 robots에서 전체를 막고 모든 화면을 noindex로 표시한다.

검색 엔진에 알리는 주소는 `NEXT_PUBLIC_SITE_URL`이 있으면 그 값, 없으면 Vercel의 운영 도메인이다. 사용자 도메인을 연결하면 Vercel이 그 도메인을 운영 도메인으로 알려 주므로 따로 설정하지 않아도 된다.

Google Search Console·네이버 서치어드바이저에 사이트를 등록하고 sitemap 주소를 제출하는 일은 운영자가 직접 한다([배포 안내](setup-deployment.md#검색-등록과-방문-통계)). 등록하지 않아도 검색 엔진이 찾아올 수 있지만 시기를 알 수 없다.

## 방문 통계

Vercel Web Analytics(`@vercel/analytics`)가 공개 화면의 방문을 센다. Vercel 대시보드의 프로젝트 **Analytics**에서 켜야 수집을 시작하며 통계도 그곳에서 본다.

- 세는 화면: 홈·서재·독서 화면·설정집·자기소개·데이터 이용 안내.
- 세지 않는 것: 집필실·로그인 화면, 집필실에 로그인해 둔 브라우저의 모든 방문(작가 본인의 열람 제외).
- 쿠키를 쓰지 않는다. 수집 항목과 방문자 구분 방식은 [데이터 이용 안내](../src/app/privacy/page.tsx)의 **방문 통계**에 적었다.
- 2026-11-15 확인한 [Vercel 요금 안내](https://vercel.com/docs/analytics/limits-and-pricing): Hobby는 월 50,000건까지 무료이고 넘으면 수집이 멈춘다. 통계는 최근 1개월만 보인다.

로컬 개발 실행에서는 통계를 보내지 않는다.

## 작품 조회수

독자가 독서 화면을 연 횟수를 작품별·날짜별로 직접 센다. 방문 통계와 별개이며 Vercel 대시보드를 켜지 않아도 동작한다. 운영 DB에 [`20261115143500_work_views.sql`](../supabase/migrations/20261115143500_work_views.sql)을 적용해야 세기 시작한다([배포 안내](setup-deployment.md#작품-조회수-배포-2026-11-15)).

보는 곳(작가만):

- 집필실 홈의 게시 중인 작품 카드 둘째 줄: `게시 중 · 조회 1,234`.
- 작품 정보 창의 공개 상태 줄: `공개 서재에 게시 중 · 날짜 판본 · 조회 1,234 · 최근 7일 56`.

공개 서재와 독서 화면에는 조회수를 보이지 않는다. 마이그레이션을 적용하지 않은 서버나 합계를 읽지 못한 때에는 조회 표시만 빠지고 나머지는 그대로다. 합계는 집필실을 열 때 읽고 1분 안에는 다시 읽지 않는다.

세는 기준:

| 경우 | 셈 |
|---|---|
| 게시 중인 작품의 독서 화면을 처음 연 브라우저 | 그날 1회 |
| 같은 브라우저가 같은 날 새로고침·다시 방문 | 세지 않음 |
| 다음 날(한국 시간) 다시 방문 | 1회 |
| 다른 브라우저·기기, 사생활 보호 창 | 각각 1회 |
| 집필실에 로그인해 둔 브라우저 | 세지 않음 |
| 배경 탭으로 연 화면 | 탭을 실제로 볼 때 1회 |
| 검색 로봇·링크 미리보기 수집기·자동화 브라우저, 다른 사이트에서 보낸 요청 | 세지 않음 |
| 설정집·서재, 게시하지 않았거나 철회한 작품 주소 | 세지 않음 |

서버에는 작품·날짜·횟수만 남고 방문자를 구분하는 값은 저장하지 않는다. 같은 날 다시 세지 않는 표시는 독자 브라우저의 `kosmos-viewed:작품` 항목 하나(날짜)뿐이다. 그래서 숫자는 방문자 수가 아니라 "브라우저별 하루 한 번"의 합이며, 사이트 데이터를 지우거나 브라우저를 바꾸면 다시 센다. 작가만 보는 숫자여서 일부러 부풀리는 요청을 막는 장치는 두지 않았다.

게시를 철회해도 그동안의 조회수는 남고 다시 게시하면 이어서 센다. 조회수는 원고 백업에 들어가지 않는다([백업 범위](backup-restore.md#작품-조회수)).
