# 서재 순서와 정렬

## 작가가 기본 순서 정하기

집필실 **홈 → 서재 순서 편집**에서 현재 게시된 작품만 불러온다. 초안의 제목을 바꿨다면 다시 게시하기 전까지 이 목록은 공개 판본의 제목을 사용한다.

1. **자동 정렬 기준**에서 제목 오름차순·제목 내림차순·최신 게시순·오래된 게시순을 고른다.
2. **자동 정렬**로 편집 목록에 적용한다. 이 단계에서는 공개 서재를 바꾸지 않는다.
3. 작품 왼쪽 손잡이를 끌어 원하는 작품 앞·뒤에 놓는다. 마우스와 터치 모두 지원하고 위·아래 버튼도 사용할 수 있다.
4. **서재 순서 저장**으로 독자의 기본 **작가 지정순**을 바꾼다.

**저장된 순서로**는 마지막으로 불러오거나 저장한 순서로 되돌린다. 저장 전 창을 닫으면 편집한 순서는 버린다. 작품이 없거나 하나이면 자동 정렬·이동을 할 수 없다. 원고·장면 순서·공개 판본 ID·게시일은 순서 저장으로 바뀌지 않는다.

드래그 중 놓을 위치를 선으로 표시한다. 긴 목록은 위·아래 가장자리에 포인터를 두면 자동으로 스크롤한다. 손잡이를 클릭만 하면 순서는 바뀌지 않는다. **Esc**는 진행 중인 드래그를 취소하고 창은 유지한다. 목록 밖에 놓거나 터치가 취소되면 이동하지 않는다. 손잡이에 키보드 초점을 두고 **↑·↓**로 한 칸씩 이동할 수도 있다. 드래그는 편집 목록만 바꾸며 **서재 순서 저장**을 눌러야 공개 서재에 반영된다. 저장 중·충돌·읽기 전용 상태에서는 이동할 수 없다. [브라우저 검사](../tests/browser/library-order-drag.mjs).

제목은 한국어 비교와 숫자 비교를 사용한다(제목 2가 제목 10보다 앞선다). 최신/오래된 기준은 원고 수정일이 아닌 공개 판본의 게시일이다. 제목·게시일이 같으면 저장된 작가 순서를 따른다.

## 독자의 정렬

공개 **서재 → 정렬**에서 작가 지정순·제목 오름차순·제목 내림차순·최신 게시순·오래된 게시순을 고른다. 처음에는 작가 지정순으로 보인다. 독자의 선택은 `kosmos-library-sort`로 그 브라우저에만 기억하고 작가의 순서나 원고를 바꾸지 않는다. 잘못된 저장값은 작가 지정순으로 돌아간다.

## 게시·철회·동시 편집

- 새 작품의 첫 게시에는 맨 뒤 자리를 부여한다. 같은 작품의 재게시에는 기존 자리를 유지한다.
- 게시 철회한 작품은 숨기지만 자리를 보관한다. 다시 게시하면 그 자리로 돌아온다.
- 편집창을 연 뒤 다른 탭/기기에서 게시하거나 철회해 목록·판본이 바뀌면 저장을 거절한다. 안내대로 창을 다시 열어 최신 목록으로 편집한다.
- 같은 판본 목록의 순서만 동시에 바꾼 경우에는 마지막으로 성공한 저장을 따른다. 순서 변경 이력·자동 병합은 없다.

초기 데이터베이스 적용은 기존의 최신 게시순을 유지해 기본 순위를 만든다. 작가 한 명의 활성 작품 최대 100개를 정렬하며, 로그인한 허용 작가만 자신의 목록을 저장할 수 있다.

## 저장·백업 범위

운영 순서는 공개 테이블의 `library_position`에 작품 기준으로 저장한다. 작가 조회·저장은 원고 본문을 받지 않는 별도 RPC를 사용한다. 전체 작업 공간 ZIP/Drive 백업을 복원해도 운영의 공개 순서는 바뀌지 않는다. 다시 게시해도 유지한다. 데이터베이스 재해 복구 백업에는 이 열이 포함된다.

기기 미리보기는 판본 사본의 선택 필드 `libraryPosition`을 사용하므로 전체 작업 공간 백업에 포함되고 복원된다. 기존 버전 1 백업도 계속 읽는다. 클라우드 작업본의 판본 사본에 이 값이 있더라도 운영 공개 순서의 기준은 데이터베이스 열이다. [데이터 모델](data-model.md#서재-순서-메타데이터)·[복구 범위](backup-restore.md#서재-순서-백업).
