# 문서 그래프

집필실 사이드바의 **문서 그래프**를 누르면 현재 작품의 원고·설정집·메모 관계가 별도 탭으로 열린다. 작가 전용 보기이며 공개 독서 화면에 초안 관계를 내보내지 않는다.

## 보는 방법

- **전체:** 현재 작품의 모든 문서를 지도에서 본다. 각 문서는 사이드바 트리와 같은 아이콘(원고, 메모, 설정 분류별 인물·기술·장소 등)과 제목의 칩으로 보이고, 원고에는 상태 점이 붙는다. 칩과 글자 크기는 확대해도 그대로이고 문서 사이 간격만 넓어진다. 문서가 50개를 넘거나 화면이 좁으면 축소 상태에서 선택한 문서 외에는 아이콘만 보인다.
- **주변 연결:** 중심 문서에서 1~3단계로 이어진 문서만 본다. 중심 문서는 드롭다운에서 바꿀 수 있다.
- 노드를 한 번 누르면 문서 정보와 연결 목록이 나타난다. 두 번 누르거나 **문서 열기**를 누르면 원본 문서 탭으로 이동한다. 기존 뒤로·앞으로와 탭 닫기도 사용할 수 있다.
- 문서 칩을 끌어 위치를 옮기고, 빈 지도 부분을 끌어 화면을 이동한다. 휠 또는 확대·축소 버튼으로 크기를 바꾼다. **전체 맞춤**은 드래그한 배치를 초기화하고 지도를 다시 맞춘다.
- 키보드로 노드를 선택한 뒤 Enter/Space로 정보를 보고 Ctrl/Cmd+Enter로 문서를 연다. 지도에 초점을 두고 방향키로 이동, `+`/`-`로 확대·축소, Home으로 맞춤을 실행한다. **표시된 문서 목록**에서도 선택할 수 있다.
- **문서 제목 검색**은 그래프 안에서만 제목을 검색한다. 사이드바의 본문 검색과 별개다. 위쪽 **필터** 버튼을 누르면 옆에 작은 창이 열리고 원고·설정집·메모, 설정 분류, 시점 연결, 연결 없는 문서 표시를 조절한다. 필터가 적용 중이면 버튼에 점이 보인다.

## 선의 의미

| 표시 | 근거 | 만드는 방법 |
|---|---|---|
| 실선 | 본문에 저장한 `wikiLink`의 문서 ID | 단어를 선택하고 편집기 **설정 링크 추가 → 문서 선택 → 연결** |
| 점선 | 원고의 시점 인물과 설정집의 인물 문서 | 원고 **속성 → 시점 인물**에 인물 제목을 선택·입력 |

시점 관계는 앞뒤 공백을 제거한 제목이 정확히 일치하고, 분류가 ‘인물’인 설정 문서가 하나일 때만 만든다. 같은 제목의 인물이 여럿이면 점선을 만들지 않는다. 시점 인물이 비어 있으면 제목 없는 인물 문서와도 잇지 않는다. 본문의 단어가 우연히 같거나 AI가 관계를 추측한 경우에는 연결하지 않는다. 현재 편집기의 링크 선택 대상은 같은 작품의 설정집이다. 임의의 원고끼리 새 링크를 만드는 도구는 이 기능에 포함되지 않는다.

같은 두 문서 사이에 본문 링크와 시점 관계가 모두 있으면 지도에는 실선 하나만 그린다. 선의 뜻은 지도 오른쪽 아래 범례에 있다. 선은 양방향으로 탐색하되 문서 정보의 **이 문서에서 연결 / 이 문서를 참조**로 본문 링크의 방향을 구분한다. 같은 문서 쌍에 본문 링크와 시점 관계가 모두 있으면 두 관계를 별도로 센다. 지운 문서·다른 작품·자기 자신을 향한 본문 링크는 지도에서 제외한다.

필터를 먼저 적용한 뒤 주변 연결을 찾는다. 주변 보기의 중심 문서는 제목 검색에서 유지되지만 문서 종류·설정 분류 필터로는 제외될 수 있다. 필터로 가려진 연결은 범위를 이어주는 중간 문서로 사용하지 않는다. 정보 패널의 연결 목록은 현재 필터와 관계없이 실제 연결을 보여준다(시점 연결 제외는 반영). 연결 목록에서 문서를 고르면 필터를 초기화하고, 표시 범위 밖이면 해당 문서의 주변 보기로 이동한다.

## 저장과 큰 작품

그래프는 기존 문서에서 계산하는 보기다. 링크·시점 인물 값은 원고와 함께 기존 기기/클라우드 저장 및 전체 ZIP 백업에 보존된다. 지도 위치·확대율·필터는 그래프를 닫거나 작품을 바꾸면 초기화되며 별도 백업 대상이 아니다. DB 스키마·의존성·AI 서비스 호출은 추가하지 않는다.

한 화면에서 최대 **200개 문서와 800개 연결**을 표시한다. 제한에 도달하면 안내 문구를 표시하며 중심 문서를 우선 유지하고 연결이 많은 문서를 먼저 고른다. 제목 검색·주변 연결·종류 필터로 작은 범위에서 살펴볼 수 있다. 제한은 원고나 실제 링크를 삭제하지 않는다. 문서가 50개보다 많거나 지도 폭이 520px보다 좁으면 100% 미만에서 선택 문서의 제목만 표시하고, 확대하면 다른 제목도 나타난다. 문서·연결 개수는 관계 수 기준이라 한 줄로 합친 선도 따로 센다.
