# 편집기 우클릭

집필실 원고·설정집·메모·분할 창과 노트에서 같은 메뉴를 쓴다. 읽기 전용에서는 브라우저 메뉴를 유지한다.

| 누른 곳 | 메뉴 | 적용 대상 |
|---|---|---|
| 드래그로 선택한 글 안 | 기존 요약·문장 다듬기·아이디어 확장·질문하기·내 스킬·복사·잘라내기·붙여넣기 | 선택 범위 그대로 |
| 선택하지 않은 본문 | 문단 스타일, 삽입, 붙여넣기 | 우클릭한 문단·커서 |
| 표 셀 | 행·열 추가/삭제, 셀 병합/나누기, 첫 행의 제목 행 전환, 표 삭제 | 누른 셀, 이미 선택한 여러 셀 안이면 그 선택 |
| 각주 표시 | 각주 수정, 각주 삭제 | 해당 각주 하나 |
| 비공개 참조 칩 | 미리보기, 참조 제거 | 해당 참조 하나; 원문은 보존 |

**문단 스타일**은 일반 문단·제목 1~3·글머리/번호 목록·인용이다. 노트에는 체크리스트도 있다. **삽입**은 3×3 표·구분선·각주·설정/노트 링크이며 노트에는 이미지가 추가된다. 각주·링크·이미지는 기존 입력 창/파일 선택기를 연다. 붙여넣기는 현재 문단 전체를 바꾸지 않고 누른 커서에 일반 텍스트로 넣는다. 여러 줄은 문단으로 나누고 HTML은 실행하지 않는다.

문단/삽입 목록의 **뒤로**는 첫 메뉴로 돌아간다. 방향키·Home/End로 활성 항목을 이동하고 Enter로 실행한다. Esc는 편집기로 돌아가며 바깥 클릭은 누른 곳의 초점을 유지한다. 선택 없는 우클릭에서 Shift를 함께 누르면 브라우저 기본 메뉴를 사용한다. 실제 OS/브라우저가 제공하는 메뉴 구성은 환경마다 다르다.

표 메뉴는 불가능한 동작을 비활성화한다. 여러 셀을 먼저 드래그하면 병합할 수 있으며, 병합한 셀에서는 나누기를 쓴다. 각주 수정은 [기존 각주 카드](editor-tools.md#각주-미리보기)를 바로 편집 상태로 연다. 참조 미리보기는 기존 연결 패널을 사용한다.

메뉴를 열 때 문서와 선택 위치를 보관하고, 적용 전에 본문이 같은지 확인한다. 메뉴를 열었다 닫는 것만으로 원고를 바꾸지 않는다. 편집은 해당 문서의 기존 저장·동기화·실행 취소를 따른다. 각주/표/문단은 본문 데이터이며 공개 판본 갱신은 다시 게시해야 한다. 비공개 참조는 계속 공개본에서 제외한다. DB·전체 백업·내보내기 형식은 바꾸지 않는다.

공개 Supabase 설정이 있는 테스트 서버에서 검사한다(로컬은 합성 anon key 사용 가능). 인증·REST·API 요청을 가로채므로 실제 계정이나 저장소를 쓰지 않는다.

검사: [합성 브라우저 시나리오](../tests/browser/editor-position-menu.mjs). `KOSMOS_TEST_BASE_URL`, `KOSMOS_PLAYWRIGHT_MODULE`, `KOSMOS_CHROMIUM_PATH`, `KOSMOS_BROWSER_ENGINE`, `KOSMOS_BROWSER_OUTPUT`을 기존 편집기 검사와 같이 사용한다. `KOSMOS_CONTEXT_QUICK=1`은 첫 색 계열만 확인하므로 54조합 검사로 기록하지 않는다. [검증 기록](../VERIFICATION.md).
