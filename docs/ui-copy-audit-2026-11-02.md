# 화면 문구 점검과 AI 제한 제거

기준 main `5c182fc`. `src/components`·`src/app`의 TSX 64개와 간접 전달하는 팝오버 설명·툴팁·설정 hint·CSS content를 조사했다. 사용자 원고·개인 소개·템플릿 본문은 고치지 않았다. 소스 조사 범위와 실제 브라우저 조작 범위는 구분한다.

## 제거·축약한 문구

| 영역 | 변경 |
|---|---|
| AI 대화·커서 질문 | 질문 2,000자·하루 10회·대화 20회 카운터와 Enter/Shift+Enter 상시 조작 안내 제거 |
| AI 자료·설정·스킬 | 원고·참고 자료 제한 설명, 프리셋/스킬 제한 카운터, 긴 스킬 예시 placeholder, 키 보관·백업 상시 설명 제거 |
| 앱 설정 | 각 행의 반복되는 기본값 설명 제거. 현재 선택과 기본값으로 버튼 유지 |
| 편집 도구 | 글꼴·크기의 기기 저장 툴팁, 크기 적용 설명, 각주 설명, 설정/노트 링크 조작 설명 제거 |
| 문서 통계 | 비교 표·표시 기준은 유지하고 합계 설명·집계 기준 장문 제거. 규칙은 [통계 안내](document-statistics.md)에 유지 |
| 트리·책장·서재 순서·그래프 | 드래그·클릭·방향키 조작법을 길게 나열하던 툴팁과 섹션 이동 설명 제거. 동작 이름과 화면 읽기용 설명 유지 |
| 노트 홈 | 수집함 제목의 “정리하거나 아이스박스로 옮길 노트” 제거 |
| 가져오기·복사·템플릿·책 | 기존 문서 유지·포함/제외 항목의 상시 나열, 파일 크기 상시 안내, EPUB 배치 설명 제거. 외부 앱에서 준비할 ZIP 형식은 한 줄로 축약 |
| 공개 읽기 | 글자 크기 입력의 범위·단위 툴팁 제거 |

공개 범위·변환 손실·덮어쓰기·영구 삭제 결과, 저장 충돌·로그인·연결 오류, 실제 백업 상태는 판단에 필요한 정보라 유지하거나 짧게 줄였다. 개인정보 안내와 글꼴 라이선스는 삭제하지 않았다. 상세 조작법은 기능별 문서와 설정의 단축키 구역에서 확인한다.

## 화면만 숨기지 않고 제거한 제한

- 질문·시스템 프롬프트·스킬 요청의 글자 수, 프리셋·스킬 개수 제한을 제거했다.
- 현재 원고·선택 범위 12,000자 제한과 참고 자료 8개·앞 1,800자 자르기를 제거했다. 선택한 자료는 전문을 전송한다.
- 대화 20회·대화가 있는 문서/노트 200개 제한을 스키마·저장 코드·노트 DB trigger에서 제거했다. 이전 대화도 최근 5회·24,000자에서 자르지 않는다.
- 대화·검토 경로에서 일일 호출 예약과 `dailyCalls`를 제거했다. 이전 열린 탭이 쓰는 `reserve_ai_call`은 작가 권한·비공개 사용 기록을 유지하고 일일 상한만 제거했다.
- 긴 글의 커서 답변이 인용문 2,000자 제한에서 실패하는 것을 브라우저에서 발견해 답변·인용·수정문 길이 제한과 답변 입력칸의 길이 제한도 제거했다.

작가 인증·자료 소유권·원고 버전·선택 범위·대화 순서는 계속 검사한다. 요청 4MiB·제공자 응답 256KiB와 서버 시간 제한, 제공자 계정/모델의 한도·요금은 별개다. 저장 공간의 기존 용량 검사도 유지한다. 전송할 자료를 조용히 잘라 한도 안에 맞추지 않는다.

## 검증 구분

서버 합성 호출, SQL, ZIP 왕복, 실제 브라우저 조작과 운영 적용 결과는 [검증 기록](../VERIFICATION.md)을 따른다. 이번 시험에는 실제 원고·제공자 키를 사용하거나 유료 모델을 호출하지 않는다.
