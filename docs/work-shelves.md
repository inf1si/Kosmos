# 집필실 책장

집필실 홈에서 작품을 **책장**으로 나눠 정리한다. 집필 중·구상·잠시 멈춘 작품처럼 이름을 직접 정한다. 작품 안의 문서 섹션·폴더와 별개이며, 공개 서재의 게시 상태·순서와도 독립적이다.

## 만들기와 정리

1. **집필실 홈 → 새 책장**에서 이름을 입력하거나 비워 두고 **책장 만들기**를 누른다.
2. 작품 카드 오른쪽 **책장 이동** 버튼에서 대상 책장을 고르고 **옮기기**를 누른다. 카드 우클릭의 **책장 이동**, **작품 정보 편집 → 책장**에서도 옮긴다.
3. 책장 제목을 누르면 접거나 펼친다. 접힌 상태에도 작품 개수와 책장 메뉴는 보인다.
4. 제목·작품 카드 왼쪽 손잡이(GripVertical)를 드래그해 책장 순서·책장 안 작품 순서를 바꾼다. 책장 사이 여백에 놓아도 앞뒤 위치를 선택할 수 있다. 작품은 다른 책장의 카드 앞뒤 또는 제목·빈 공간에 놓는다. 빈 책장·접힌 책장에도 놓을 수 있고 이동한 책장은 펼친다.
5. 제목 옆 `…`에서 **이름 변경**, **책장 위로**, **책장 아래로**를 고른다. 처음·마지막 책장의 불가능한 이동은 비활성이다.
6. 제목 옆 `+`로 새 작품을 만들면 그 책장이 미리 선택된다. 일반 **새 작품**은 현재 열린 작품의 책장을 기본으로 제안하며, 만들기 전에 바꿀 수 있다.

손잡이는 평소 숨기고 해당 책장 제목·작품 카드에 마우스를 올리거나 키보드 초점이 있을 때, 드래그 중에만 보인다. 호버 없는 터치 기기에서는 항상 보인다. 표시/숨김으로 카드 위치가 움직이지 않는다.

손잡이에 초점을 두고 **↑↓**로 순서를 바꾼다. 작품 손잡이에서는 **Alt+↑↓**로 이전·다음 책장 끝에 옮긴다. 마우스·터치 드래그 중 **Esc**·포인터 취소·창 이탈 또는 대상 밖 놓기는 저장하지 않는다. 이동할 위치는 선/테두리와 떠 있는 이름으로 표시하고 목록 가장자리에서 자동 스크롤한다. 실제 이동은 놓는 순간 반영되며 이동한 손잡이로 초점이 돌아온다.

긴 이름이 화면을 덮지 않도록 아이콘 툴팁은 동작만 짧게 표시하고, 접근성 이름에는 대상 작품·책장 이름을 포함한다.

사이드바 위 작품 카드의 전환 메뉴도 같은 책장 순서로 작품을 묶는다. 전환하면 해당 작품에서 마지막으로 열었던 문서를 연다. 홈의 **이어 쓰기**와 **최근 수정 문서**는 모든 책장에서 찾는다.

책장은 기본 책장을 포함해 최대 **40개**, 이름은 앞뒤 공백을 뺀 **0~80자**다. 비운 이름은 `title: ""`로 저장하고 홈·전환·선택 목록에서 **이름 없는 책장**으로 표시한다. 이름 없는 책장은 여러 개 만들 수 있으며 ID로 각각 구분한다. 비어 있지 않은 같은 이름은 대소문자와 관계없이 거절한다. 새로 가져온 작품과 노트에서 만든 작품은 기본 책장에 들어간다.

## 책장 삭제와 작품 보존

`… → 책장 삭제`는 짧은 확인 뒤 책장만 없애고 안의 작품은 **기본 책장**으로 옮긴다. 작품 내용·첨부·AI 대화·판본 기록은 남고 게시 상태도 그대로다. 기본 책장도 이름과 위치를 바꿀 수 있지만 삭제할 수 없다.

작품 자체의 **휴지통으로 이동**은 별도 동작이다. 휴지통에 있는 동안 원래 책장 위치를 기억하고, 복원하면 그 책장으로 돌아간다. 그사이 책장을 지웠다면 기본 책장으로 돌아간다. 작품을 영구 삭제하면 책장의 참조도 제거한다. [휴지통 안내](workspace-trash.md).

## 저장과 복원

이름·책장 순서·작품 위치는 선택적 `Workspace.workShelves`에 저장하며 기존 계정 저장 큐·버전 충돌 처리를 따른다. 드래그 중에는 저장하지 않고 놓은 결과의 책장 배열/작품 ID 순서만 저장한다. 저장 실패 시 기기 사본과 대기 요청을 유지하고 재전송한다. 다른 기기로 옮기기 전에 **클라우드 동기화됨**을 확인한다. 자동 병합은 없다. 접힌 상태는 계정별 기기 보기 설정이며 백업·다른 기기로 전송하지 않는다.

전체 ZIP·Drive ZIP·DB 백업·기기 복구 이력에는 책장 정보가 들어간다. 책장 필드가 없는 이전 백업을 복원하면 현재 책장을 보존하고, 복원본에도 남은 작품 ID의 위치만 유지한다. 책장 배열이 명시돼 있으면 그 배열을 사용하며, 명시적인 빈 배열은 기본 책장으로 초기화한다. 선택 문서 교환 파일에는 작품 책장 목록을 넣지 않는다.

이전 작업 공간에는 책장이 없어도 **기본 책장** 하나로 모든 작품을 보여준다. 작품 원본의 순서·문서 내용·공개 판본·공개 서재 순위는 책장 이동으로 바꾸지 않는다. 새 기능을 쓰기 전에 기존 집필실 탭을 새로고침한다. 새 필드의 제거를 막는 별도 서버 보호 SQL은 추가하지 않았다.

## 검증 범위

손잡이 표시 회귀는 `KOSMOS_SHELF_VISIBILITY_ONLY=1`로 `tests/browser/work-shelves.mjs`를 실행해 포인터/터치 환경을 구분해서 확인한다. 자동 검사와 브라우저 조작의 결과는 [VERIFICATION](../VERIFICATION.md)에 기록한다. 브라우저 시험은 합성 계정·원고·저장 응답을 사용하며 실제 사용자 원고를 변경하지 않는다. 실제 계정의 다중 기기 동기화·모바일 기기·다른 브라우저는 별도 확인 대상이다.
