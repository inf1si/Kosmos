# 작가·독자 사용 안내

홈 화면에서 **서재 둘러보기**·**작가 집필실**로 들어가며 상단에서 테마를 고른다. 홈 바닥글은 사이트 이름만 표시한다. [개인정보 및 데이터 이용 안내](https://kosmos-ashy.vercel.app/privacy)는 해당 주소에서 읽을 수 있다.

노트의 **최상위 폴더 추가**와 행의 `…`에서 하위 노트·폴더, 드래그/이동·순서 변경·정리 되돌리기를 쓴다. 검색과 보관함 보기에서도 상위 경로가 남는다. **AI 대화**에서 아이디어 확장·브레인스토밍·생각 정리와 기존 제공자·프리셋을 쓰고 대화를 하위 노트로 보관할 수 있다.

## 개인 노트

집필실 사이드바의 **노트**를 연다. 원고를 쓰다가 떠오른 생각은 상단 **빠른 메모**(Alt+N, 맥 Option+N)에 적고 Ctrl/Cmd+Enter로 수집함에 넣으면 화면이 바뀌지 않는다. 노트 공간의 Alt+N은 새 노트, Ctrl/Cmd+K는 전체 검색이다. 제목·태그·작품은 선택 사항이다.

노트 공간을 열면 **노트 홈**에 고정한 노트·최근 수정·수집함과 템플릿(인물 시트·세계관·로그라인·장면 구상·브레인스토밍)이 보이고, **보드**로 바꾸면 최상위 폴더별 카드를 끌어 옮긴다. 노트 편집기에는 **체크리스트**와 **본문에 이미지 넣기**가 있고, **노트 링크 추가**로 다른 노트를 연결하면 **노트 링크 n** 칩에서 가리키는 노트와 백링크를 본다. 원고를 쓰는 중에는 참고 패널 **노트** 탭에서 메모·검색·읽기를 한다. Evernote는 사이드바 **노트 가져오기**에서 ENEX로 옮기고(태그·날짜·체크리스트·이미지 유지), 구상이 모인 폴더는 `…` → **새 작품으로 만들기**로 작품을 시작한다. 아이스박스 보관, 여러 작품 연결, 원본을 남기는 작품 문서 가져오기와 첨부·백업은 [개인 노트 안내](personal-notes.md)를 따른다.

운영 집필실의 Google 로그인은 먼저 기존 이메일 로그인 → 상단 **로그인 계정** → **Google 계정 연결**을 한 번 승인한 뒤 사용한다. Naver 이메일과 Gmail 주소가 달라도 기존 작가·원고를 그대로 유지한다. Google 제공자 설정을 먼저 활성화해야 한다. [연결·설정·오류 안내](google-login.md).

현재 로컬 주소는 `http://127.0.0.1:3210/studio`다. 개발 서버가 실행 중이어야 열린다. 처음 보이는 작품과 문서는 샘플이며 실제 원고가 아니다.

## 집필실 홈

집필실에 들어가면 **집필실 홈**이 열린다. 맨 위 **이어 쓰기**는 이 기기에서 마지막으로 연 작품·문서, **책장**은 작품을 나누는 묶음(형식·원고 문서 수·글자 수·마지막 수정일, 지금 사이드바에 열린 작품은 선택 바탕), **최근 수정 문서**는 모든 작품에서 최근에 고친 문서 8개다. 카드를 누르면 그 작품으로 바꿔 문서를 연다. 작품 카드는 그 작품에서 마지막으로 연 문서(없으면 첫 원고 문서)를 연다. 위쪽 줄에 전체 작품·원고·글자 수와 **서재 순서 편집**, **새 책장**, **새 작품**이 있다. **새 책장**으로 보관·구상 등을 만들거나 이름을 비울 수 있다. 책장·작품 왼쪽 손잡이를 드래그해 순서와 소속을 바꾸며 빈/접힌 책장에도 놓을 수 있다. 손잡이 ↑↓는 순서, 작품의 Alt+↑↓는 책장 이동, Esc는 드래그 취소다. 작품 카드 오른쪽 **책장 이동**으로 옮긴다. 제목을 눌러 접거나 펼치고 `…`에서 이름·순서를 바꾼다. 책장을 지워도 작품은 기본 책장으로 옮겨 남는다. 사이드바 작품 전환도 같은 분류를 쓴다. [책장 사용법·저장 범위](work-shelves.md).

홈은 탭으로 남아 있어 탭 줄이나 **뒤로**, 사이드바 맨 위 **집필실 홈**으로 돌아온다. 바로 편집 화면으로 들어가려면 **설정 › 집필 도구 › 집필실 첫 화면**을 **마지막 문서**로 바꾼다. 마지막 위치는 이 기기에만 기억하며 원고·계정·백업에는 들어가지 않는다. 사이드바 작품 카드 메뉴로 작품을 바꿀 때도 그 작품에서 마지막으로 연 문서가 열린다. [설정](settings.md).

작품 카드의 별표로 즐겨찾기를 추가하면 홈의 **즐겨찾기** 목록에서 바로 연다. 선택하지 않은 별표는 호버·키보드 초점에서 보인다. 카드 우클릭·작품 정보 창에서도 추가/해제하며 계정·전체 백업에 저장한다. [저장 범위](work-shelves.md#작품-즐겨찾기).

작품 카드를 우클릭하면(터치는 길게 누르기, 키보드는 카드에 초점을 두고 Shift+F10) **열기**, **작품 정보 편집**, **책장 이동**, **게시 철회**(게시 중인 작품만), **휴지통으로 이동**이 뜬다. 게시 중인 작품은 카드 둘째 줄에 **게시 중**이 붙는다. 같은 동작은 사이드바 작품 메뉴·사이드바 아래 설정 아이콘·더 보기의 **작품 정보 편집** 창에도 있다. 이 창에서는 작품명·형식·책장·부제·작품 소개를 고치고 공개 상태를 확인한다.

**휴지통으로 이동**은 작품 전체(문서·정리 구조·AI 대화·이전 판본 기록·첨부)를 한 항목으로 공유 휴지통에 옮긴다. 확인창에서 한 번 묻고, 게시 중이면 판본 게시도 함께 철회한다. 노트의 작품 연결은 떼었다가 복원할 때 다시 잇는다. 마지막 작품은 옮길 수 없다. 휴지통에서 **복원**하면 작품 목록과 책장의 원래 자리로 돌아오며 게시는 다시 하지 않는다.

## 1. 작품과 문서 만들기

1. 사이드바 위 작품 카드를 눌러 **새 작품**에서 작품명과 단편·중편·장편, 책장을 선택한다. 책장 제목 옆 `+`는 해당 책장을 미리 선택한다.
2. 생성 후 같은 작품 카드 메뉴나 **집필실 홈**의 작품 카드에서 새 작품으로 전환한다.
3. 사이드바의 섹션 옆 `+`로 문서를 만든다. 문서나 폴더의 `…`에서 **하위 문서 추가**, **하위 폴더 추가**로 내용을 묶는다. 위의 **섹션 추가**로 연대표·아이디어 등 새 묶음을 만든다.
4. 제목은 원고 위 제목을 바로 고친다. 비워도 저장되며 트리·탭·공개 목차에는 **제목 없음**으로 표시한다. 진행 상태는 제목 아래 첫 칩에서 바꾸고, **속성**을 펼쳐 원고의 부·장, 시점 인물, 작중 시간, 요약을 기록한다. 기록한 값은 제목 아래 칩으로 보인다.

새 빈 작품은 **원고 → 본문 → 첫 문서**로 시작한다. 새 문서의 **부 · 장 (발행 구분)**은 비어 있으며 부모 문서의 값을 자동으로 이어받지 않는다. 플롯보드의 일반 **문서 추가**도 빈 값으로 시작하고, 특정 열의 **이 부에 문서 추가**·**부 추가**를 선택할 때만 그 부를 지정한다. 기존 작품의 폴더와 발행 구분은 그대로 유지한다.

폴더 안에 문서가 하나만 있어도 `… → 휴지통으로 이동`을 쓸 수 있다. 작품 전체의 마지막 문서라면 폴더 밖 원고 섹션에 빈 **새 문서** 하나를 남기고 연다. 원본은 본문·속성·첨부·AI 대화와 함께 휴지통에서 복원하며, 그동안 새 문서에 쓴 내용도 남는다.

문서와 폴더는 모두 하위 문서·폴더를 품을 수 있다. 행 왼쪽 이동 손잡이를 끌어 위·아래에 놓으면 순서가 바뀌고, 가운데에 놓으면 그 항목 아래로 들어간다. `… → 이동`(행 우클릭으로도 열림)에서 키보드로도 위치를 고른다. **정리 되돌리기**는 마지막 구조 변경 하나를 되돌리며 이후 편집한 본문은 유지한다. [문서 트리 사용법](document-navigation.md).

폴더는 정리용이다. 폴더 이동·이름 변경과 원고의 **부·장 (발행 구분)**은 별도이며, 플롯보드는 원고 속성의 부·장으로 묶는다. 문서 종류나 공개 권한은 이동으로 바뀌지 않는다. 노트·원고·설정집·메모 행의 `… → 휴지통으로 이동`으로 해당 항목을 옮긴다. 확인창은 없고 하위 항목은 남는다. 왼쪽 **휴지통 → 복원**으로 항목 하나만 되돌린다. 영구 삭제와 비우기도 짧게 확인하며 자동 삭제하지 않는다. [휴지통 안내](workspace-trash.md).

내용이 있는 폴더의 `… → 폴더 전체 삭제`는 짧은 확인창에서 **삭제**를 눌러 하위 폴더·문서를 모두 지운다. 검색에 숨겨진 문서도 포함하며 문서·노트는 각각 휴지통에 보관한다. 작품의 모든 문서를 지우면 빈 **새 문서** 하나를 남긴다. 휴지통에는 폴더 한 줄로 묶여 보이며 **복원** 한 번에 내부 계층·순서도 되돌린다. 사이드바와 창의 개수도 폴더당 **1개**이고 내부 문서/노트 수는 행에 따로 표시한다. 구조 정보가 없는 이전 항목은 폴더 하나에 모아 복원한다. **백업과 복구**의 삭제 전 복구 지점은 당시 작업 공간 전체를 복원한다.

문서 종류에 관계없이 **속성 → 속성 추가**에서 텍스트·숫자·날짜·체크박스 항목을 만든다. 항목 이름과 값을 문서별로 보관하며 `×`로 지울 수 있다. 노트도 같은 속성 기능을 제공한다.

**템플릿**은 양쪽 사이드바에서 연다. 문서/폴더 메뉴의 **템플릿으로 저장**으로 시작하거나 **새 템플릿 저장**에서 여러 항목을 선택한다. 저장한 템플릿과 넣을 위치를 고른 뒤 **템플릿으로 만들기**를 누른다. [포함 범위와 복구](workspace-templates.md).

## 2. 집필과 참고 문서

본문에 입력하고 도구 모음에서 서식·정렬·목록·인용·구분선을 적용한다. 글꼴 20가지와 10~72px 크기(0.5px 단위 직접 입력 또는 옆 화살표의 크기 목록)는 브라우저의 보기 설정이다. 글자를 드래그해 선택한 뒤 크기를 고르면 **선택한 부분만** 그 크기가 되고, 이 크기는 본문 서식으로 저장된다. **목록** 버튼에서 점·빈 원·네모 글머리 기호나 숫자·가나다·ㄱㄴㄷ·소문자·대문자·로마자 번호를 고른다. **문단 스타일**, **문자 서식**, **문단 서식**, **표**, **특수문자**에서 제목·위/아래첨자·강조·들여쓰기·간격·표를 편집한다. 이 본문 서식은 원고·동기화·백업·공개 문서에 포함된다. [원고 편집 도구](editor-tools.md). 도구가 가려지면 양끝 화살표로 이동하거나 가로로 스크롤한다.

도구 모음의 **글자 수**를 누르면 **문서 통계**를 연다. **도구 모음에 표시**에서 공백 제외·포함, 단어(어절), 문단, 200자 원고지 환산을 고른다. 선택은 즉시 반영하고 글꼴·크기와 함께 이 브라우저에 저장한다. 본문을 드래그하거나 키보드로 선택하면 도구 모음은 **선택** 표시와 함께 해당 부분만 세고, 선택을 해제하면 문서 전체로 돌아간다. 숫자를 누르면 선택 영역·현재 문서·작품 전체 원고의 상세 수치를 비교한다. 분할 창도 각 문서와 각자의 선택 통계를 제공한다. [집계 기준과 원고지 환산](document-statistics.md).

문서를 열면 편집 창 위 탭에 유지되고, 탭 줄의 뒤로·앞으로로 앞서 본 문서로 돌아간다. 사이드바 문서 행의 **… → 옆에서 열기**, 설정 링크 미리보기의 **옆에 열기**, 탭 줄의 **옆에 열기**로 설정이나 앞 문서를 함께 연다. 두 편집창은 각각 입력할 수 있다. 경계를 드래그하거나 경계에 키보드 포커스를 두고 좌우 화살표로 폭을 조절한다. **더 보기 → 집중 모드**로 사이드바와 참고 패널을 접고, 탭 줄 왼쪽의 사이드바 버튼으로 돌아온다.

사이드바 아래 보라·카세트·사이버 버튼으로 색 계열을, 달/해 버튼으로 라이트·다크를 바꾼다. 공개 페이지와 같은 설정이다. 사이드바 도구 줄의 **설정**에서는 이 값과 원고 표시(글꼴·크기·줄간격·첫 줄 들여쓰기·문단 간격·본문 폭), 글자 수 기준, 플롯보드·문서 그래프 첫 보기, 노트 보기, AI 연결·보낼 자료 기본값, 자동 복구 지점 간격을 한곳에서 고르고 단축키를 확인한다. 밝기를 **기기 설정**으로 되돌릴 수도 있다. [설정 항목](settings.md). 탭·분할 폭 등 작업 배치는 현재 세션 중심이다. 새로 열었을 때 같은 배치를 복구하는 프리셋은 아직 없다. 좁은 화면의 사이드바·참고 패널은 내부 닫기 버튼·Esc·배경 클릭으로 닫는다.

## 3. 검색과 구성

설정의 **속성 → 분류**와 원고의 **속성 → 시점 인물**은 직접 입력하거나 오른쪽 화살표로 기존 항목을 고른다. 위·아래 키와 Enter로도 선택할 수 있다. Esc로 목록을 닫는다. 입력 내용은 다른 속성과 같이 즉시 저장되며 별도 분류 생성 버튼은 없다.

- 사이드바 **검색**(Ctrl K)은 현재 작품의 문서 제목·일반 본문과 폴더 이름을 문자열로 검색한다. 일치하는 문서와 그 상위 경로를 함께 보여준다. 검색 중에는 끌어 이동을 잠시 막는다. Esc로 닫는다. 다른 작품이나 모든 문서 속성을 함께 검색하지 않는다.
- 편집기 **찾기와 바꾸기**(원고 안에서 Ctrl/⌘ F·H)는 현재 문서의 일치 강조·개수·이전/다음 결과, 대소문자·어절 일치, 개별/모두 바꾸기를 제공한다. 서식 경계를 넘는 검색과 문자 그대로의 치환을 지원하며 모두 바꾸기는 한 번에 실행 취소한다. [검색 범위](editor-tools.md#찾기바꾸기).
- **더 보기 → 문서 위로/아래로 옮기기**로 같은 부모 아래의 순서를 바꾼다. 폴더·문서 트리를 위에서 아래로 펼친 원고 순서는 다음 공개 판본의 문서 순서에도 쓰이며 이미 게시한 판본은 그대로다.
- 사이드바 **플롯보드**는 문서 카드를 부와 장(기본), 진행 상태, 작중 시간으로 모아 본다. 작중 시간 보기는 "귀환일 · 08:40"처럼 가운뎃점 앞 값으로 묶는다. 부 열의 **이 부에 문서 추가**와 **부 추가**로 문서를 만든다. 상태는 문서의 상태 칩에서 바꾼다. 카드 드래그는 미지원이다.

### 문서 관계 지도

사이드바의 **문서 그래프**에서 현재 작품의 원고·설정집·메모를 한눈에 본다. **전체 / 주변 연결**을 전환하고, 제목 검색·종류·설정 분류·시점 인물 필터로 범위를 좁힌다. 본문 설정 링크는 실선, 시점 인물은 점선이다. 노드를 한 번 누르면 연결 목록을 보고 두 번 누르거나 **문서 열기**로 원본을 연다. 노드·빈 배경을 드래그하고 휠·버튼으로 확대한다. [연결 기준·키보드 조작·표시 한도](document-graph.md).

## 4. 각주와 설정 링크

**각주:** 본문에서 위치를 잡고 **각주 추가 → 내용 입력 → 각주 삽입**을 실행한다. 입력 창은 선택한 글자 바로 아래에 열리고 원고를 가리지 않는다. 원고의 각주 표시(*)에 마우스를 올리면 각주 번호와 내용을 카드로 보여준다. 공개 문서에 포함된 각주는 독자도 읽는다. 비공개 집필 메모를 각주에 적지 않는다.

**설정 링크:** 먼저 같은 작품의 설정 문서를 만든다. 연결할 단어를 선택하고 **설정 링크 추가 → 문서 선택 → 연결**을 실행한다. 선택한 글자가 없으면 설정 제목을 링크로 삽입한다. 설정 링크에 마우스를 올리면 분류·설명·등장 수가 있는 미리보기가 뜨고, **옆에 열기** 또는 Ctrl+클릭으로 설정을 옆에서 연다. 키보드로는 참고 패널의 **연결** 탭에서 연다.

기존 각주는 표시(*)에 마우스를 올리거나 클릭한 뒤 **각주 수정 → 내용 편집 → 각주 저장**으로 고친다. 취소·Esc는 원문을 유지하고, 저장한 수정은 편집기 실행 취소 한 번으로 되돌린다. 노트와 분할 창에서도 같으며 이전 세션의 실행 취소 기록까지 보존하지 않는다. 이미 게시한 공개판은 다시 게시하기 전까지 기존 설명을 유지한다.

## 5. 설정집의 집필용 내용과 독자용 내용

설정 문서의 본문에는 작가용 상세 설정을 쓴다. 제목 아래 **속성**의 **독자용 설명**에는 공개할 설명만 쓴다. **독자용 설명 공개**를 체크해도 설명이 비어 있으면 공개 설정에 포함하지 않는다.

설정 본문과 메모는 게시 판본에 들어가지 않는다. 독자용 설명은 현재 일반 텍스트다. 공개 위키의 표·복잡한 문서 서식·별칭·스포일러 단계 표시는 후속 개발이다.

## 6. 참고 이미지

참고 패널의 **첨부** 탭에서 **이미지 첨부**로 PNG/JPEG/WebP 파일을 추가한다. 파일 하나는 10MiB 이하다. 첨부 이름을 클릭하면 내려받는다. 현재 첨부는 비공개 참고 자료이며 본문 이미지·공개 표지로 게시하는 흐름은 없다.

클라우드 모드에서는 업로드를 완료할 연결이 필요하다. 첨부 실패 후에는 오류를 확인하고 연결이 돌아왔을 때 다시 추가한다.

## 7. 게시하기

1. 원고 순서와 독자용 설정 설명을 확인한다.
2. 편집 창 오른쪽 위 **게시 준비**를 열고 공개할 문서를 선택한다. 본문이 빈 원고 문서(새로 만든 문서, 마지막 문서를 옮긴 뒤 남은 문서 등)는 처음에 선택되지 않는다. 필요하면 직접 체크한다.
3. 함께 공개되는 설정 설명 목록을 확인한다.
4. **선택한 문서 게시**를 실행한다. 클라우드 모드에서는 저장 완료가 먼저 확인되어야 한다.
5. **독서 화면 열기**로 각주와 설정 연결까지 읽어본다.

현재는 선택한 문서들이 작품의 새 공개 판본을 구성한다. 별도의 회차 객체·예약 게시는 없다.

공개를 멈추려면 집필실 홈 작품 카드 우클릭이나 **작품 정보 편집**의 **게시 철회**를 누르고 확인한다. 공개 서재·독서·설정집 화면에서 그 작품이 바로 빠진다. 원고와 이전 판본 기록은 남고, 다시 게시하면 그때 원고로 새 판본을 만든다. 클라우드 모드에서는 서버에 2026-10-07 [작품 휴지통·게시 철회 마이그레이션](../supabase/migrations/20261007081500_work_trash_unpublish.sql)이 설치되어 있어야 하며, 없으면 아무것도 바꾸지 않고 데이터베이스 업데이트가 필요하다고 알린다. 미리보기의 게시 버튼은 해당 기기의 미리보기만 바꾸며 외부 독자에게 공개하지 않는다.

게시 후 초안을 바꿔도 기존 공개판은 유지된다. 수정 내용을 공개하려면 새로 게시한다. 공개할 문서의 본문과 각주 자체에 비공개 내용이 없는지도 확인한다.

## 8. 독서와 공개 설정집

서재의 **본문 미리보기**는 첫 공개 문서의 첫 번째 비어 있지 않은 문단을 16px로 최대 4줄 보여주고, 긴 내용은 말줄임표로 줄인다. 문단 안 줄바꿈은 공백으로 이어 표시하며 원고·공개 본문을 수정하지 않는다. 전체 내용은 **작품 읽기**로 연다.

서재 기본 순서는 **작가 지정순**이다. 집필실 **홈 → 서재 순서 편집**에서 작품 왼쪽 손잡이를 드래그하거나 위·아래 버튼으로 조정한 뒤 **서재 순서 저장**을 누른다. 마우스·터치와 손잡이의 ↑↓ 키를 사용할 수 있고 제목 오름차순·내림차순·최신/오래된 게시순의 자동 정렬도 제공한다. 독자는 서재의 **정렬**에서 같은 기준을 별도로 고르며 선택은 그 브라우저에만 기억한다. 새 작품의 첫 게시에는 맨 뒤 자리를 주고 재게시에는 지정한 순서를 유지한다. [순서 편집과 저장 범위](library-order.md).

독자는 `/library`에서 작품을 열고 목차로 문서를 이동한다. 각주에 포인터를 올리거나 키보드로 접근하면 짧은 설명을 확인한다. 클릭하면 각주로 이동하고 복귀 링크로 본문에 돌아간다. 모바일에서는 탭으로 사용한다.

설정 링크를 누르면 그 단어 옆에 설명 카드가 열리고 해당 작품의 설정집으로 갈 수 있다. 공개 설명이 없는 설정은 독자에게 본문을 제공하지 않는다. 설정집에서 분류·검색과 그 설정을 연결한 공개 문서를 확인한다.

읽기 설정은 집필실과 같은 글꼴 20종, 글자 크기, 본문 폭, 밝은/어두운 배경, 테마(보라/카세트/사이버)다. 글자 크기는 10~72px 목록에서 고르거나 **크기 직접 입력 (px)**에서 0.5px 단위로 입력한다. Enter·입력칸 밖 이동으로 적용하고 잘못된 값은 마지막 유효값으로 돌아간다. Esc는 적용하지 않은 입력을 취소하고 설정 창을 닫는다. 기본 고운바탕·19px와 이전 명조/고딕 선택·17/19/21/23px 저장값을 유지하고 모바일에서도 선택한 크기를 적용한다. 배경은 모든 공개 페이지 헤더의 달/해 버튼과, 테마는 그 옆의 보라·카세트·사이버 버튼과 같은 값이다. 사이버는 라이트에서 밝은 사이버프렙, 다크에서 네온 사이버펑크로 보인다. 배경을 고르지 않으면 기기의 라이트·다크 설정을, 테마를 고르지 않으면 보라를 쓴다. 설정과 읽기 위치는 독자의 현재 브라우저에 저장한다. 읽기 글꼴·크기는 집필실의 원고 표시 설정과 별도로 저장하며 공개 판본의 본문 서식은 바꾸지 않는다. 기기 간 읽기 위치 동기화와 독자 계정은 없다.

## 9. 저장·복구·AI

사이드바 아래 저장 상태를 확인한다. 사이드바를 접으면 서식 도구 오른쪽에 보인다. **이 기기에 저장됨**과 **클라우드 동기화됨**은 다르다. 실제 원고를 이동하기 전에는 사이드바의 **백업과 복구 → 백업 내려받기**로 ZIP을 보관한다.

현재 시점을 남기려면 **더 보기 → 복구 지점 만들기** 또는 백업 대화상자의 **지금 복구 지점 만들기**를 사용한다. 이력 복원·ZIP 복원은 작업 공간 전체를 바꾼다. 절차와 경계는 [백업·복구](backup-restore.md)를 따른다.

서식 도구 오른쪽 **AI 대화** 또는 참고 패널의 **AI 대화** 탭을 연다. 추천 기능을 누르면 질문이 입력된다. **보낼 자료**에서 원고 포함 여부를 정하고 같은 작품의 설정·원고·메모를 최대 8개 선택한 뒤 보낸다. Enter는 전송, Shift+Enter는 줄바꿈이다. 연결된 제공자만 전송할 수 있고 현재 API 키·모델 연결은 필요하다.

키가 없으면 AI 대화 위의 **AI 설정**(설정 아이콘)을 연다. 제공자와 모델 ID를 고르고 API 키를 붙여 넣은 뒤 **연결 저장**을 누른다. OpenAI·Claude·Gemini를 각각 연결할 수 있다. 보관한 키는 다시 표시하지 않는다. 모델만 바꿀 때는 키를 비워도 된다. 저장은 AI를 호출하지 않으므로 실제 연결은 짧은 첫 질문으로 확인한다.

키는 서버가 암호화해 이 브라우저·도메인에 최대 30일 보관한다. 원고·대화·백업에는 넣지 않으며, 다른 기기·도메인이나 만료 후에는 다시 입력한다. **브라우저 연결 해제**를 누르면 해당 연결을 지운다. Vercel에 기본 키·모델을 설정해 두었다면 다시 그 값을 사용한다.

같은 설정 창의 **시스템 프롬프트·프리셋**에서 기본 6종 또는 새 프리셋을 골라 이름·지침을 **저장·적용**한다. 사용자 최대 20개, 이름 80자·지침 4,000자다. 기본값 편집은 사용자 사본을 만든다. 대화창의 **프리셋**으로 갈아끼운다. **기본값으로 재설정**은 사용자 프리셋을 보존한다. 동일 계정의 모든 작품·기기에 동기화하고 전체 백업에 포함한다. API 키는 기기마다 연결한다. 창을 닫기 전 저장·적용과 클라우드 상태를 확인한다. [AI 안내](ai.md).

대화는 문서마다 이어지며 기기 저장·클라우드 동기화·전체 ZIP/DB 백업에 포함된다. 한 문서에 20회까지 대화하며 최근 5회 안에서 길이 제한에 맞춰 이전 대화를 보낸다. **대화를 메모로 보관**하면 Markdown·HTML·ENEX로도 내보낼 수 있다. **새 대화**는 확인 후 현재 기록을 비우며 복구 지점을 먼저 만든다.

수정 제안은 원문·수정안·이유를 비교한 뒤 **원고에 적용**을 누른다. 적용 전 복구 지점을 만들고, 답변 이후 원고가 바뀌면 적용을 막는다. 제한과 동작은 [AI 기능](ai.md)에 기록했다.

## 10. Notion·Evernote 등과 문서 교환

사이드바의 **가져오기 · 내보내기**를 열고 파일을 선택한다. 미리보기에서 문서를 원고·설정집·메모로 분류하고 새 작품이나 현재 작품에 추가한다. 내보내기에서는 작품·문서를 선택해 MD/HTML ZIP 또는 ENEX를 만든 뒤 파일 저장 링크를 누른다. 표·DB·첨부 제한과 원본 보관은 [교환 안내](import-export.md)를 따른다.

백업과 복구 아래의 Drive 상태는 연결 전에는 미연결로 표시한다. [연결 순서](service-connection.md) 완료 후 마지막 검증 시각과 지금 외부 백업을 사용한다. AI 패널에서는 키·모델을 연결한 OpenAI·Claude·Gemini만 실행할 수 있다.

집필실 원고·설정집·메모·분할 창에서도 문장 중간에서도 여는 `/` 메뉴, **Alt+Enter** AI 질문과 선택 글 우클릭 AI를 쓴다. 답변은 질문한 문서에 저장하고 선택 범위/문단 교체·커서 삽입과 한 번 실행 취소를 제공한다. [편집기 조작](editor-tools.md#입력-명령과-ai-질문).

읽기 설정의 합성 브라우저 검사는 [reader-preferences.mjs](../tests/browser/reader-preferences.mjs)에 있다. 클라우드 설정을 비운 로컬 빌드에 `ALLOW_LOCAL_PREVIEW=true`로 시작하고 [노트 검사와 같은 브라우저 환경 변수](personal-notes.md#검증)로 실행한다. 20종의 실제 글꼴 적용·앱 내 웹폰트 응답, 크기 목록·22.5px·잘못된 입력·Esc·목차 전환·기존 설정 복원·새로고침 유지와 여섯 테마 × 1280/360px를 확인한다.
