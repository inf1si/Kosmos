# 사용자 속성과 템플릿

기준: 2026-10-07. 집필실 원고·설정·메모와 개인 노트에서 사용한다.

## 사용자 정의 속성

제목 아래 **속성 → 속성 추가**에서 이름과 형식을 정한다. 텍스트·숫자·날짜·체크박스를 지원하며 문서마다 최대 40개다. 이름은 80자, 텍스트 값은 2,000자까지이고 이름은 중복할 수 없다. 숫자 0과 체크 해제도 저장한다. 값은 바로 편집하고 `×`로 항목을 지운다. 기본 부·장·시점·분류와 독립된 항목이다. 값이 있으면 제목 아래 칩으로 최대 세 개와 나머지 개수를 보여준다.

## 템플릿 저장과 사용

- 문서/폴더의 `…` 또는 우클릭 → **템플릿으로 저장**에서 이름을 정한다. 폴더 및 상위 문서의 모든 하위 항목을 포함한다.
- 여러 문서는 **설정 → 저장 · 백업 → 템플릿 → 새 템플릿 저장**에서 체크한다. 선택이 겹쳐도 한 번만 담는다. 폴더를 선택하면 내부 문서도 포함되며 검색에 가려진 항목도 포함한다.
- **템플릿 사용**에서 저장한 템플릿·넣을 위치를 고른 뒤 **템플릿으로 만들기**를 누른다. 폴더/문서 아래 또는 섹션 최상위에 새 문서를 만든다. 문서/폴더/섹션 메뉴의 같은 동작은 해당 위치를 미리 선택한다.
- 계정에 최대 100개를 저장한다. 작품 문서 템플릿은 다른 작품에서도 쓸 수 있고, 개인 노트 템플릿은 노트 공간에서 사용한다. 기존 노트 홈의 인물/세계관 기본 템플릿은 별도로 유지한다.

본문·각주·요약·사용자 속성·폴더 구조·첨부·묶음 내부 연결을 포함한다. 저장 후 원본을 고쳐도 템플릿은 바뀌지 않는다. 첨부는 별도 사본이므로 원본을 삭제해도 남는다. 적용할 때 문서·폴더·블록·각주·속성·첨부에 새 ID를 만들고 내부 링크를 새 문서로 잇는다. 선택하지 않은 상위 문서는 복사하지 않고 포함한 항목을 루트로 둔다. 서로 다른 섹션에서 선택한 루트들은 넣을 위치의 같은 섹션에 들어가며 문서 종류는 유지한다.

AI 대화·공개 상태·작품 연결·고정 여부는 복사하지 않는다. 묶음 밖의 문서 연결은 연결을 떼고 글자만 남긴다. 적용한 작품 문서는 비공개·집필 중이다. 노트 본문 이미지는 새 첨부로 연결하고 체크리스트는 유지한다. 원본과 템플릿은 그대로 남는다.

## 삭제·복구·저장

**템플릿 사용 → 템플릿 삭제**는 짧게 확인한다. 이미 생성한 문서에는 영향을 주지 않는다. 적용 전과 삭제 전에 전체 복구 지점을 만든다. **백업과 복구**에서 이 지점을 복원하면 당시 전체 작업 공간을 되돌리며 이후 다른 편집도 함께 되돌아간다.

템플릿·속성은 계정 작업 공간에 동기화하고 전체 ZIP/복구 지점/Drive 백업에 포함한다. 템플릿과 복제 첨부는 비공개이며 공개 판본에 포함하지 않는다. MD/HTML 교환 ZIP은 선택 문서의 속성과 빈 제목을 Kosmos 메타데이터로 보존하지만 템플릿 목록은 포함하지 않는다. 다른 앱·ENEX의 속성 호환성은 제공하지 않는다.

첨부 복제나 저장이 실패하면 새 항목 생성 전에 멈춘다. 준비 중 본문·계정·충돌이 바뀌면 다시 시도하도록 한다. 기존 문서/노트 5,000개·탐색 노드 7,500개·깊이 24단계·작업 공간 JSON 20MB·첨부 2,000개 한도를 공유한다. 템플릿 삭제는 과거 백업과 Storage 바이트를 지우지 않는다.

이전 형식 1 자료는 계속 읽는다. 이전 전체 백업이 새 필드를 누락한 경우 현재 템플릿·필요 첨부 및 같은 ID 문서의 사용자 속성을 보존한다. 명시적 빈 배열은 삭제된 상태다. [서버 보호 SQL](../supabase/migrations/20261007124540_workspace_templates_guard.sql)은 구버전 탭의 필드 누락을 거절한다. 배포 후 열린 탭은 새로고침한다.

## 제목 없음

집필실 문서 제목도 선택 사항이다. 만들기 창을 비워 제출하거나 기존 제목을 지워도 빈 문자열로 저장한다. 트리·탭·플롯보드·그래프·선택 목록·공개 목차는 **제목 없음**으로 표시한다. 폴더·섹션·작품·템플릿 이름은 필요하다. 개인 노트는 기존처럼 제목이 없으면 본문 첫 줄을 목록 제목으로 쓴다.
