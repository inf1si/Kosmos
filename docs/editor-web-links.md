# 웹 링크

집필실 원고·설정집·메모·분할 편집과 노트의 도구 모음에서 **웹 링크**(지구본)를 누른다. `/웹` 또는 선택 없는 본문의 **우클릭 › 삽입 › 웹 링크**로도 연다. 기존 설정/노트 연결과 비공개 `@` 참조는 유지한다.

- 글을 선택한 뒤 주소를 넣으면 그 글에만 연결한다. 글자·굵게/기울임 같은 서식·각주·비공개 참조는 보존한다. 선택 부분의 기존 설정/노트 링크는 웹 링크로 바뀐다.
- 커서만 있으면 **표시할 글**을 입력할 수 있다. 비워 두면 주소를 넣는다. HTML 모양의 글도 문자 그대로다. 뒤에 새로 입력하는 글까지 링크로 이어 붙이지 않는다.
- 본문에 입력하거나 붙여 넣은 글은 `https://`·`http://`·`www.`로 시작하는 주소만 저절로 링크가 된다. "Mr.Kim"·"readme.md"·"naver.com"처럼 점이 든 낱말과 이메일은 글로 남는다. 그런 주소는 도구로 연결한다.
- `example.com/path`처럼 프로토콜을 생략하면 HTTPS를 붙인다. 입력 창은 HTTP/HTTPS 주소만 허용하며 실행 주소·인증 정보가 든 주소·내부 공백/제어 문자는 거절한다. 사이트 존재 여부를 확인하거나 미리보기를 받기 위해 주소에 접속하지 않는다.

편집 중 링크를 클릭하면 커서는 그 자리에 두고 링크 아래에 주소 말풍선을 띄운다. 초점이 본문에 남아 링크 글자를 바로 고칠 수 있고, 입력하거나 커서가 링크 밖으로 나가면 말풍선이 닫힌다. 말풍선의 주소는 새 탭으로 열고, 연필은 **웹 링크 수정** 창을, 링크 해제 아이콘은 글만 남긴다(한 번에 실행 취소). 수정 창에서 주소를 고쳐 **저장**하거나 **링크 해제**로 글만 남긴다. 커서를 기존 링크 안에 놓고 도구를 눌러도 링크 전체를 수정한다. 링크의 일부 글을 직접 선택했으면 선택한 부분에만 적용한다. 본문에서 Ctrl/Cmd+클릭, 입력 창의 새 탭 버튼, 링크 우클릭의 **새 탭에서 열기**로 주소를 연다. 새 탭은 opener를 분리한다. 드래그로 선택한 글의 기존 우클릭 메뉴는 유지한다.

**취소**·Esc·바깥 클릭은 입력 중인 변경을 버린다. 저장 전 본문이 바뀌면 오래된 범위에 적용하지 않는다. 추가·주소 수정·해제는 한 번에 실행 취소한다. 읽기 전용에서는 수정 도구를 비활성화한다.

웹 링크는 기존 본문 `link` 서식이다. 원본·기기 저장·계정 동기화·전체 백업·공개 판본·HTML/Markdown 교환에 들어가며 비공개 참조처럼 발행 때 감추지 않는다. 게시된 판본은 다시 게시해야 바뀐다. DB·작업 공간 형식은 바꾸지 않는다.
