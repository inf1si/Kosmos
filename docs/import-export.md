# 외부 문서 가져오기·내보내기

기준: 2026-10-01. Notion·Evernote·Obsidian 등과 **파일로 교환**한다. 외부 계정 연결·실시간 양방향 동기화는 제공하지 않는다. 원본 파일은 따로 보관한다.

## 가져오기

집필실 왼쪽 아이콘의 **문서 가져오기 · 내보내기**를 연다. 여러 파일 또는 ZIP을 선택하고 미리보기를 확인한다. 문서별로 원고·설정집·메모를 선택한 뒤 새 작품이나 기존 작품에 추가한다. 기존 문서를 덮어쓰지 않으며 가져온 문서는 비공개다. 적용 전 현재 작업을 복구 이력에 남긴다.

| 원본 | 준비·지원 범위 |
|---|---|
| Notion | 페이지 메뉴의 Export에서 Markdown & CSV 또는 HTML, 하위 페이지 포함 옵션으로 ZIP 생성. 제목·하위 경로·기본 서식·묶음 내부 링크·지원 이미지 읽기 |
| Evernote | 데스크톱 앱에서 노트 또는 노트북을 ENEX로 내보내기. 본문·제목·태그 텍스트·체크박스·PNG/JPEG/WebP 자원 읽기 |
| Obsidian·기타 | Markdown 파일과 연결된 이미지·문서를 함께 ZIP으로 묶기 |
| 일반 파일 | UTF-8 TXT, MD/Markdown, HTML/HTM, CSV. 여러 파일 동시 선택 가능 |

설정 문서로 지정한 대상에 대한 묶음 내부 상대 링크를 Kosmos 설정 링크로 바꾼다. 선택하지 않은 문서나 원고·메모를 가리키는 내부 링크는 일반 글자로 가져온다. Markdown 각주는 Kosmos 각주로 변환한다. 이미지는 문서의 **별도 참고 첨부**로 저장하고 본문에는 위치 표시를 남긴다. 다른 작품에 있는 문서와 자동으로 연결하지 않는다.

HTML의 실행 코드·스타일·삽입 객체는 제거한다. 원격 이미지 주소에 접속하지 않는다. 표는 행별 텍스트로, CSV는 항목별 제목·값으로 변환한다. Notion의 관계·수식·필터·뷰·댓글·버전 이력은 복원하지 않는다. Evernote 암호화 영역은 원본 앱에서 먼저 복호화해야 한다. PDF·오디오·SVG 등 지원하지 않는 첨부는 제외되며 미리보기 경고에 표시한다. 그 첨부는 원본 파일로 별도 보관한다.

한 번에 입력 및 압축 해제 합계 100MiB, ZIP 파일 항목 3,000개, 문서 500개, 텍스트 파일 5MiB, ENEX 100MiB(각 노트 본문 5MiB), 이미지 하나 10MiB까지다. ZIP 경로 이탈·중복 경로·손상 XML·외부 엔티티·잘못된 UTF-8을 거절한다. 앱의 전체 작업 공간 용량 제한도 적용한다. 큰 노트북은 나누어 내보낸다.

클라우드 모드는 첨부 업로드 완료 후 문서를 추가한다. 도중 실패나 동시 원고 수정이 있으면 문서 추가를 중단한다. 이미 업로드한 미참조 첨부가 남을 수 있으며 자동 삭제하지 않는다.

## 내보내기

같은 대화상자의 **내보내기**에서 작품·문서와 형식을 선택한다. **파일 만들기** 완료 후 나타나는 **파일 저장** 링크를 눌러 실제 파일을 보관한다. 선택한 초안·비공개 설정·참고 이미지도 포함할 수 있으므로 전달할 문서를 확인한다.

| 형식 | 내용·용도 |
|---|---|
| Markdown ZIP | 문서별 MD, 각주, 선택된 설정의 상대 링크, 지원 이미지, 분류 메타데이터. Obsidian 등에서 사용 |
| HTML ZIP | 문서별 HTML, 기본 서식·각주·상대 링크·이미지. Notion 가져오기 등에 사용 |
| Evernote ENEX | 선택 문서별 노트, 기본 서식·첨부·분류 태그. 각주 번호와 설명은 일반 텍스트이며 설정 링크는 글자로 전달 |

MD/HTML ZIP의 `kosmos-transfer.json`은 Kosmos로 다시 가져올 때 제목·문서 종류·부·장·분류·요약을 복원한다. 새 문서·관계 ID가 생성되며 공개 설정은 자동 활성화하지 않는다. ENEX는 같은 수준의 메타데이터·각주 관계를 복원하는 형식이 아니다.

교환 파일에는 복구 이력·공개 판본·모든 편집 속성이 들어가지 않는다. 완전한 원고 보관·이동에는 [전체 ZIP 백업](backup-restore.md)을 사용한다. 전체 백업 ZIP을 외부 문서 가져오기에 넣으면 백업 화면으로 안내한다.

외부 앱으로 실제 업로드해 전체 호환성을 검증한 상태는 아니다. 합성 Notion/ENEX 자료, MD/HTML 왕복, 첨부 바이트·각주·설정 관계는 자동 테스트로 확인했다. 실제 앱이 지원하는 기능·가져오기 용량은 해당 앱의 정책을 따른다. 공식 안내: [Notion 내보내기](https://www.notion.com/help/export-your-content), [Notion 가져오기](https://www.notion.com/help/import-data-into-notion), [Evernote ENML](https://dev.evernote.com/legacy/doc/articles/enml).
