# 디자인 가이드

기준일: 2026-10-14. 새 화면이나 기능을 추가할 때 기존 화면과 같은 색·글꼴·간격·문구를 쓰기 위한 규칙이다. 화면 시안은 작가 계정의 [디자인 캔버스](https://claude.ai/artifact/8JQvgoZDiTun4ZQ4Cp8FEW)(비공개)에, 여섯 테마의 토큰과 컴포넌트 미리보기는 [디자인 시스템](https://claude.ai/artifact/XVVsdiqKsa5D99pgd6gc1P)(비공개, main `a7ee675` 기준)에 있고, 참고 서비스 연구는 [디자인 레퍼런스](design-references.md)에 있다. 두 아티팩트는 레포 밖에 있어 다른 도구에서는 열리지 않을 수 있으며, 값이 다르면 이 문서와 CSS가 기준이다.

## 0. 새 화면을 만들기 전에 (필수)

새 기능은 **새 모양을 만들지 않고 아래 기존 부품을 조립한다.** 새 CSS는 배치(위치·크기)만 쓰고 색·모서리·글자 모양은 기존 클래스와 토큰에서 가져온다. 여기서 벗어나야 하면 먼저 이 문서에 이유와 새 패턴을 적는다. 2026-10-03 문서 그래프가 이 규칙 없이 만들어져 다른 앱처럼 보였고 다시 만들었다.

**하지 말 것**

- 탭 이름과 같은 제목 줄을 화면 안에 다시 쓰지 않는다. 탭 아래 고정 줄은 한 줄이다(주변 연결처럼 보기에 딸린 설정만 예외로 한 줄 더).
- 이미 아이콘이 있는 뜻을 다른 기호로 다시 표시하지 않는다. 예: 원고·메모·설정을 트리에서는 아이콘으로, 그래프에서는 네모·마름모·원으로 보여 주지 않는다. 한 뜻에 한 아이콘이다. 기존 아이콘이 없는 새 뜻에는 Lucide 아이콘을 새로 골라 쓰고 위 표에 더한다.
- 글자는 UI 13px, 보조 12px, 최소 11px. 굵기는 400·500·600만 쓴다. 확대·축소 화면에서도 UI 글자는 크기가 변하지 않게 한다.
- 버튼·입력칸·목록 항목에 새 테두리·바탕·모서리 규칙을 만들지 않는다.
- 아이콘과 입력칸을 한 줄로 묶는 부품(`sidebar-search`)은 `<label>`로 감싸지 않는다. 전역 `label`이 세로 배치(`flex-direction:column`)여서 아이콘이 입력칸 위로 올라간다. `div`로 감싸고 입력칸에 `aria-label`을 단다.
- 모양 토큰(`--ctl-r`·`--r-in`·`--panel-r`·`--led-r`·`--cut*`)은 사이버에만 정의되어 있다. **항상 기본값을 함께 쓴다**: `var(--ctl-r,6px)`, `var(--r-in,8px)`. 기본값이 없으면 보라·카세트에서 모서리가 사라진다.
- 색 계열 이름으로 분기하지 않는다. 카세트의 Mono 숫자·키 모양처럼 꼭 필요한 차이만 `[data-palette=…]` 규칙으로 더한다(4절).
- hex 값, 그라데이션, 새 그림자를 쓰지 않는다.

**끝내기 전에** 같은 탭 화면(플롯보드 등)과 나란히 마흔네 조합 × 1280px·360px 화면을 찍어 위 표와 다른 곳이 없는지 본다. 그다음 27절 체크리스트를 확인한다.

## 2. 원칙

1. **바탕은 무채색, 색은 적게.** 바탕과 본문은 보라 기운이 아주 살짝 도는 회색·검정(카세트는 베이지·콘솔 검정)이다. 강조색은 브랜드·버튼·링크에만 쓴다. 그라데이션과 넓은 강조색 면은 쓰지 않는다.
2. **두 보라의 역할을 나눈다.** Ultra Violet(Pantone 18-3838, #5F4B8B)은 브랜드와 주요 동작, Very Peri(Pantone 17-3938, #6667AB)는 연결이다. 섞어 쓰면 탁해 보인다.
   - Ultra Violet `--pub-brand`: ◌ 표시, "서재 둘러보기"·"작품 읽기" 버튼, 표지, 설정 분류명.
   - Very Peri `--pub-link`: 설정 링크, 각주 번호, 읽기 진행 막대, 텍스트 링크.
3. **서재는 책, 집필실은 도구.** 공개 페이지는 명조 제목·넓은 여백·가는 구분선으로 책처럼, 집필실은 작은 고딕·촘촘한 배치로 작업 도구처럼 만든다. 색 규칙은 같고 레이아웃과 글꼴로 구분한다.
4. **꾸밈말보다 사실.** 슬로건·영문 장식 제목 대신 실제 데이터(편수, 날짜, 개수)를 보여준다. [7절](#7-문구)을 따른다.
5. **마흔네 조합에서 모두 확인한다.** 새 화면은 보라·카세트·사이버·잉크·컬럼비아·나사펑크·디젤·누아르·선조 유적·스파르탄·붉은 책·실마릴리온·바벨·무한·히치하이커·트론·매트릭스·프로토스·타투인·제국·오디세이·노스트로모 × 라이트·다크 마흔네 조합에서 각각 보고, 본문 대비 4.5:1 이상을 지킨다.

## 3. 색 토큰 (공개 페이지)

공개 페이지의 색은 `src/app/globals.css`의 `--pub-*` 변수로만 쓴다. 컴포넌트나 CSS 모듈에 hex 값을 직접 쓰지 않는다. 아래 표는 기본 색 계열인 보라 값이다. 라이트 값은 `:root`, 다크 값은 `[data-theme=dark]`에 있다. 카세트 값은 [9절](#9-카세트-퓨처리즘-테마)에 있다.

| 토큰 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `--pub-paper` | #faf9fb | #131219 | 페이지 바탕 |
| `--pub-raised` | #ffffff | #1c1a24 | 목차 패널, 검색칸, 테마 버튼, 공개 페이지의 대화상자 |

## 4. 테마 (색 계열 × 밝기)

- 테마는 `<html>`의 두 속성으로 정한다. 밝기 `data-theme="light|dark"`와 색 계열 `data-palette="violet|cassette|cyber|ink|columbia|nasapunk|diesel|noir|forerunner|spartan|redbook|silmaril|babel|infinity|hitchhiker|tron|matrix|protoss|tatooine|empire|odyssey|nostromo"`이다. 둘은 따로 고르며 마흔네 조합이 모두 있다. 색 계열 목록은 `src/lib/theme.ts`의 `PALETTES`(이름은 `theme-toggle.tsx`의 `paletteOptions`) 하나에서 온다.
- `src/lib/theme.ts`의 `themeScript`가 `<head>`에서 첫 그리기 전에 실행된다. 밝기는 저장된 선택(`localStorage`의 `orbis-theme`)이 있으면 그것을, 없으면 기기 설정을 쓴다. 색 계열은 저장된 선택(`orbis-palette`)이 `cassette`·`cyber`·`ink`·`columbia`·`nasapunk`·`diesel`·`noir`·`forerunner`·`spartan`·`redbook`·`silmaril`·`babel`·`infinity`·`hitchhiker`·`tron`·`matrix`·`protoss`·`tatooine`·`empire`·`odyssey`·`nostromo` 중 하나면 그것을, 나머지는 보라를 쓴다.
- CSS는 `:root`(보라 라이트) → `[data-theme=dark]`(보라 다크) → `[data-palette=cassette]`(카세트 라이트) → `[data-palette=cassette][data-theme=dark]`(카세트 다크) 순서로 덮어쓴다. 마지막 블록은 선택자가 더 구체적이라 순서와 관계없이 이긴다.
- 공개 페이지 헤더마다 `ThemeControls`를 둔다. 왼쪽은 지금 색 계열의 아이콘 버튼 하나(이름 "테마 · 보라")이고, 누르면 `Popover`(제목 **테마**, 260px, `.palette-popover`)에 스물두 색 계열이 두 줄 격자(`.palette-picker`, 아이콘 + 이름, `aria-pressed`)로 열린다. 오른쪽은 달/해 밝기 버튼이다. 색 계열이 여덟 개라 버튼을 헤더에 늘어놓으면 360px 독서 화면 헤더가 넘쳐 팝오버로 옮겼다(2026-10-15). 다른 조작에서 바꿀 때는 `useSiteTheme()`·`useSitePalette()`를 쓴다. 독서 화면의 "읽기 설정 › 배경"과 "읽기 설정 › 테마"도 같은 값을 바꾼다.
- **고르기 버튼 모양.** 헤더 테마·밝기 버튼(`.theme-controls .theme-toggle`), 테마 팝오버 버튼(`.palette-picker button`), 집필실 `segmented`(설정 › 화면 › 색 계열 포함)는 계열마다 그 계열 주요 버튼 모양을 따르고, 선택된 버튼은 주요 버튼 색이다. 보라만 기본 둥근 상자(6px, 선택은 `--pub-tint`)다. 잉크부터 히치하이커까지는 처음에 이것이 빠져 모두 기본 상자였다(2026-10-21 고침). 새 계열을 더할 때 세 곳을 함께 정하고 [`palette-picker-shapes.mjs`](../tests/browser/palette-picker-shapes.mjs)의 목록에 넣는다. `clip-path`로 모양을 낸 계열은 `:focus-visible`에서 `clip-path:none`으로 초점 테두리를 살린다.

**새 공개 페이지를 만들 때**

1. 가장 바깥 요소에 `public-site` 클래스를 붙인다. 바탕·글자색·글꼴과 `<html>` 바탕(넘침 스크롤 영역)이 함께 적용된다.
2. 헤더에 `ThemeControls`를 넣는다. 사이트 로고는 모든 화면에서 메인(`/`)으로 연결한다. 공개 공용 헤더의 **서재**는 `/library`, **집필실**은 `/studio`로 연결한다. 독서 화면에서만 이 두 메뉴를 숨기고 작품 **설정집**·테마 선택을 남긴다. 설정집의 작품 읽기와 독서 하단 **작품 목록**을 유지한다. 기존 페이지는 `PublicHeader`(`public-site.tsx`) 또는 CSS 모듈 헤더(`page.tsx`·`privacy/page.tsx`)를 쓴다.
3. 버튼이나 단어에 딸린 작은 설정·설명은 `primitives.tsx`의 `Popover`, 화면 전체를 막아야 하는 확인·큰 작업은 `Modal`을 쓴다(8절 **떠 있는 창**). 공개 페이지가 열려 있으면 `html:has(.public-site) .popover`·`.modal` 규칙으로 테마 색을 따른다.
4. 색 계열마다 모양이 달라야 하면 3절의 모양 토큰을 쓰고, 그래도 부족할 때만 `[data-palette=cassette] .클래스` 규칙을 `globals.css`의 카세트 줄에 추가한다. CSS 모듈에서는 `:global([data-palette=cassette]) .클래스`로 쓴다.

**색 계열을 하나 더 추가할 때**

1. `globals.css`에 `[data-palette=<이름>]`(라이트)과 `[data-palette=<이름>][data-theme=dark]`(다크) 블록을 만들고 `--pub-*` 전체 값과 모양 토큰을 정의한다. 일부만 정의하면 보라 값이 섞인다.
2. `SitePalette` 타입, `preferredPalette`, `themeScript`의 허용 값에 이름을 추가하고 `tests/theme.test.ts`를 갱신한다.
3. `theme-toggle.tsx`의 `paletteOptions`에 이름을, `paletteIcons`에 Lucide 아이콘을 추가한다. 헤더 팝오버·독서 설정 "테마"·설정 → 화면이 모두 이 목록을 쓴다.
4. 네 화면(서재·독서·설정집·홈)을 라이트·다크와 360px 폭에서 확인하고 이 문서, [사용 안내](user-guide.md), [변경 기록](../CHANGELOG.md)을 고친다.

사이트 웹폰트는 `src/app/layout.tsx`에서 Google Fonts 한 줄로 불러온다(Gowun Batang, Chakra Petch, IBM Plex Mono, IBM Plex Sans KR, Michroma, Oxanium, Saira Semi Condensed, Cinzel, Marcellus SC, Fredoka, Jua, Shrikhand, Orbitron, Share Tech Mono, Nanum Gothic Coding, M PLUS 1 Code). 히치하이커는 `--pub-title`에 Jua를, 표지 DON'T PANIC에 Shrikhand를 쓴다. 매트릭스는 `--pub-title`·분류 글자(`--pub-code`)에 Nanum Gothic Coding을, 코드비 가타카나(`--pub-glyph`)에 M PLUS 1 Code를 쓴다. 제목은 `--pub-serif`를 직접 쓰지 않고 `--pub-title`을 쓴다(3절 모양 토큰).

작가가 선택하는 원고 글꼴은 별도다. 명조·고딕·코딩·손글씨·기기 글꼴 등 20가지를 제공한다([목록과 크기 범위](editor-tools.md#글꼴크기)). 크기는 10~72px에서 0.5px 단위로 직접 입력한다. `manuscript-fonts.ts`가 웹폰트를 사이트에서 직접 제공하며 preload하지 않는다. Google Fonts 글꼴은 Next Font로, Google Fonts에 없는 마루부리·나눔바른고딕·프리텐다드·원티드 산스는 npm 글꼴 패키지의 CSS를 불러온다. 원고 글꼴을 더할 때는 상업적 이용이 가능한 무료 라이선스(OFL 등)만 쓰고, 외부 CDN 대신 이 두 방식 중 하나로 사이트에서 제공한다. 선택한 글꼴만 내려받으며 글자 범위로 나뉜 글꼴은 필요한 범위만 로드한다. `--manuscript-font`는 원고 본문에만 적용한다. 글꼴·크기는 현재 브라우저에 저장하고 문서·분할 창이 바뀌어도 유지한다. 이 작가 보기 설정은 공개 페이지·문서의 서식 데이터·내보내기에 영향을 주지 않는다. 독서 화면은 같은 글꼴 목록과 웹폰트를 사용하되 `--reading-font`에 독자가 고른 family를 넣어 본문에만 적용한다. 읽기 설정은 독자의 브라우저에 별도로 저장한다.

## 6. 레이아웃·모양 (공개 페이지)

- 헤더 77px, 좌우 여백 `clamp(24px, 7vw, 110px)`. 왼쪽 ◌ + 사이트 이름, 오른쪽 메뉴와 `ThemeControls`. 700px 이하에서는 높이가 자동(최소 65px)이고, 폭이 모자라면 메뉴가 둘째 줄 오른쪽으로 내려간다. 메뉴 글자와 사이트 이름은 줄바꿈하지 않는다.
- 서재 최대 폭 1190px. 작품 항목은 표지 156px · 정보 · 본문 미리보기 300px의 세 열, 간격 48px, 위에 `--pub-rule` 선. 700px 이하에서 표지 96px·정보 두 열, 미리보기는 아래로. 본문 미리보기는 첫 비어 있지 않은 문단의 줄바꿈을 공백으로 이어 데스크톱·모바일 공통 16px·줄간격 1.9로 최대 4줄만 표시하고 넘친 부분은 말줄임표로 줄인다. 공백 없는 긴 글도 폭 안에서 줄바꿈하며 짧은 문단의 높이는 늘리지 않는다. 모바일 글자 확대 시에도 네 줄이 온전히 보이도록 미리보기에는 별도 `max-height`를 두지 않는다.
- 공개 서재의 **정렬**은 수록 작품 제목 아래, 목록 위 오른쪽에 둔다. 라벨과 기본 select를 한 줄에 두며 전역 `label` 세로 배치를 `flex-direction:row`로 덮는다. 공개 토큰(14px, `var(--pub-ctl-r,6px)`, `--pub-brand` 포커스 외곽선)을 쓰고 새 토큰은 없다.
- 독서 본문 폭은 독자 선택 580·680·780px. 상단 52px 막대(← 서재·목차·작품명·읽기 설정)는 화면 위에 붙어 있다. 막대는 폭이 같은 `minmax(0,1fr)` 세 칸이고 왼쪽에 **← 서재** 링크·목차, 가운데 작품명, 오른쪽 읽기 설정을 둔다. 작품명은 큰 제목과 같은 화면 가운데 선에 놓이고 길면 한 줄 말줄임한다. 700px 이하에서는 목차·읽기 설정의 글자를 숨겨 32px 아이콘 버튼으로 표시하되 접근성 이름과 native title을 유지한다. **← 서재**는 글자와 ArrowLeft를 계속 표시하며 링크 모양·호버·색 계열별 테두리는 같은 막대 버튼 규칙을 따른다. 새 줄·색·모양 토큰은 없다.
- 가운데 정렬 글자에 글자 간격(`letter-spacing`)을 주면 마지막 글자 뒤에도 간격이 붙어 왼쪽으로 치우친다. 같은 값만큼 `padding-left`를 준다(독서 제목 위 분류 글자).
- 카드로 감싸지 않고 가는 선으로 구분한다. 그림자는 떠 있는 요소(각주 미리보기, 목차)에만 쓴다.
- 모서리: 태그 3px, 버튼 6px, 테마 버튼 8px, 색 계열 고르기 팝오버 안 버튼 6px(다른 계열은 4절 **고르기 버튼 모양**), 미리보기·목차 패널 10px(카세트 6px).
- 주요 버튼(`.book-read`, 홈 `.primaryLink`)은 화면당 하나, `--pub-brand` 바탕. 보조 버튼(`.book-wiki`)은 `--pub-line` 테두리.
- 선택된 항목은 `--pub-tint` 바탕 + `--pub-tint-ink` 글자.
- 작품 이미지가 없으므로 `BookCover`가 제목·"ORBIS TERTIUS"·◌ 궤도 점선으로 글자 표지를 만든다. 표지는 장식이라 탭 순서에서 빠진다(제목 링크가 같은 곳으로 간다). 표지 제목은 공백 없는 긴 단어도 폭 안에서 줄바꿈하며 데스크톱 4줄·700px 이하 3줄(디젤·누아르는 마름모 때문에 두 줄)을 넘으면 말줄임한다. 옆 작품명은 전체 제목을 유지하며 공백 없는 제목도 폭 안에서 줄바꿈한다.
- 아이콘은 Lucide(lucide-react)이고 헤더·막대에서 16–17px이다. ◌는 아이콘이 아니라 글자다.
- 파비콘(`public/favicon.svg`)은 Ultra Violet 둥근 사각형(모서리 8/32) 위에 ◌ 궤도 점 12개(#efeaf9)와 Very Peri 행성 하나(#a3a6ee)다. 16px에서도 궤도와 행성이 읽히도록 점을 굵게 두었고, 색 계열·밝기를 따르지 않는다.
- 브레이크포인트는 700px 하나다. 360px 폭에서 가로 스크롤이 생기지 않아야 한다.

## 7. 문구

조작법·저장 위치·동기화·백업 설명을 화면에 상시 나열하지 않는다. 빈 섹션에는 추가·이동을 권하는 문장을 붙이지 않고, 목록의 빈 상태는 “노트가 없습니다”처럼 사실만 쓴다. AI 시작 화면에는 질문 예시 버튼만 두고 인사말·질문을 권하는 문단·예시 요청 전문을 나열하지 않는다. 버튼 이름·아이콘 툴팁·현재 선택·변경된 결과로 설명하고 상세 조작법은 사용자 안내에 둔다. 실패·미전송·충돌·공개 범위처럼 사용자의 판단이 필요한 정보는 표시한다. 덮어쓰기 전에 현재 상태를 남기는지, 외부 앱에서 파일을 받는 방법처럼 화면만 보고 알 수 없는 준비 단계는 한 줄로 남긴다. 저장 위치가 달라 생기는 제약은 설명 문단이나 탭으로 나누지 말고 동작을 고쳐 없앤다(예: 복구 이력은 브라우저·서버 이력을 한 목록으로 보여준다). 문서 정리의 상시 도움말·성공 문단은 제거하며 오류와 정리 되돌리기는 유지한다.

서식 도구는 기존 한 줄 도구 모음의 문자·문단·표·특수문자·목록·검색 팝오버와 크기 입력칸 옆 크기 목록으로 제공한다. 고르기 항목(크기 목록의 숫자, 목록 모양 버튼)은 눌린 상태를 `--sel`·`--sel-ink`로 보여주고 목록 모양 버튼은 실제 표시(•, 가. 등)를 `--link` 색으로 앞에 붙인다. 팝오버끼리는 버튼 한 번으로 바로 바뀌어야 하며, 닫힐 때 원고로 초점을 돌리는 처리가 다음 팝오버를 닫지 않게 한다(`Popover`의 `onReturnFocus`). 원고의 각주 표시 미리보기는 설정 링크 미리보기 카드(`wiki-preview`)를 그대로 쓴다. 각주 카드는 포털 팝오버로 표시 옆에 붙이고 화면 가장자리에서 위치를 조정한다. **각주 수정**은 같은 카드에 기존 textarea와 **취소·각주 저장** 버튼을 보여준다. 편집 중에는 포인터가 벗어나도 유지하며 읽기 전용에서는 수정 동작을 숨긴다. UI 13/12px·기존 버튼 규격을 유지한다. 특수문자 선택 글리프만 식별을 위해 16px로 표시한다. 셀 경계·열 너비 손잡이·선택 셀과 검색 강조는 본문 편집에 필요한 패턴이며 기존 선·선택·포커스 토큰을 쓴다. 새 바탕색·모양 토큰·고정 막대는 만들지 않는다.

- **슬로건을 쓰지 않는다.** "쓰여진 시간들.", "소설과 그 곁의 세계를 모아둔 서재."처럼 어느 사이트에 붙여도 되는 시적 소개는 지웠다. 홈페이지는 사이트 이름·서재/집필실 링크·테마 선택으로 구성하며 바닥글에는 사이트 이름과 오른쪽 **About Me** 링크를 둔다.
- **영문 장식 제목을 쓰지 않는다.** FICTION & WORLDS, WORLD BIBLE, DATA USE를 지웠다. 예외는 사용자가 지정한 둘이다. 자기소개 이름: 홈 바닥글 링크 **About Me**, `/about` 페이지·탭 제목 **Who I Am**. 설정 구역과 안내 문구는 한국어 **자기소개**를 쓴다. 히치하이커 테마 서재 표지의 **DON'T PANIC**은 다른 예외로, 사용자가 요청했다(원작 안내서 표지 글자, 19절).
- **실제 데이터로 채운다.** "수록 작품 1편 · 마지막 공개 2026. 10. 2.", "먼 별의 항구 설정집 · 공개 설정 2개".
- **이름:** 공개 목록은 **서재**(도서관 아님), 쓰는 곳은 **집필실**, 목록 제목은 **수록 작품**. 사이트 이름 Orbis Tertius가 보르헤스의 가상 백과사전에서 왔기 때문에 "수록"을 쓴다.
- **문장은 합니다체.** 결과는 한 문장으로 끝낸다: "백업 파일을 만들었습니다." 다음 조작은 버튼으로 표시한다. 오류는 무엇이 실패했고 어떻게 하는지: "기기 저장 실패: 저장 공간과 브라우저 설정을 확인하세요."
- **버튼은 짧은 명사·동사구, 마침표 없음:** 작품 읽기, 설정집, 게시 준비, 백업 내려받기.
- **구분은 가운뎃점:** "장편 · 원고 3 · 684자", "제1부 · 남겨진 시간". 화살표(↗ →)는 글자로 쓰고 `aria-hidden`을 붙인다.
- 이중 피동(쓰여진)을 쓰지 않는다. 느낌표·이모지를 쓰지 않는다.

대비(WCAG 2): `--muted`는 가장 진한 바탕인 `--hover` 위에서도 4.9:1(라이트·다크), 원고는 14.6:1·12.1:1, 선택 글자는 7.6:1·8.4:1, 주요 버튼 글자는 7.3:1·6.9:1이다. 글자에는 `--faint`를 쓰지 않는다(비활성 아이콘 전용).

**틀.** 바닥 위에 사이드바(264px, 1600px 이상 280px)와 편집 패널을 모서리 10px, 사이 8px로 띄운다. 사이의 8px 틈이 사이드바 폭 손잡이(`.sidebar-resizer`)이며 끌어서 200~480px(창 폭의 40%까지)로 바꾸고 두 번 누르면 기본 폭이다. 120px 아래까지 끌면 사이드바를 흐리게(`[data-collapsing]`, 불투명도 .45) 보이고 놓으면 닫는다. 폭은 기기 설정 `sidebarWidth`로 노트 사이드바와 함께 쓴다. 900px 이하에서 사이드바는 끈 폭과 손잡이 없이 편집 패널 위에 겹쳐 뜨고 문서를 열면 닫힌다. 내부 닫기 버튼·Esc·배경 클릭으로 닫으며 키보드 포커스를 안에 유지하고 닫으면 열기 버튼으로 돌린다. 700px 이하에서는 바닥 여백과 패널 모서리를 없앤다.

**사이드바.** 위에서부터 ◌ Orbis Tertius(홈 링크), 작품 카드(표지·작품명·형식·원고 수·글자 수, 누르면 작품 전환·새 작품·작품 정보 메뉴), 도구(집필실 홈·검색 Ctrl K·플롯보드·문서 그래프·휴지통·설정), 문서 트리(기본 원고·설정집·메모 · 리서치와 사용자 섹션 → 폴더·문서·하위 항목, 원고 상태 점·종류 아이콘), 맨 아래 한 줄에 저장 상태·공개 서재·라이트/다크. 새 도구는 `nav-item` 줄로 추가한다. 가끔 쓰는 관리 창(템플릿·백업과 복구·가져오기 · 내보내기·노트 가져오기)과 색 계열은 도구 줄에 다시 넣지 말고 **설정**의 해당 구역에 둔다. 같은 창을 여는 세 번째 입구(예: 바닥의 작품 정보 아이콘)도 만들지 않는다.

**편집 패널.** 44px 탭 줄(사이드바·뒤로·앞으로·문서 탭·옆에 열기·참고 패널·더 보기·게시 준비)과 40px 서식 도구(오른쪽 끝에 글자 수와 AI 대화)만 원고 위에 고정한다(84px). 가려진 서식 도구가 있으면 양끝 이동 화살표를 보여준다. 분할 창에서는 도구가 줄바꿈하고 높이가 줄 수만큼 늘어난다. 카세트·사이버의 46px 도구 높이도 분할 창에서는 최소 높이로만 쓴다(고정하면 줄바꿈한 줄이 원고를 덮는다). 드물게 쓰는 동작(집중 모드, 순서 옮기기, 복구 지점, 작품 정보)은 **더 보기** 메뉴에 둔다. 원고 위에 고정 막대를 더 만들지 않는다.

**문서 머리.** 분류 글자(부·장 또는 설정 분류) 13px, 제목 입력칸 32px 600, 그 아래 칩(높이 28px, 모서리 6px): 상태(선택 상자), 시점 인물(같은 이름의 인물 설정이 있으면 `--soft` 칩이고 누르면 옆에 열림), 작중 시간, 연결 설정 수, 첨부 수, 속성. 설정 문서는 공개 상태와 등장 수 칩을 둔다. **속성**은 칩 아래에 입력 폼을 펼친다. 새 문서 속성은 이 폼에 넣고, 값이 있으면 칩으로 보여준다.

**문서 통계.** 기존 숫자 자리를 화살표가 있는 버튼으로 바꿔 그 아래 380px 팝오버를 연다(오른쪽 끝 정렬). 본문 선택 시 도구 모음 숫자를 선택 영역 기준으로 바꾸고 ‘선택’을 표시한다. 해제 시 문서 전체로 복귀한다. 표시 기준 선택과 현재 문서·선택 영역·전체 원고 비교 표, 짧은 합계 안내를 두고 세부 집계 규칙은 접힌 **집계 기준**에 넣는다. 표시 단위가 바뀌어도 카세트·사이버의 다섯 자리 카운터 모양은 유지한다. 분할 창에도 각 문서 버튼을 제공한다. `document-statistics.module.css`는 기본 토큰·모양 토큰만 사용하고 키보드 초점은 카운터 안쪽에도 표시한다. 모바일은 팝오버 내부 스크롤과 줄바꿈을 사용한다. [집계·저장 기준](document-statistics.md).

**원고지 보기.** 문서 통계 창 아래 `.button` **원고지로 보기**(Grid3x3)와 **더 보기 › 원고지 보기**가 같은 `Modal`(`modal-wide`, 720px)을 연다. 머리 아래 12px `--muted` 한 줄(문서 제목 · N매), 그 아래 매마다 한 장: 20칸 × 10줄, 줄 사이 0.3칸 틈, 칸 크기 `min(30px, (100vw - 68px) / 20.6)`, 글자 0.64칸 원고 글꼴, 마침표·쉼표는 칸 왼쪽 아래, 오른쪽 아래 11px 매 번호. 칸 선은 지역 변수 `--paper-line`(`--brand` 42%와 `--panel` 혼합, 잉크는 `--pub-kicker` 45%)이라 마흔네 조합 모두 따로 정하지 않는다. 700px 이하에서는 창 안쪽 여백을 20px 14px로 줄여 360px에서도 가로로 넘치지 않는다. 쓰는 화면에는 칸을 그리지 않는다(11절 원고지 줄).

**선택 입력.** 설정의 분류·원고의 시점 인물은 직접 입력 가능한 combobox다. 화살표를 누르면 이미 값이 채워져 있어도 작품의 기존 항목 전체를 펼친다. 입력 중에는 항목을 거르고 위·아래·Enter로 선택, Esc·바깥 클릭으로 닫는다. 새 값도 그대로 저장한다. 목록은 `--pop`·`--line`·`--sel`, 모양은 `--ctl-r`·`--r-in`을 쓴다.

**참고 패널.** 탭은 연결·첨부·노트·AI 대화 순이다. 이 작품에 연결된 개인 노트는 **노트** 탭에 있다(연결 탭에 두지 않는다). 연결·첨부·노트는 300px, AI 대화는 360px(1200px 이하 340px)이다. 900px보다 넓으면 원고 옆에 배치한다. 900px 이하에서는 배경을 가리고 편집 창 위에 겹치며 닫기·Esc·포커스 관리를 지원한다. 700px 이하에서는 편집 창 너비를 채운다. 원고와 나란히 봐야 하는 자료는 분할 편집으로 연다.

**AI 대화.** 패널 위에 현재 문서 제목(15px 600, 넘치면 말줄임. 패널 머리·탭의 'AI 대화'를 다시 쓰지 않는다)·제공자·보낼 자료, 가운데 독립 스크롤 대화 기록, 아래 질문 입력과 전송 버튼을 둔다. 빈 대화에는 '무엇을 도와드릴까요?'와 퇴고·설정 점검·장면 구상·요약·SF 개연성·자료 질문 시작 버튼을 제안한다. 답변은 자동 적용하지 않고 원문·수정안·이유를 비교하는 카드에서 선택 적용한다. 대화는 문서별 작업 데이터로 저장하며 전체 백업에 포함한다. 색과 모양은 기본 토큰만 사용한다.

**AI 설정.** 대화 패널 제목 옆 설정 아이콘과 미연결 안내 버튼에서 기존 Modal을 연다. 제공자·모델 ID, 암호 입력 형태의 API 키, 연결 상태·30일 보관 안내를 한 구역에 두고 시스템 프롬프트를 다음 구역에 둔다. 저장한 키는 다시 표시하지 않는다. 연결 저장과 프리셋 저장·적용은 각 구역에서 동작한다. 세 번째 구역은 **내 스킬**(편집할 스킬 select·이름·설명·요청·저장/삭제)이다. 프리셋 선택·이름·지침·사본·기본값 재설정, 미저장 전환·삭제 확인과 오래된 편집 안내를 제공한다. 대화창에는 제공자 다음에 빠른 프리셋 선택을 둔다. 선택과 저장 상태를 구분한다. 모바일은 제공자·모델을 한 열로 배치하고 대화상자 내부에서 스크롤한다. 색은 기본 토큰, 완료·오류 안내는 success·danger 토큰을 쓴다.

**커서 명령.** 집필실·노트 문단·제목의 모든 커서 위치(목록·표 셀 포함)에서 `/`의 입력 메뉴와 선택 글 우클릭 메뉴는 `.menu`·`.menu-item`·기존 Lucide 아이콘을 쓴다. 입력 중 본문 초점을 유지하고 활성 명령은 `--hover`·`--ink`로 표시한다. Alt+Enter의 AI 질문은 커서에 붙는 400px `.popover`(360px에서는 화면 양쪽 12px)이며 기존 `chat-heading`·`chat-context`·`chat-composer`와 `popover-actions`를 공유한다. 대상·제공자/프리셋·질문·답변·직접 적용/취소를 담고 창 내부에서 스크롤한다. 대상 요약(`chat-context`)과 연결 안내는 창 안 다른 칸과 같은 폭(바깥 여백 0)이고 입력칸 묶음 바탕은 창과 같다. 적용/취소 `popover-actions`는 스크롤해도 창 아래에 붙어 있어 360px에서도 보인다. 집필실 원고·설정집·메모·양쪽 분할 편집도 같은 명령/AI 패턴을 쓴다. 링크는 현재 공간의 설정/노트 대상으로 표시하고 지원하는 서식만 메뉴에 둔다. 우클릭 메뉴의 AI 항목은 뜻마다 아이콘이 다르다(요약 ListCollapse, 문장 다듬기 PenLine, 아이디어 확장 Lightbulb, 질문하기 MessageCircleQuestionMark). `/` 메뉴의 AI 질문은 Sparkles다.

**내 스킬.** 사용자가 저장한 AI 요청이며 아이콘은 WandSparkles 하나다. `/` 메뉴에서는 기본 명령 뒤에 `note-command-caption` 소제목 **내 스킬** 아래 같은 `.menu-item`으로 두고, 설명은 항목 `title`과 검색어로만 쓴다(줄을 늘리지 않는다). 메뉴 맨 끝은 **스킬 관리**(Settings2)이며 AI 설정 `Modal`을 내 스킬 구역에 초점을 둔 채 연다. 우클릭 메뉴에서는 기본 AI 항목 뒤 `.menu-separator`로 나눈다. AI 질문 창의 **스킬** select는 제공자·프리셋 아래 한 줄 전체 폭이며 직접 질문·기본·내 스킬 묶음을 담는다. 관리 구역은 프리셋 구역과 같은 `ai-preset-picker`·입력칸·`ai-prompt-confirm`·`ai-settings-actions`를 쓰고 새 클래스는 배치(`note-ai-request`의 전체 폭)뿐이다.

**설정.** 집필실·노트 사이드바 도구 줄의 **설정**(Settings) `nav-item`이 `Modal`(`modal-wide`, 높이 680px 이하 고정)을 연다. 왼쪽 168px 구역 목록은 사이드바와 같은 `nav-item`(`aria-pressed`)이고 오른쪽 내용만 스크롤한다. 스크롤 칸은 밖으로 나간 그림을 자르므로 `.settings-body`는 위·왼쪽 3px, 오른쪽 4px 안쪽 여백을 두어 입력칸 초점 테두리(2px + 간격 1px)가 잘리지 않게 한다. 구역 제목·저장 설명은 반복하지 않고 맨 위 오른쪽에 **기본값으로** `.button`만 둔다. 항목은 `settings-row` 한 줄: 왼쪽 이름 13px `--ink`와 기본값 12px `--muted`, 오른쪽 조작. 고르는 값이 5개 이하면 `segmented`, 많으면 `select`(180px), 켬/끔도 `segmented`다. 묶음 소제목은 12px 600 `--muted`이며 AI 구역 안의 AI 설정 소제목도 같은 크기로 맞춘다. 원고 표시 미리보기는 `--side` 바탕·`--line` 테두리·`var(--r-in,8px)` 상자 안의 실제 `.manuscript`다. 단축키는 `dl`과 기존 `kbd`(`--line` 테두리, `var(--ctl-r,4px)`)다. 기기 값은 고르는 즉시 적용하므로 저장 버튼을 두지 않는다. AI 구역의 **연결 저장**과 자기소개의 **공개/갱신**은 기존 주요 버튼 규격을 쓴다. 700px 이하에서는 구역 목록이 위쪽 가로 스크롤 줄이 되고(선택 구역이 보이게 스크롤) 조작이 이름 아래 전체 폭으로 내려간다. 새 CSS는 `settings.css`의 배치뿐이다. [설정 항목·저장](settings.md).

**설정 하위 창의 돌아가기.** 설정에서 연 관리 창은 기존 `modal-heading`의 제목 왼쪽에 닫기(X)와 같은 ArrowLeft `.icon-button`(접근성 이름 **설정으로 돌아가기**, native title)을 둔다. 제목과 화살표는 8px 간격이며 닫기(X)는 오른쪽을 유지한다. 창 제목(`.modal-heading h2`)은 `word-break:keep-all`이라 360px에서 줄이 바뀌어도 낱말 중간에서 끊기지 않는다. 직접 연 휴지통·트리 메뉴의 템플릿에는 넣지 않는다. 돌아가면 저장 · 백업 구역의 호출 버튼에 초점을 돌리고, 이전 창의 늦은 초점 복귀가 새 창의 초점을 빼앗지 않게 한다. 처리 중과 중첩 확인창이 열려 있으면 비활성이다. 초기 초점의 툴팁이 Esc를 먼저 소비하지 않도록 제목 줄의 화살표는 닫기 버튼과 같은 native title을 쓴다. 새 색·모양·글자 토큰이나 안내 문단은 없다.

**자기소개.** 설정의 마지막 구역(User 아이콘)이다. 저장·공개 방식의 상시 설명 없이 **이름 · 필명** 입력칸과 **소개 · 마크다운** textarea, 공개 상태 한 줄(12px `--muted`), `.settings-links`의 **자기소개 페이지 보기**·**공개 취소**(`.button danger`)·**자기소개 공개/공개 내용 갱신**(`.button primary`)을 둔다. 상태 줄은 공개 날짜를 `· 2026. 10. 9. 공개`처럼 가운뎃점 뒤에 붙인다. **공개 취소**는 AI 프리셋 삭제와 같은 `ai-prompt-confirm` 확인 상자를 버튼 줄 아래에 열고(설정 내용 칸 안으로 스크롤, 초점은 **그대로 두기**), 상자의 **공개 취소**로 실행한다. 초안은 자동 저장하고 공개·갱신·취소만 버튼으로 하며 **기본값으로**는 두지 않는다. 공개 화면 `/about`은 `public-info.module.css`의 헤더·document·footer와 `--pub-*` 토큰을 그대로 쓰고, 입력한 이름(h2)과 소개 마크다운(문단·목록·인용·구분선·코드, `.bio`)을 보여주며 목록 기호는 독서 화면처럼 disc/circle/decimal, 인용은 `--pub-line` 왼쪽 선과 `--pub-muted`, 코드 블록은 `--pub-tint` 바탕이다. 이미지·제목·표는 막아 페이지 h1·h2 위계를 지키며 등록 전에는 사실만 안내한다. 새 색·모양·글자 크기 토큰은 없다. [자기소개](author-profile.md).

**설정 링크 미리보기.** 링크에 마우스를 올리면 300px 카드(분류, 제목, 집필용 본문 첫 문단 110자, 옆에 열기, 등장 수)를 링크 아래에 띄운다. Ctrl+클릭도 옆에 연다.

**플롯보드.** 탭으로 열린다. 부와 장(기본)·진행 상태·작중 시간 보기를 전환한다. 열 320px(`--side`), 카드는 상태 점·글자 수·제목·요약·칩(시점 인물, 연결 설정 최대 2개, 작중 시간). 부 보기에서만 **이 부에 문서 추가**와 **부 추가**를 둔다. 같은 부의 원고 문서는 원고 순서가 떨어져 있어도 한 열에 모은다(사이드바의 정리 폴더·부모 문서와는 독립적이다).

**집필실 홈.** 집필실의 첫 화면이며 노트 홈과 같은 부품을 쓴다. 사이드바 도구 줄 맨 위 `nav-item`(House)과 탭(House, **집필실 홈**)으로 들어가고, 작품을 바꿔도 홈 탭은 남는다. 위쪽은 `board-bar` 한 줄(전체 작품·원고·글자 수 `span`, `.button` 새 작품)이고, 아래는 12px 600 `--muted` 소제목과 `reference-card` 격자(`notes-home-body`·`notes-home-grid`): 이어 쓰기 카드 하나, 책장별 작품 카드(Book, 사이드바에 열린 작품은 `aria-current`로 `--sel` 바탕·`--sel-ink` 제목), 최근 수정 문서 8개(문서 종류 아이콘). 카드 둘째 줄은 데이터만 쓴다(작품 · 위치 · 날짜). 홈에서는 옆에 열기·참고 패널을 끄고 게시 준비가 주요 버튼으로 남는다. 게시 중인 작품 카드는 둘째 줄에 **게시 중**을 더한다. 작품 카드 우클릭(터치 길게 누르기, Shift+F10)은 `.menu`로 열기(BookOpen)·작품 정보 편집(Settings2)·책장 이동(LibraryBig)·게시 철회(GlobeOff, 게시 중일 때만)·구분선·휴지통으로 이동(Trash2, 마지막 작품이면 비활성과 이유 `title`)을 띄운다.

**작품 정보.** 사이드바 작품 메뉴·사이드바 아래 Settings2·더 보기·작품 카드 메뉴가 같은 `Modal`을 연다. `form-grid`에 작품명·형식 select·책장 select·부제·작품 소개를 두고, 아래 `modal-actions` 줄의 첫 줄은 공개 상태 12px `--muted` 한 줄(게시 중 · 날짜 판본 / 게시하지 않음), 다음 줄 오른쪽에 `.button` 게시 철회(게시 중일 때)·휴지통으로 이동이다. 두 동작은 각각 확인 `Modal`(질문 한 줄, 결과·보존 범위 한 줄, 취소 `.button`·실행 `.button.danger`)을 겹쳐 연다. 게시 철회 결과는 작품 정보 안 `field-help` 한 줄로 알린다.

**떠 있는 창.** 화면 전체를 회색으로 덮는 `Modal`은 꼭 필요할 때만 쓴다. 고르는 기준:

| 종류 | 쓰는 곳 | 구성 |
|---|---|---|
| 메뉴 (`.menu`, Radix DropdownMenu·ContextMenu) | 문서 트리 `…`·우클릭, 집필실 홈 작품 카드 우클릭 | 항목 32px, 아이콘 15px, 구분선 `.menu-separator`. 위·아래·Enter·Esc. 우클릭 메뉴는 누른 자리에 열리고 좌우로만 뒤집히므로 700px 이하 작품 카드 메뉴(`.work-context-menu`)는 최소 폭 190px 대신 내용 폭을 써서 가운데를 눌러도 화면 안에 들어간다 |
| 팝오버 (`Popover`) | 문서 트리 만들기·이동, 문서 통계, 각주 추가, 설정집 연결, AI 참고 자료, 읽기 설정, 독자 설정 카드, 빠른 메모, 노트 필터, 책장 만들기·이름 변경·작품 이동 | 누른 버튼·행·선택한 글자 옆에 붙는다. 제목 14px 600, 설명 12px, 폭 280~380px(화면 폭 − 24px 이하), 높이 70dvh 이하 내부 스크롤. 바깥 클릭·Esc로 닫고 초점을 원래 자리로 돌린다 |
| 행 안 편집 | 폴더·섹션 이름 변경 | 행 높이를 유지하는 입력칸. Enter·바깥 클릭 저장, Esc 취소 |
| 대화상자 (`Modal`) | 원고 충돌, 새 대화 확인, 백업과 복구(브라우저·서버 이력을 한 `revision-list`로 합침), 공개 판본, 가져오기·내보내기, AI 설정, 설정, 새 작품, 작품 정보, 게시 철회·작품 휴지통 이동 확인, 템플릿, 서재 순서 편집, 폴더 전체 삭제 확인, 책장 삭제 확인 | 결정을 강제하거나 내용이 많아 집중해야 하는 작업 |

메뉴 항목이 팝오버를 열면 그 메뉴 Content의 `onCloseAutoFocus`를 막는다(문서 트리 `menuClose`, 집필실 홈 책장 `…`·작품 카드 우클릭의 `keepMenuFocus`). Radix 메뉴는 닫힌 뒤 타이머로 메뉴 버튼에 초점을 돌리는데, 이 복귀가 팝오버가 열린 뒤에 닿으면 팝오버가 바깥 초점으로 보고 바로 닫힌다. 빠른 클릭에서는 순서가 맞아 드러나지 않으므로 검사에서 초점 복귀를 늦춰 확인한다.

팝오버와 메뉴는 `--pop`·`--pop-line`·`--shadow`, 모서리 `--r-in`(카세트 6px), 사이버는 배경 흐림을 쓴다. 클래스는 `globals.css` 앞부분에 있다.

노트 메타 항목처럼 단순한 목록·폼은 바깥 `.popover`의 스크롤과 14px/16px 여백을 쓴다. 안쪽 목록에 여백 없는 스크롤 영역을 겹치면 입력·체크박스의 바깥 초점 테두리가 잘린다. 긴 레이블의 체크박스는 `flex-shrink:0`으로 크기를 유지하고 제목만 줄바꿈한다. 기존 `--focus` 강조를 유지하고, 실제 포커스/텍스트 선택·목록 끝으로 이동했을 때도 테두리가 온전히 보이는지 확인한다.

**글꼴.** UI는 `--sans` 13px, 원고는 `--serif` 18px / 2, 폭 680px. 서식 도구에서 원고 표시 글꼴 20종·크기를 바꾸며 본문 서식은 별도 저장한다. 줄간격·첫 줄 들여쓰기·문단 간격·본문 폭은 **설정 › 원고 표시**의 기기 보기 설정이며 `.manuscript` 규칙이 `--manuscript-line`·`--manuscript-indent`·`--manuscript-gap`·`--manuscript-width`를 기본값과 함께 읽는다(`var(--manuscript-line,2)`).

**문서 트리.** `DocumentTree`와 CSS module을 사용한다. 섹션의 `+`는 문서 생성, `…`는 폴더·이름·순서, 문서/폴더 `…`는 하위 문서·폴더·이동 동작이다. 같은 메뉴를 행 우클릭(터치는 길게 누르기)으로도 연다. 메뉴는 행 옆 `.menu`, 만들기·이동 폼은 행 오른쪽(700px 미만은 아래) 팝오버, 폴더·섹션 이름 변경은 행 안 입력칸(Enter 저장, Esc 취소)이다. 접기 화살표와 문서 열기를 나눈다. 왼쪽 손잡이에서 이동을 시작하고 위/아래 경계선은 형제 순서, 행 가운데 윤곽은 하위 위치다. 이동 팝오버에서도 같은 이동을 지원하며 자기 자신·자식으로의 이동은 거절한다.

문서의 **휴지통으로 이동**은 작품에 문서가 하나여도 활성이다. 마지막 문서일 때 `title`로 **빈 원고 하나를 남깁니다**를 표시한다. 읽기 전용·저장 중에는 기존처럼 잠그며 확인창이나 새 CSS를 추가하지 않는다. 이동 후 폴더 밖 원고 섹션의 빈 **새 문서**를 열고 원래 폴더는 유지한다.

새 빈 작품의 첫 폴더는 **본문**, 새 원고의 **부 · 장 (발행 구분)**은 빈 값이며 입력칸의 placeholder는 **선택 사항**이다. 내용이 있는 폴더 메뉴의 **폴더 전체 삭제**는 Trash2와 구분선을 쓰고 집필실·노트가 같은 `Modal`을 공유한다. 질문 한 줄·**폴더 구조와 하위 문서/노트 n개를 휴지통에 보관합니다** `field-help` 한 줄(모든 작품 문서 삭제 시 빈 원고 안내), `modal-actions`의 취소 `.button`·삭제 `.button.danger`를 쓴다. 질문의 폴더명은 앞 40자로 줄이고 공백 없는 이름도 창 안에서 줄바꿈한다. 저장 중 버튼/닫기를 잠그고 실패는 창 안 `error-message`로 표시한다. 새 색·모양·CSS 패턴은 추가하지 않는다.

트리 바탕·선·선택·신호는 `--side`, `--line`, `--soft`, `--brand`, `--danger` 등 기존 기본 토큰을 쓴다. 글자는 UI 글꼴을 따르고 카세트 섹션 번호는 기존 Mono 규칙을 따른다. 깊은 들여쓰기는 세 단계 폭으로 제한해 제목·동작을 남긴다. 손잡이와 `…`는 평소 숨기고 행에 마우스를 올리거나 키보드 초점이 들어오거나 메뉴·폼이 열렸을 때 보인다. 열린 문서 행에서는 흐리게 남긴다. 호버가 없는 기기(`hover: none`)에서는 항상 보인다. 모바일 행은 최소 36px이다. 이동 폼의 긴 부모 경로는 선택 상자 안에 둔다. 폼 Escape는 폼만 닫고 원래 행의 `…`로 초점을 돌린다. 검색 결과에는 상위 경로를 남기며 검색 중 드래그를 막는다. [사용법·데이터 계약](document-navigation.md).

**문서 그래프.** 사이드바의 `nav-item`과 열린 문서 탭에 Network 아이콘으로 들어간다. 플롯보드처럼 편집 영역 전체를 사용한다. 위쪽은 `board-bar` 한 줄(전체/주변 연결 `segmented`, 제목 검색칸, 문서·연결 개수, **필터** 팝오버)이고 주변 연결일 때만 중심 문서·단계 줄이 붙는다. 노드는 문서 아이콘 + 제목 + 원고 상태 점의 칩(높이 28px, `--panel`·`--line`, 모서리 `--ctl-r`)이고 선택하면 `--sel`(사이버는 `--brand` 면)이다. 칩 크기와 글자 12px은 확대율과 관계없이 그대로이고 위치만 확대된다. 문서가 50개를 넘거나 화면 폭이 520px 미만이면 100% 미만에서 선택 문서 외에는 아이콘만 보인다. 선은 본문 링크 실선, 시점 인물 점선이며 같은 두 문서 사이는 한 줄로 그린다(본문 링크 우선). 선택 문서의 선은 `--link`. 범례와 확대 버튼은 지도 아래 모서리에 둔다. 오른쪽 정보 패널은 참고 패널 규격(300px, `--side`)이다. 700px 이하에서는 정보 패널을 지도 아래에 놓고 범례를 숨긴다.

지도 바탕은 `--panel`, 정보 패널·필터는 `--side`, 일반 선은 `--muted`, 선택 문서의 선은 `--link`, 선택 노드는 `--brand`, 글자는 `--ink`·`--ink2`·`--muted`를 사용한다. 컨트롤은 `--ctl-r`를 따른다. 문서 종류는 트리와 같은 아이콘·제목 칩·상태 점으로, 관계는 실선(본문 링크)·점선(시점 인물)으로 구분해 색만으로 뜻을 전달하지 않는다. 별도 주요 버튼을 추가하지 않고 게시 준비가 화면의 주요 버튼으로 남는다. 조작·제목은 기존 집필실 UI 글꼴을 따른다. [상세 사용법](document-graph.md), 구현은 `document-graph.tsx`와 `document-graph.module.css`다.

**개인 노트.** 개인 노트는 사이드바의 기존 segmented로 집필실과 전환하며 같은 RichEditor·doc-head·chip·Popover·DocumentTree·AIChat·저장 상태·밝기 버튼을 쓴다. 제목·태그·작품 선택은 선택 사항이다. 노트 아이콘은 메모와 같은 StickyNote, 수집함은 Inbox, 아이스박스는 Snowflake다. 좁은 화면의 노트 트리와 AI 창은 기존 사이드바·참고 패널 서랍과 초점 규칙을 따른다. 노트 트리의 손잡이·메뉴·들여쓰기는 집필실과 같다.

- **사이드바:** 노트 홈(House) → 새 노트 → 검색칸과 그 옆 **노트 필터** `IconButton`(SlidersHorizontal, 적용 중이면 `--brand` 6px 점·`aria-pressed`) → 전체·수집함·아이스박스 `segmented` 한 줄(이름 뒤 11px 개수) → 휴지통·설정 → 목록 위 **폴더 · 최근 수정순** `segmented` → 트리 또는 날짜순 `reference-card.note-card` 목록. 태그·작품 select는 필터 팝오버 안에 둔다. 검색 줄 아래 12px을 둔다. 보기·필터를 세로 목록으로 늘려 트리를 밀어내지 않는다.
- **문서 머리:** 칩은 태그(태그가 있으면 `#이름` 최대 3개 + 나머지 수가 칩 글자), 작품 연결, 첨부가 있을 때만 **첨부 n**, 링크가 있을 때만 **노트 링크 n**(Waypoints, 노트 참고 패널의 연결 탭을 연다), 연결 작품 `soft` 칩 순이다. 드물게 쓰는 고정·아이스박스 이동·이미지 첨부·작품으로 가져오기는 맨 끝 `…`(MoreHorizontal 28px) `.menu`에 두고, 메뉴에서 연 팝오버는 칩 줄 아래에 붙는다. 같은 정보를 칩 두 개로 겹쳐 보이지 않는다.
- **본문:** 원고 조판(문단 첫 줄 1em 들여쓰기, 줄간격 2, 문단 아래 1.2em) 대신 들여쓰기 없음·줄간격 1.85·문단 아래 0.6em, 소제목(h2) 1.15em을 쓴다. 글꼴·크기는 기기 표시 설정을 따른다. 노트에만 있는 서식 도구는 목록 메뉴 다음의 **체크리스트**(ListChecks)·**본문에 이미지 넣기**(ImagePlus) `IconButton`이다. 체크박스는 15px `accent-color: --brand`, 체크한 항목은 `--muted`와 취소선. 본문 이미지는 최대 폭 100%·높이 70vh, `--line` 1px 테두리, 모서리 `var(--r-in,8px)`, 선택 시 `--focus` 외곽선이다.
- **노트 홈:** 플롯보드와 같은 `board-bar`(최근·보드 `segmented`, 개수, `.button` 새 노트) 아래 12px 600 `--muted` 소제목과 `reference-card` 격자(`minmax(min(240px,100%),1fr)`)를 쓴다. 보드는 `board-columns`·`board-column`·`plot-card`·`board-add`를 그대로 쓰고, 열 머리 오른쪽에 26px `IconButton`(BookPlus, 새 작품으로 만들기)을 둔다. 끌어 놓을 열은 `--link` 2px 점선 외곽선이다.
- **링크·참고 패널:** 노트의 오른쪽 패널은 집필실 참고 패널과 같은 탭(연결·AI 대화)과 닫기 버튼을 쓴다. 연결 탭은 12px 소제목 두 개(이 노트가 가리키는 노트 n·이 노트를 가리키는 노트 n)와 `note-card` 목록이다. 집필실 참고 패널의 노트 탭은 빠른 메모 입력칸·`sidebar-search`·`note-card` 목록과 읽기 보기(뒤로 `IconButton`, 날짜, **노트에서 열기** `.button`)로 구성한다.
- **가져오기·새 작품:** 노트 가져오기(**설정 › 저장 · 백업**에서 열며 집필실에서 누르면 노트 공간으로 바꾼 뒤 연다)는 문서 가져오기와 같은 `Modal`·`transfer-guide`·`backup-upload`·`transfer-summary`·`transfer-list`·`transfer-warnings`·`.primary`를 쓴다. 파일과 폴더를 함께 받는 곳은 `backup-upload` 두 개를 `.transfer-pick`(넓은 폭 2열, 600px 이하 1열)으로 묶는다. 목록 행 안의 체크박스는 공용 `label`이 세로 배치이므로 행에 `flex-direction:row`를 쓰고 체크박스는 `width:auto`로 둔다(`.transfer-export-row`). 폴더 → 새 작품은 폴더 행(또는 보드 열 머리)에 붙는 300px `Popover`(제목 입력, 형식 select, 취소·**작품 만들기**)다.
- **빠른 메모:** 집필실 탭 줄의 StickyNote `IconButton`(Alt+N)이 340px `Popover`를 연다. 제목 14px·설명 한 줄, 4줄 textarea, `popover-actions`의 **노트에서 열기**·**수집함에 넣기**(`.button`, 게시 준비가 화면의 주요 버튼으로 남는다). 저장 결과는 `muted` 한 줄(`role=status`)로 보이고 입력칸을 비워 연달아 적게 한다. 화면을 노트로 바꾸지 않는다.
- 브라우저가 예약한 단축키(Ctrl/Cmd+Shift+N·T·W 등)는 쓰지 않는다. [노트 사용법](personal-notes.md).

**휴지통.** 공유 휴지통은 양쪽 사이드바의 Trash2 `nav-item`에서 연다. 기존 `Modal`(검색칸은 `<label>`이 아닌 `div.sidebar-search`)·`sidebar-search`·`reference-card`·`.button`·`IconButton`을 재사용하고 추가 CSS는 배치만 정의한다. 폴더 전체 삭제는 폴더 이름 한 줄(Folder 아이콘, 둘째 줄 **폴더 · 작품 · 문서 n개**)로 묶어 한 번에 복원·영구 삭제한다. 집필실·노트 사이드바와 창의 개수는 같은 공통 계산을 사용해 폴더당 **1개**로 표시하며 내부 문서/노트 수는 폴더 행에 별도로 둔다. 이동은 확인창 없이 처리하고 영구 삭제/비우기 확인은 질문 한 줄과 이력·백업 보존 한 줄로 제한하고, 실행 버튼은 `.button.danger`를 쓴다. [휴지통](workspace-trash.md).

**계정.** 집필실·노트의 로그인 계정 관리는 상단 User `IconButton`과 기존 `Popover`·`.button`으로 구성한다. Google 연결 안내 아래 LogOut 아이콘과 **로그아웃** 버튼을 둔다. 처리 중에는 연결·로그아웃을 잠그고 **연결 중…**/**로그아웃 중…**으로 표시한다. 로그인 화면의 Google 버튼도 `.button`을 사용하며 연결 상태·오류는 13px 토큰 문구를 쓴다. 계정 동작은 상단 계정 버튼에 둔다.

**사용자 속성.** 원고·설정·메모·노트의 기존 DocHead **속성** 패널에 공용 `CustomPropertiesForm`을 둔다. 값 칩은 기존 `.chip`으로 세 개와 나머지 개수를 표시한다. 속성 추가는 기존 Popover(300px)와 입력/선택 컴포넌트를 사용한다. 속성 행은 두 열에서 700px 이하 한 열로 바뀐다. 삭제 `IconButton`은 입력칸 아래쪽에 맞춰 입력칸 가운데에 오고, 체크박스 줄은 입력칸 높이(38px)를 써서 같은 선에 놓인다.

**템플릿.** 사이드바 Files `nav-item`에서 넓은 `Modal`을 연다. 위쪽 `segmented`로 템플릿 사용/새 템플릿 저장을 나누고, 저장 목록은 `transfer-export-row` 체크 목록이다. 작품 템플릿 목록은 섹션마다 참고 패널 소제목 규격(12px 600 `--muted`)의 제목을 둔다. 저장·만들기는 `.button.primary`, 삭제 확인은 겹친 `Modal`과 `.button.danger`다. 저장 결과는 성공 문구 대신 **템플릿 사용**으로 바뀐 화면과 선택된 새 템플릿으로 보여준다. [기능 안내](workspace-templates.md).


**집필실 책장.** 기존 GripVertical `.icon-button` 손잡이는 책장 제목의 LibraryBig 아이콘, 작품 카드의 Book 아이콘 자리에 겹쳐 두고 손잡이가 보이는 동안 그 아이콘을 숨긴다. 손잡이 폭만큼 들이지 않으므로 책장 제목·카드는 이어 쓰기·즐겨찾기·최근 수정 문서와 같은 왼쪽 선과 격자 폭을 쓴다. 손잡이는 평소 숨기고 해당 책장 제목/작품 카드의 hover·focus-within 또는 드래그 중에만 표시한다. 책장 전체에 hover를 걸어 하위 작품의 손잡이를 한꺼번에 드러내지 않는다. `hover:none`에서는 트리와 같은 .7 투명도로 항상 보이고 아이콘 대신 자리를 차지하며, 표시 전후 배치는 그대로다. 마우스·터치·↑↓, 작품의 Alt+↑↓로 정리한다. 원본은 흐리게, 책장/카드 앞뒤는 `--link` 2px 선(같은 줄에 카드가 나란하면 카드 사이 세로선, 한 열이면 가로선), 책장 안 놓기는 같은 토큰 테두리로 표시한다. 같은 줄의 작품 카드는 높이를 맞추고 내용은 위쪽에 맞춘다. 책장 이동·별표는 카드 안 오른쪽 위 26px IconButton 묶음(`.work-card-actions`, 별표가 맨 오른쪽)에 두고 제목에 그 폭만큼 오른쪽 여백을 둔다. 카드 밖에 버튼을 붙여 카드 폭을 줄이지 않는다. 트리 ghost를 재사용해 제목 앞 24자와 놓을 위치를 화면 안에 표시한다. 목록 가장자리 자동 스크롤과 Esc/포인터 취소를 지원한다. 이름을 비우면 화면에서만 **이름 없는 책장**을 표시한다. 홈 board-bar에 LibraryBig **새 책장** `.button`을 둔다. 각 책장은 기존 12px 600 `--muted` 소제목에 접기 화살표·LibraryBig·이름·작품 개수를 두고 오른쪽 `+`·`…` IconButton을 붙인다. 제목은 긴 경우 한 줄 말줄임, 작품은 기존 `reference-card`와 카드 안 LibraryBig **책장 이동** IconButton을 쓴다. 이 버튼은 우클릭·드래그·작품 정보에도 있는 동작이라 별표처럼 해당 카드 hover/focus-within에서만 보이고 `hover:none`에서는 .7로 보인다. 생성·이름 변경·이동은 300px 공용 `Popover`의 label/input/select/`.button.primary`, `…`의 이름/위/아래/삭제는 공용 `.menu`다. 책장 삭제는 짧은 확인 `Modal`로 작품의 기본 책장 이동을 알린다. 이동 후 카드가 재배치되면 그 카드로 초점을 돌리고 목적 책장은 펼친다. 접힘은 기기 설정, 이름·배치는 계정 데이터다. 사이드바 전환 메뉴의 `.work-menu-shelf`도 기존 소제목 규격을 쓰며 긴 이름을 말줄임하고, 작품이 없는 책장은 넣지 않는다. 360px 홈 board-bar와 긴 제목/팝오버/새 작품·정보 select, 메뉴를 여섯 테마에서 확인한다. 아이콘 툴팁은 **새 작품/책장 메뉴/책장 이동**처럼 짧게 표시하고, 접근성 이름에는 대상 책장·작품명을 넣어 구분한다. 새 색·모서리 토큰은 없다. [책장 안내](work-shelves.md).

**작품 즐겨찾기.** 집필실 홈의 이어 쓰기 아래에 기존 소제목·`reference-card` 격자로 선택한 작품을 모은다. 별표 `IconButton`은 선택하지 않았으면 해당 카드 hover/focus-within에서만 보이고, 선택 시 채운 Star·`--brand`·`aria-pressed`로 상태를 남긴다. `hover:none`에서는 항상 보인다. 손잡이와 별표는 카드 안에 겹쳐 두어 표시 여부로 레이아웃이 움직이지 않는다. 즐겨찾기 카드에는 별표와 열기만 두며 별도 드래그를 넣지 않는다. 카드 우클릭·작품 정보는 같은 동작을 `.menu`/`.button`으로 제공한다. 새로운 토큰·바탕·글자 규칙은 없다.

**서재 순서 편집.** 집필실 홈 board-bar의 ListOrdered `.button`에서 넓은 `Modal`을 연다. 기존 label/select/button/reference-card와 ArrowUp/ArrowDown `IconButton`을 사용한다. 행 왼쪽에 트리와 같은 GripVertical 손잡이를 둔다(`.icon-button`, 마우스·터치·↑↓ 키). 드래그 중 원래 행은 흐리게 표시하고 놓을 위치는 트리와 같은 `--link` 2px 선으로 표시한다. 떠 있는 제목은 트리의 ghost 스타일을 재사용하며 긴 이름은 앞 24자로 줄여 화면 안에 둔다. 손잡이 안내는 짧은 native title로 드래그 중 긴 툴팁을 피한다. 자동 정렬은 편집 목록에만 적용하고 **저장된 순서로**·**서재 순서 저장**(`.button.primary`)은 modal-actions에 둔다. 목록은 최대 360px 안에서 세로 스크롤하며 가장자리 드래그는 지속 스크롤한다. 긴 제목은 한 줄 말줄임으로 표시한다. 첫/마지막 이동 버튼은 비활성이고 게시 작품 없음·불러오는 중·저장 오류를 표시한다. 이동 결과는 화면 낭독용 status로 알린다. 저장하면 두 동작 버튼이 비활성으로 바뀌어 결과를 보여준다. 드래그 중 Esc는 이동만 취소하며 평소 Esc/닫기는 홈의 호출 버튼에 초점을 돌린다. 새 색·모서리 토큰은 없다. [사용 안내](library-order.md).

## 9. 카세트 퓨처리즘 테마

1970–80년대 녹음기·컴퓨터 콘솔 느낌의 두 번째 색 계열이다. 독자가 공개 페이지 헤더나 읽기 설정에서 고르며, 보라와 마찬가지로 라이트·다크가 있다. 라이트는 베이지 종이(#F5F5DC)에 오렌지(#E5632D), 다크는 콘솔 검정에 밝힌 오렌지다. 캔버스의 Cassette 아트보드 네 개(집필실·독서 × 라이트·다크)가 시안이다.

**주황은 면이 아니라 신호다.** 주황은 주요 버튼 하나, 줄무늬, 선택된 고르기 버튼, 분류 글자, 링크에만 쓴다. 본문·카드·패널 바탕을 주황으로 칠하지 않는다. 베이지 위 넓은 주황 면은 긴 글을 읽는 눈을 피로하게 하고, 주요 버튼과 줄무늬가 눈에 띄지 않게 만든다. 더 강조하고 싶으면 읽는 영역 밖(표지, 헤더 줄무늬, 선택 상태)에서 늘린다.

| 토큰 | 라이트 | 다크 | 비고 |

## 11. 잉크 테마

네 번째 색 계열이다. 책과 원고지 느낌이다. 라이트는 미색 종이에 남색 잉크, 다크는 먹색 바탕에 종이색 글자다. 독자와 작가가 다른 색 계열과 같은 자리에서 고른다(`data-palette="ink"`, 고르기 아이콘 Lucide Feather). 글꼴 크기·배치는 보라와 같고, 색과 아래 장식만 다르다.

**남색은 잉크, 주색은 분류 글자.** 남색(`brand`)은 주요 버튼·표지 천·선택에, 옛 책의 붉은 제목 글자(주서)처럼 주색 `--pub-kicker`는 제목 위 작은 분류 글자와 장면 구분 기호에만 쓴다. 본문 링크는 남색보다 밝은 잉크 파랑(`link`)이다. 주색은 오류색(`--danger`)과 헷갈리지 않게 주황 쪽으로, 오류색은 진홍 쪽으로 뗐다.

**잉크에서 달라지는 것** (`globals.css`의 잉크 줄, `public-info.module.css` 끝, `studio.css`의 잉크 줄)

- 헤더 아래 1px 선 대신 3px 겹줄(`double`, `--pub-rule`). 공개 홈 헤더도 같다.
- 글자 표지는 왼쪽 14px 책등(700px 이하 9px)과 위아래 금박 띠 두 줄씩. 사이드바 작품 표지도 6px 책등.
- 독서 화면: 막대 아래 오른쪽에 리본 책갈피, 장면 첫 문단의 첫 글자를 크게(두 줄 높이, `--pub-brand`), 장면 구분선(`hr`)은 주색 ⁂. 첫 문단은 `display:flow-root`라 큰 글자가 다음 문단으로 넘어가지 않는다.
- 집필실: 원고 제목은 명조(`--serif`) 400, 분류 글자는 주색, 원고 머리 오른쪽 위에 리본 책갈피, 제목 아래 구분선과 원고 안 `hr`은 주색 ⁂.
- **원고지 줄.** 원고 문단마다 줄 높이 안에 칸 높이(1.3em)의 위아래 괘선을 긋는다(`.manuscript p`). 세로 칸은 긋지 않는다: 원고 글꼴 16종을 재 보면 한글이 0.86~0.97em, 띄어쓰기가 0.2~0.3em이고 고운바탕은 한글끼리도 폭이 달라, 칸을 그으면 글자가 칸을 넘는다. 문단 간격은 줄 높이의 배수로 올린 아래 여백(`padding-bottom`, 바깥 여백 0)이라 문단 사이에도 줄이 끊기지 않는다. 글자 수 표시는 기존 문서 통계의 **200자 원고지 환산**을 고르면 매수로 보인다. 칸에 맞춘 모양은 모든 테마의 **원고지 보기**(8절)에서 본다.
- ❦(U+2766)는 일부 기기에서 컬러 이모지로 그려져 쓰지 않는다.
- 그 밖의 버튼·칩·모서리·글꼴은 보라와 같다. 새 모양 토큰은 없다.

## 12. 컬럼비아 테마

## 16. 헤일로 테마: 선조 유적·스파르탄

- 글자 표지: 깎은 귀퉁이, 하늘을 비스듬히 가로지르는 고리(`::before`), 빛기둥 하나(`::after`). 표지 그림 SVG는 숨긴다(16·17절 네 계열 공통).
- 분류 글자 명판·주요 버튼·설정집 버튼은 깎은 판. 독서 제목 아래와 장면 구분선은 가운데 V 꺾쇠와 양쪽 선(220×14). 장면 번호는 육각 판 안 두 자리 숫자(CSS 카운터 `decimal-leading-zero`).
- 집필실: 원고 머리 위 두 귀퉁이 꺾쇠, 명판 분류 글자, 같은 꺾쇠 구분선(200×14), 상태 점은 기운 세 칸 방어막, 활성 탭 빛 밑줄, 사이드바 도구 줄 아래 빛 선, 작품 표지 깎은 귀퉁이.

**스파르탄에서 달라지는 것**

- 새 토큰: `--pub-accent-hi`·`--pub-accent-lo`, `--pub-glow`, `--pub-armor`·`--pub-olive`·`--pub-olive-hi`·`--pub-olive-dk`(장갑판), `--pub-planet`·`--pub-holo`·`--pub-holo-bg`(바이저 속 행성과 홀로그램), `--pub-ink-ship`, `--pub-tech`(Saira Semi Condensed), `--sp-cortana-a`·`--sp-cortana-b`·`--sp-cortana-ink`(코타나). 장식 변수 `--sp-ship`(인피니티 함선 그림)·`--sp-divider`(방위 눈금 구분선)·`--sp-circuit`(회로 번호 칸 52×34)·`--sp-trace`(제목 뒤 회로선 72×8)·`--sp-chip-cover`(표지 AI 칩과 회로선)·`--sp-chip`·`--sp-chip-win`·`--sp-chip-out`(집필실 칩 마스크: 채움·창 뚫림·윤곽).
- 헤더 아래 115° 끊긴 장갑판 띠와 금빛 표시 칸. 사이트 이름 Saira Semi Condensed 700 대문자 15px·자간 .24em, 옆에 각진 금빛 바이저.
- 글자 표지: 위쪽 계단 장갑판, 각진 금빛 바이저(`::before`)에 행성과 함선이 비친다(`::after`). 함선은 길고 각진 상자형 선체·계단식 윗면·뭉툭한 뱃머리·푸른 엔진이고 옆면에 INFINITY가 적혀 있다. 바이저가 두 밝기 모두 금빛이라 함선 그림은 고정색이다. 700px 이하에서는 바이저를 줄여 두 줄 제목과 겹치지 않는다(`fiction-palettes.mjs`가 간격을 잰다).
- 코타나: 표지 오른쪽 아래 장갑에 AI 칩이 꽂히고 회로선이 바이저 쪽으로 올라간다(`.book-cover>span:last-child::after`). 칩 자리만큼 제목 오른쪽 여백을 둔다(1280px 18px, 700px 이하 12px에 칩도 줄임). 서재 분류 줄은 `.book-no`(작품 번호)·`.book-dot`(가운뎃점)·`.book-kind`(분류)로 나뉘고, 스파르탄만 번호를 회로 칸에 넣고 가운뎃점을 숨긴다. 다른 계열의 글자는 그대로 "01 · 소설"이다.
- 분류 글자 명판·주요 버튼은 오른쪽 사선 변. 구분선은 방위 눈금과 아래 삼각 표식. 장면 번호는 파랑에서 보라로 번지는 회로 칸 안 두 자리 숫자(주사선), 제목 뒤에 회로선이 이어진다(700px 이하에서는 회로선 숨김). 번호 글자는 `--sp-cortana-ink`로 라이트 종이 위 5.2:1이다(병합된 홀로그램 번호는 2.8:1이었다).
- 독서 진행 막대: 4px 데이터 흐름. 파랑→보라 그러데이션을 종이색 틈으로 끊고, 끝에 빛나는 8px 머리를 둔다.
- 집필실: 원고 머리 위 장갑판 단, 사선 명판, 같은 눈금 구분선, 활성 탭 금빛 밑줄, 사이드바 도구 줄 아래 장갑판 띠, 작품 표지 계단 장갑판과 바이저. 상태 표시는 14×10 AI 칩 마스크로, 초안 채움(`--draft`), 검토 파랑 채움(`--review`), 완료 보라에 창이 뚫린 칩(`--done`), 구상은 윤곽만이다. 색만이 아니라 모양으로도 구분한다. 원고 머리 분류 글자(`.doc-kicker`) 앞에 파랑→보라 칩이 붙는다. 마스크 위에서는 빛번짐(`filter`)이 지워지므로 칩은 빛나지 않는다.

**붉은 책에서 달라지는 것**

- 새 토큰: `--pub-accent-strong`(버튼 마우스 올림), `--pub-gold`·`--pub-gold-hi`(금박), `--pub-map`(등고선·산맥), `--pub-cover-edge`·`--pub-cover-band`(표지 테와 아래 띠), `--pub-tech`(Cinzel). 장식 변수 `--rb-mountains`(산맥 실루엣)·`--rb-divider`(가운데 반지 구분선).

**실마릴리온에서 달라지는 것**

- 새 토큰: `--pub-accent-strong`, `--pub-pri-bg`(주요 버튼 바탕, 다크는 은→금), `--pub-silver`·`--pub-silver-hi`·`--pub-gold`·`--pub-gold-hi`(두 나무의 빛), `--pub-gem`, `--pub-cover-top`, `--pub-tech`(Marcellus SC). 장식 변수 `--sm-light`(은→금 선), `--sm-waves`(엇갈린 물결), `--sm-divider`(보석 셋), `--sm-jewel-y`(표지 보석 높이, 700px 이하 30%).
- 헤더 아래 은→금 선과 엇갈린 물결 띠(12px). 사이트 이름 Marcellus SC 400 대문자 16px·자간 .22em, 옆에 보석(라이트는 은·남색·금으로 짙게, 다크는 밝게).

- 분류 글자 앞 작은 보석. 주요 버튼은 은→금 테두리. 구분선은 은빛·금빛 선 사이 보석 셋. 장면 번호는 반은 은·반은 금 고리 안 로마 숫자.
- 집필실: 원고 머리 위 은→금 선과 금빛 번짐, 보석 분류 글자, 같은 보석 구분선(200×14), 마름모 상태 점, 활성 탭 금빛 밑줄, 사이드바 도구 줄 아래 은→금 선, 작품 표지 보석 빛.

**16·17절 네 계열 공통**

- 웹폰트 넷(Oxanium, Saira Semi Condensed, Cinzel, Marcellus SC)은 `layout.tsx`의 Google Fonts 한 줄에 더했다. 한글은 IBM Plex Sans KR(헤일로) 또는 고운바탕(가운데땅)으로 넘어간다.
- 모서리·칩·입력칸·글꼴 크기는 보라와 같다. 새 모양 토큰은 없다. 장면 제목에 이미 번호가 있으면 번호가 두 번 보일 수 있다(디젤·누아르와 같음).

## 18. 무한 테마: 바벨·무한

열세·열네 번째 색 계열이다. 앱 이름(Orbis Tertius)이 온 보르헤스의 무한에서 나왔다. `data-palette`는 `babel`·`infinity`, 고르기 아이콘은 Lucide Hexagon·Infinity. 두 계열 모두 기본 서재 표지 그림(점선 원)을 숨기고 자기 표지 그림을 `::before`·`::after`에 그린다. 모서리·칩·입력칸·글꼴 크기는 보라와 같고 새 웹폰트는 없다.

**바벨** (바벨의 도서관). 돌빛 종이에 녹청, 다크는 서가 그늘의 검은 녹색. 등불 호박색(`--pub-lamp`)은 표지 가운데 점 하나에만 쓴다(디젤 호박색과 겹치지 않게 다크 주요 버튼도 녹청).

- 헤더 아래 18px 육각 벌집 띠(`--babel-tile` 마스크, `--pub-band`). 공개 홈 헤더와 집필실 사이드바 도구 줄 아래(12px)도 같다.
- 표지: 돌면서 작아지는 육각형 일곱 겹(`--babel-nest`)과 가운데 등불. 700px 이하에서는 제목과 덜 겹치게 작고 높게.
- 분류 글자(서재·독서 제목 위·집필실 원고 머리)는 양끝이 뾰족한 육각 명판(`--babel-hex`, `--pub-plate`). 주요 버튼(`.book-read`, 홈 주요 링크)도 육각 모양이고, 키보드 초점에서는 모양을 풀어 초점 테두리가 잘리지 않게 한다.
- 구분선(독서 제목 아래·장면 구분·집필실 제목 아래와 원고 `hr`): 가운데가 찬 육각 세 개와 양쪽 선(`--babel-div`, 220×14, 집필실 200px).

**무한** (진정한 무한). 알레프(모든 것이 보이는 한 점)와 ∞를 합쳤다. 끝없이 작아지는 수열이 한 점에 모인다. 진주색 / 밤 검정. 무지갯빛(청록·분홍·금, `--pub-iris-conic`)은 점·고리·∞에만 쓰고 글자에는 쓰지 않는다. 링크·분류 글자는 짙은 청록.

- 헤더 아래 18px 눈금 띠(`--inf-band`, 1920×18 마스크를 가운데 정렬, `--pub-ink`): 양 끝의 긴 눈금이 점점 짧고 촘촘해지며 가운데로 모이고, 모이는 곳에 무지갯빛 고리 하나(`::before`, `--inf-point`). 공개 홈 헤더와 집필실 사이드바 도구 줄 아래(12px, 고리 10px)도 같다.
- 사이트 이름 앞 기호(◌)는 무지갯빛 ∞(`--inf-mark`)로 바꾼다. 공개 헤더·홈·집필실 사이드바 모두.
- 표지: 작아지며 한 점으로 감겨 드는 성냥개비 나선(`--inf-spiral`, `--pub-cover-ink` 72%)과 그 점의 무지갯빛 고리. 표지 바탕이 다크 바탕과 비슷해 1px `--pub-line` 테두리. 700px 이하에서는 제목과 덜 겹치게 작고 높게.
- 분류 글자 앞 작은 무지갯빛 고리(`--inf-o`). 주요 버튼·설정집 버튼·집필실 `.primary`는 알약 모양(999px).
- 구분선: 양쪽에서 짧아지며 모이는 눈금과 가운데 ∞(`--inf-div`, 220×16, 집필실 200px). 눈금은 글자색 70%, ∞ 자리 32px만 무지갯빛.

## 19. 히치하이커 테마

열다섯 번째 색 계열이다. 더글러스 애덤스의 『은하수를 여행하는 히치하이커를 위한 안내서』에서 안내서 단말기를 가져왔다. `data-palette`는 `hitchhiker`, 고르기 아이콘은 Lucide ThumbsUp(엄지 들기). 원작 표지의 DON'T PANIC은 노랑 글자에 빨강 테두리, 1981년 TV판 안내서 화면은 검은 화면 위 선 그림이라 검정·노랑·빨강을 쓴다. 영화·TV 로고와 그림은 쓰지 않는다. 다른 계열과 달리 모서리를 둥글게, 외곽선과 아래 그림자를 굵게 둔다(나사펑크·사이버의 각진 모양과 겹치지 않게).

- **색 역할.** 빨강(`--pub-accent`, 집필실 `--brand`)은 라이트·다크 모두 행동 색(주요 버튼·진행 막대·활성 탭). 노랑은 장식에만 쓴다(DON'T PANIC, 스티커, 행성, 장면 번호 말풍선). 다크 주요 버튼은 밝은 빨강 #ff4a3a에 검은 글자.
- **헤더.** 라이트·다크 모두 검은 단말기 띠(헤더 안에서 글자 토큰을 밝게 다시 정의)와 그 아래 14px 수건 띠(`--hh-towel`: 노랑 바탕, 빨강·검정 줄, 아래 술). 사이트 이름은 Fredoka, 앞 기호(◌)는 고리 달린 노란 행성. 공개 홈 헤더는 같은 모양에 위 모서리 14px(700px 이하 0), 집필실 사이드바 도구 줄 아래는 5px 수건 띠.
- **표지.** 검은 단말기: 7px 테두리와 24px 아래 턱, 턱 가운데 빨간 버튼 점(`::after`). 화면에 별과 선으로만 그린 고리 행성(`--pub-line-art`), 그 아래 5도 기운 DON'T PANIC(Shrikhand, `::before`), 맨 아래 작품 제목(두 줄까지). 기본 표지 그림(점선 원)은 숨긴다. 700px 이하에서는 테두리를 줄이고 DON'T PANIC과 행성을 위로 올려 제목과 띄운다.
- **분류 글자**(서재·독서 제목 위·집필실 원고 머리)는 2도 기운 노란 알약 스티커. **장면 번호**는 노란 말풍선(아래 왼쪽 귀만 뾰족, 두 자리 숫자).
- **버튼.** 주요 버튼·설정집 버튼·홈 주요 링크·집필실 `.primary`는 2px 외곽선, 모서리 12px, 아래 3px 그림자.
- **구분선**(독서 제목 아래·장면 구분·집필실 제목 아래와 원고 `hr`): 가운데 고리 행성과 양쪽 점선 궤도(`--hh-orbit`, 220×16, 양 끝은 `--hh-fade` 마스크로 흐림).
- **집필실 상태 점**은 달의 위상: 구상 빈 원, 초고 초승달, 검토 반달, 완료 보름(`--pub-moon`). 표지 미니 카드(`.work-cover`)도 작은 단말기.

## 20. 트론 테마

## 21. 매트릭스 테마

열일곱 번째 색 계열이다. 영화 「매트릭스」의 코드비(디지털 비)에서 가져왔다. `data-palette`는 `matrix`, 고르기 아이콘은 Lucide Binary. 라이트는 영화 속 흰 구성 공간(로딩 프로그램), 다크는 검은 화면의 인광 녹색이다. 히치하이커(검은 단말기 띠·노랑·둥근 모양)와 겹치지 않게 헤더는 두 밝기 모두 바탕색 그대로 두고, 모서리는 0, 글자는 고정폭으로 만든다.

- **색 역할.** 녹색(`--pub-accent`, 집필실 `--brand`)이 행동 색이다. 코드비는 흐린 녹색(`--pub-rain`)에 머리 글자만 밝게(`--pub-head`). 다크는 `--pub-glow`로 빛을 더한다.
- **가타카나.** 코드비의 반전 가타카나·숫자는 읽는 글이 아니라 무늬다(7절 영문 장식 금지와 별개). CSS `content`에 `/ ""` 대체 글을 붙여 화면 읽기 프로그램이 읽지 않게 한다.
- **헤더.** 아래 16px 코드비 띠(`--mx-rain`: 주기가 다른 네 겹 줄기와 머리, `--mx-rain-fade`로 위를 흐리게). 사이트 이름은 Share Tech Mono 대문자, 앞 기호(◌) 자리는 이름 뒤에서 깜박이는 네모 커서(`order:1`, `mx-blink`). `prefers-reduced-motion`이면 깜박이지 않는다.
- **표지.** 두 밝기 모두 검정. 반전 가타카나를 세로쓰기(`writing-mode:vertical-rl`)로 채우고 열마다 위는 투명·끝은 밝은 줄기 배경을 글자에 오려 쓴다(`background-clip:text`, `--mx-streaks`, 열 폭 15px). 제목은 아래 검은 띠 위(세 줄까지). 기본 표지 그림은 숨긴다.
- **분류 글자**는 명령 줄 표시 `›` 뒤의 고정폭 글자(`--pub-code` Nanum Gothic Coding). **장면 번호**는 두 칸 물방울이 떨어지는 녹색 숫자(Share Tech Mono).
- **버튼.** 주요 버튼·홈 주요 링크·집필실 `.primary`는 모서리 0, 고정폭 굵은 글자. 서재 **작품 읽기**는 화살표 자리에 깜박이는 커서, **설정집**은 테두리 없이 `[ ]` 꺾쇠.

## 22. 프로토스 테마

열여덟 번째 색 계열이다. 게임 「스타크래프트」의 프로토스 종족(금빛 테를 두른 상아 갑옷, 사이오닉 파랑, 떠 있는 수정)에서 가져왔다. `data-palette`는 `protoss`, 고르기 아이콘은 Lucide Diamond. 게임 로고·문자·그림은 쓰지 않는다. 시안 세 안(프로토스·테란·저그) 중 사용자가 프로토스를 골랐고, "더 세련되게" 요청에 따라 장식을 덜어낸 안으로 만들었다. 선조 유적(은빛·청록·깎은 귀퉁이)과 실마릴리온(남색 밤·보석 셋)과 겹치지 않게 모서리는 2px로 곧게, 장식은 가는 금빛 선·가는 수정·빛 한 줄로만 만든다.

- **색 역할.** 사이오닉 파랑(`--pub-accent`, 집필실 `--brand`)이 행동 색이다. 금빛(`--pub-gold`)은 선·테에만 쓰고 글자색으로 쓰지 않는다(라이트 종이 위 2.7:1). 분류 글자는 짙은 금갈색 `--pub-kicker`. 다크는 `--pub-glow`로 버튼에 빛을 더하고 라이트는 빛이 없다(`transparent`).
- **헤더.** 아래쪽 1px 금빛 선, 그 2px 아래 양끝이 사라지는 파랑 빛 한 줄(`--pt-seam`, `--pub-psi-glow`). 사이트 이름은 Syncopate 400 대문자·자간 .38em, 앞 기호(◌) 자리는 가는 수정(`--pt-crystal` 마름모 `clip-path`).
- **표지.** 라이트는 상아, 다크는 따뜻한 검정. 안쪽 5px 들어간 금빛 테(`inset` 그림자), 수정을 감싼 가는 금빛 고리와 파랑 빛(배경), 아래 받침 호(`::before`의 아래 테두리), 떠 있는 수정(`::after`), 수정에서 내려오는 빛 한 줄과 금빛 지평선(배경). 위치는 `--pt-y`·`--pt-r`(700px 이하 40px·22px, 분류 줄 숨김, 제목 아래 정렬). 제목·분류는 가운데 정렬, 제목은 세 줄까지. 기본 표지 그림은 숨긴다.
- **분류 글자**(서재·독서 제목 위·집필실 원고 머리) 앞에 5×10 파랑 수정. **장면 번호**는 금빛 고리 안 Syncopate 숫자와 고리 바깥 왼쪽 위를 지나는 파랑 호(44px, 700px 이하 38px). 호는 원뿔 그러데이션을 종이색 원으로 가려 만들므로 바탕이 `--pub-paper`인 곳에만 쓴다.
- **버튼.** 주요 버튼·홈 주요 링크·집필실 `.primary`는 2px 모서리에 금빛 테, 테와 파랑 바탕 사이 2px 틈(이중 테), 윗면 빛 선 한 줄(`--pt-pri`). 틈은 바탕색 `inset` 그림자라 놓인 바탕을 따른다(공개 페이지 `--pub-paper`·팝오버 `--pub-popover`, 집필실 `--pt-gap` 기본 `--panel`, 팝오버 안 `--pop`, `segmented` `--hover`). 보조 버튼은 옅은 금빛(`--pub-gold-soft`) 테두리.

## 26. 노스트로모 테마

스물두 번째 색 계열이다. 영화 「에일리언」(1979)의 화물선 노스트로모호에서 가져왔다: 퍼티색 플라스틱 기기, 둥근 브라운관 단말기, 조종석 색 키, 움직임 탐지기. `data-palette`는 `nostromo`, 고르기 아이콘은 Lucide SquareTerminal. 영화 로고·회사 표식·대사·글자와 기거 그림은 쓰지 않는다. 매트릭스(선명한 녹색·코드비·모서리 0)·디젤(강철 회색·호박색 경고 줄무늬)·오디세이(차가운 흰 실내)와 겹치지 않게 바탕은 따뜻한 퍼티색, 초록은 탁한 인광으로 화면 속 글자와 탐지기에만, 호박색은 작은 키에만 쓴다.

- **색 역할.** 주요 버튼·선택(`--pub-accent`, 집필실 `--brand`)은 라이트에서 어두운 화면 유리 #1b211d에 인광 글자 #b2e8ae, 다크에서 불 켜진 인광 판 #a6e2a2에 어두운 글자다. 주사선(`--ns-scan`)과 안쪽 1px 테(`--pub-accent-rim`), 아래 2px 그림자로 유리 키를 만든다. 보조 버튼과 헤더 테마·밝기 버튼은 3px 자판 키(`--pub-key`·`--pub-key-line`·`--pub-bevel`).
- **헤더.** 아래 14px 자판 받침 띠(`--ns-band`): 어두운 받침 위 오른쪽에 색 키 세 묶음(흰·노랑·빨강·파랑·초록, `--ns-keys`), 왼쪽에 짧은 인광 표시줄. 사이트 이름은 Jost 대문자(넓은 자간), 앞 기호(◌) 자리는 움직임 탐지기 부채꼴(`--ns-mark`). 집필실 사이드바 도구 줄 아래는 같은 색 키 줄.
- **표지.** 퍼티색 틀(`--pub-bezel`, 8px, 아래 3px 턱) 속 둥근 브라운관(`::before`): 지평선(64%) 아래 선으로 그린 지면 격자(가로선 + 소실점에서 퍼지는 선), 지평선에 걸친 행성 고리와 위도선, 별, 주사선. 틀 아래 오른쪽 표시등 둘(호박·초록, `::after`). 제목은 화면 위쪽의 고정폭 인광 글자(세 줄, 700px 이하 두 줄)이고 시리즈 이름과 기본 표지 그림은 숨긴다. 집필실 표지 미니 카드도 틀 속 화면과 지평선·행성.
- **분류 글자**(서재·독서 제목 위·집필실 원고 머리)는 호박색 키(9×8px) 뒤의 고정폭 글자(`--pub-mono`). **장면 번호**는 움직임 탐지기: 위가 둥근 부채꼴 화면에 거리 고리와 점 하나, VT323 인광 숫자(46×28px, 700px 이하 40×24px), 퍼티색 테.
- **구분선**(독서 제목 아래·장면 구분·집필실 제목 아래와 원고 `hr`): 220×16 눈금자 가운데 탐지기 반원과 점(`--ns-div`, 양 끝 `--ns-fade`).
- **집필실 상태 점**은 자판 키(11×8px): 구상 꺼진 키(테두리만), 집필 중 파랑, 퇴고 중 호박, 완성 초록. 색뿐 아니라 밝기도 다르다. 다크는 호박·초록 키가 은은하게 빛난다.

## 27. 새 기능 체크리스트

- [ ] 0절 표의 기존 부품으로 만들었고 **하지 말 것**에 걸리는 곳이 없다. 같은 종류의 기존 화면과 나란히 찍어 비교했다.

- [ ] 공개 페이지는 `public-site` 안에 있고 헤더에 `ThemeControls`가 있다.
- [ ] 집필실 기능은 8절의 자리(사이드바 도구, 제목 아래 칩과 속성 폼, 참고 패널 탭, 더 보기 메뉴, 팝오버, 대화상자)에 들어가고 원고 위 고정 영역을 늘리지 않았다. 카세트에서 키·LED·Mono 숫자 모양이 필요한지 확인했다.
- [ ] 공개 페이지 색은 `--pub-*`, 집필실·대화상자 색은 기본 토큰만 썼고, 보라·카세트·사이버·잉크·컬럼비아·나사펑크·디젤·누아르·선조 유적·스파르탄·붉은 책·실마릴리온·바벨·무한·히치하이커·트론·매트릭스·프로토스·타투인·제국·오디세이·노스트로모 × 라이트·다크 마흔네 조합을 확인했다.
- [ ] 새 색 계열이면 헤더 테마 버튼·테마 팝오버·`segmented` 고르기 버튼에도 그 계열 주요 버튼 모양을 주었다(4절 **고르기 버튼 모양**).
- [ ] 제목은 `--pub-title`, 분류 글자는 `--pub-kicker-font`, 조작·설명은 `--pub-sans`다. 색 계열 이름으로 분기하는 대신 모양 토큰을 썼다.
- [ ] 버튼 옆 작은 입력·선택은 대화상자가 아니라 팝오버나 메뉴로 열었다(8절 **떠 있는 창**).
- [ ] 주요 버튼은 화면당 하나이고 보라 역할 규칙(2절)과 카세트 주황 규칙(9절)을 지켰다.
- [ ] 슬로건·영문 장식 제목이 없고 숫자에는 단위가 있다.
- [ ] 700px 이하와 360px 폭에서 가로 스크롤이 없다.
- [ ] 새 토큰·패턴을 만들었다면 이 문서와 [변경 기록](../CHANGELOG.md)을 갱신했다.
- [ ] [실제 조작 검증](interaction-verification.md)에 따라 각 변경 도구의 결과와 적용 범위를 확인했다. 선택한 글자와 전체 문서, 기기 보기 설정과 저장되는 서식을 구분했다.
- [ ] 팝오버를 열어 둔 채 다른 도구로 한 번에 전환하고 Esc·바깥 클릭·Tab·편집기 복귀를 확인했다. 선택 범위가 필요한 동작은 실제 선택에서 확인했다.
- [ ] CSS 초기화·전역 규칙을 함께 적용한 화면에서 목록 기호·들여쓰기·표·링크처럼 바뀐 표현을 눈과 계산된 스타일로 확인했다. 버튼·노드가 존재한다는 것만으로 표시 성공으로 판단하지 않았다.
