# 디자인 가이드

기준일: 2026-10-02. 새 화면이나 기능을 추가할 때 기존 화면과 같은 색·글꼴·간격·문구를 쓰기 위한 규칙이다. 화면 시안은 작가 계정의 [디자인 캔버스](https://claude.ai/artifact/8JQvgoZDiTun4ZQ4Cp8FEW)(비공개)에 있고, 참고 서비스 연구는 [디자인 레퍼런스](design-references.md)에 있다.

## 1. 적용 상태

| 영역 | 상태 | 근거 |
|---|---|---|
| 공개 페이지: 홈·서재·독서·설정집·데이터 이용 안내 | **구현.** 보라·카세트 두 색 계열 × 라이트·다크, 웹폰트, 글자 표지 | `src/app/globals.css`의 `--pub-*`, `src/app/public-info.module.css`, `src/lib/theme.ts`, `src/components/theme-toggle.tsx` |
| 집필실 | **기존 화면 유지.** 슬레이트 색(`--ink`·`--accent` 등)과 상단 헤더·네이비 아이콘 바 구조 | 새 구조는 [8절 목표 시안](#8-집필실-목표-시안-미구현) |
| 카세트 퓨처리즘 테마 | **공개 페이지에 구현.** 독자가 헤더에서 고른다. 집필실 카세트 시안은 미구현 | [9절](#9-카세트-퓨처리즘-테마) |

이 문서의 구현 항목은 코드가 기준이다. 코드와 다르면 코드를 따르고 이 문서를 고친다.

## 2. 원칙

1. **바탕은 무채색, 색은 적게.** 바탕과 본문은 보라 기운이 아주 살짝 도는 회색·검정(카세트는 베이지·콘솔 검정)이다. 강조색은 브랜드·버튼·링크에만 쓴다. 그라데이션과 넓은 강조색 면은 쓰지 않는다.
2. **두 보라의 역할을 나눈다.** Ultra Violet(Pantone 18-3838, #5F4B8B)은 브랜드와 주요 동작, Very Peri(Pantone 17-3938, #6667AB)는 연결이다. 섞어 쓰면 탁해 보인다.
   - Ultra Violet `--pub-brand`: ◌ 표시, "서재 둘러보기"·"작품 읽기" 버튼, 표지, 설정 분류명.
   - Very Peri `--pub-link`: 설정 링크, 각주 번호, 읽기 진행 막대, 텍스트 링크.
3. **서재는 책, 집필실은 도구.** 공개 페이지는 명조 제목·넓은 여백·가는 구분선으로 책처럼, 집필실은 작은 고딕·촘촘한 배치로 작업 도구처럼 만든다. 색 규칙은 같고 레이아웃과 글꼴로 구분한다.
4. **꾸밈말보다 사실.** 슬로건·영문 장식 제목 대신 실제 데이터(편수, 날짜, 개수)를 보여준다. [7절](#7-문구)을 따른다.
5. **네 조합에서 모두 확인한다.** 새 화면은 보라·카세트 × 라이트·다크 네 조합에서 각각 보고, 본문 대비 4.5:1 이상을 지킨다.

## 4. 테마 (색 계열 × 밝기)

- 테마는 `<html>`의 두 속성으로 정한다. 밝기 `data-theme="light|dark"`와 색 계열 `data-palette="violet|cassette"`이다. 둘은 따로 고르며 네 조합이 모두 있다.
- `src/lib/theme.ts`의 `themeScript`가 `<head>`에서 첫 그리기 전에 실행된다. 밝기는 저장된 선택(`localStorage`의 `orbis-theme`)이 있으면 그것을, 없으면 기기 설정을 쓴다. 색 계열은 저장된 선택(`orbis-palette`)이 `cassette`일 때만 카세트, 나머지는 보라다.
- CSS는 `:root`(보라 라이트) → `[data-theme=dark]`(보라 다크) → `[data-palette=cassette]`(카세트 라이트) → `[data-palette=cassette][data-theme=dark]`(카세트 다크) 순서로 덮어쓴다. 마지막 블록은 선택자가 더 구체적이라 순서와 관계없이 이긴다.
- 공개 페이지 헤더마다 `ThemeControls`를 둔다. 왼쪽은 색 계열 고르기(보라 원 두 개 / 카세트 아이콘, `aria-pressed`), 오른쪽은 달/해 밝기 버튼이다. 다른 조작에서 바꿀 때는 `useSiteTheme()`·`useSitePalette()`를 쓴다. 독서 화면의 "읽기 설정 › 배경"과 "읽기 설정 › 테마"도 같은 값을 바꾼다.
- 이전 독서 설정(`orbit-reader-prefs`의 `theme: 'night'`)은 사이트 밝기가 저장되지 않은 경우에 한 번만 다크로 옮긴다.
- 집필실은 아직 두 속성을 읽지 않는다. 집필실 화면은 테마와 관계없이 기존 밝은 화면이다.

**새 공개 페이지를 만들 때**

1. 가장 바깥 요소에 `public-site` 클래스를 붙인다. 바탕·글자색·글꼴과 `<html>` 바탕(넘침 스크롤 영역)이 함께 적용된다.
2. 헤더에 `ThemeControls`를 넣는다. 기존 페이지는 `PublicHeader`(`public-site.tsx`) 또는 CSS 모듈 헤더(`page.tsx`·`privacy/page.tsx`)를 쓴다.
3. 대화상자는 `primitives.tsx`의 `Modal`을 그대로 쓴다. 공개 페이지가 열려 있으면 `html:has(.public-site) .modal` 규칙으로 테마 색을 따른다.
4. 색 계열마다 모양이 달라야 하면 3절의 모양 토큰을 쓰고, 그래도 부족할 때만 `[data-palette=cassette] .클래스` 규칙을 `globals.css`의 카세트 줄에 추가한다. CSS 모듈에서는 `:global([data-palette=cassette]) .클래스`로 쓴다.

**색 계열을 하나 더 추가할 때**

1. `globals.css`에 `[data-palette=<이름>]`(라이트)과 `[data-palette=<이름>][data-theme=dark]`(다크) 블록을 만들고 `--pub-*` 전체 값과 모양 토큰을 정의한다. 일부만 정의하면 보라 값이 섞인다.
2. `SitePalette` 타입, `preferredPalette`, `themeScript`의 허용 값에 이름을 추가하고 `tests/theme.test.ts`를 갱신한다.
3. `ThemeControls`에 고르기 버튼을, 독서 설정의 "테마" 목록에 선택지를 추가한다.
4. 네 화면(서재·독서·설정집·홈)을 라이트·다크와 360px 폭에서 확인하고 이 문서, [사용 안내](user-guide.md), [변경 기록](../CHANGELOG.md)을 고친다.

- 위 크기는 두 색 계열에 같다. 카세트는 제목 글꼴만 고딕 600으로 바뀐다.
- 명조 제목은 굵게 쓰지 않는다(400). 위계는 크기와 여백으로 만든다.
- 독서 본문 글꼴은 색 계열과 관계없이 독자가 고른 명조/고딕(기본 명조)을 따른다. 첫 문장 발췌도 명조로 둔다.
- 한국어 본문은 `word-break: keep-all`로 어절 단위 줄바꿈을 하고, 첫 문단 다음부터 1em 들여쓴다.
- 영문은 이름에만 쓴다(Orbis Tertius, 표지의 ORBIS TERTIUS).

## 6. 레이아웃·모양 (공개 페이지)

- 헤더 77px, 좌우 여백 `clamp(24px, 7vw, 110px)`. 왼쪽 ◌ + 사이트 이름, 오른쪽 메뉴와 `ThemeControls`. 700px 이하에서는 높이가 자동(최소 65px)이고, 폭이 모자라면 메뉴가 둘째 줄 오른쪽으로 내려간다. 메뉴 글자와 사이트 이름은 줄바꿈하지 않는다.
- 서재 최대 폭 1190px. 작품 항목은 표지 156px · 정보 · 첫 문장 300px의 세 열, 간격 48px, 위에 `--pub-rule` 선. 700px 이하에서 표지 96px·정보 두 열, 발췌는 아래로.
- 독서 본문 폭은 독자 선택 580·680·780px. 상단 52px 막대(목차·작품명·읽기 설정)는 화면 위에 붙어 있다.
- 카드로 감싸지 않고 가는 선으로 구분한다. 그림자는 떠 있는 요소(각주 미리보기, 목차)에만 쓴다.
- 모서리: 태그 3px, 버튼 6px, 테마 버튼·색 계열 고르기 묶음 8px(안쪽 버튼 5px), 미리보기·목차 패널 10px(카세트 6px).
- 주요 버튼(`.book-read`, 홈 `.primaryLink`)은 화면당 하나, `--pub-brand` 바탕. 보조 버튼(`.book-wiki`)은 `--pub-line` 테두리.
- 선택된 항목은 `--pub-tint` 바탕 + `--pub-tint-ink` 글자.
- 작품 이미지가 없으므로 `BookCover`가 제목·"ORBIS TERTIUS"·◌ 궤도 점선으로 글자 표지를 만든다. 표지는 장식이라 탭 순서에서 빠진다(제목 링크가 같은 곳으로 간다).
- 아이콘은 Lucide(lucide-react)이고 헤더·막대에서 16–17px이다. ◌는 아이콘이 아니라 글자다.
- 브레이크포인트는 700px 하나다. 360px 폭에서 가로 스크롤이 생기지 않아야 한다.

## 7. 문구

- **슬로건을 쓰지 않는다.** "쓰여진 시간들.", "소설과 그 곁의 세계를 모아둔 서재."처럼 어느 사이트에 붙여도 되는 시적 소개는 지웠다. 홈페이지도 이름과 링크만 둔다.
- **영문 장식 제목을 쓰지 않는다.** FICTION & WORLDS, WORLD BIBLE, DATA USE를 지웠다.
- **실제 데이터로 채운다.** "수록 작품 1편 · 마지막 공개 2026. 10. 2.", "먼 별의 항구 설정집 · 공개 설정 2개".
- **이름:** 공개 목록은 **서재**(도서관 아님), 쓰는 곳은 **집필실**, 목록 제목은 **수록 작품**. 사이트 이름 Orbis Tertius가 보르헤스의 가상 백과사전에서 왔기 때문에 "수록"을 쓴다.
- **문장은 합니다체.** 결과는 과거형 다음에 할 일: "백업 파일을 만들었습니다. 아래 파일 저장 버튼을 눌러 보관하세요." 오류는 무엇이 실패했고 어떻게 하는지: "기기 저장 실패: 저장 공간과 브라우저 설정을 확인하세요."
- **버튼은 짧은 명사·동사구, 마침표 없음:** 작품 읽기, 설정집, 게시 준비, 백업 내려받기.
- **구분은 가운뎃점:** "소설 · 1개 장면", "제1부 · 남겨진 시간". 화살표(↗ →)는 글자로 쓰고 `aria-hidden`을 붙인다.
- 이중 피동(쓰여진)을 쓰지 않는다. 느낌표·이모지를 쓰지 않는다.

## 8. 집필실 목표 시안 (미구현)

캔버스의 집필실 시안을 코드로 옮길 때의 기준이다. 아직 구현하지 않았다.

- **틀:** 상단 헤더와 네이비 아이콘 바를 없앤다. 회색 바닥 위에 사이드바와 편집 창을 둥근 패널(모서리 10px, 사이 8px)로 띄운다.
- **사이드바(264px):** 위에서부터 ◌ Orbis Tertius, 작품 카드(표지·작품명·형식·장면 수·글자 수, 누르면 작품 전환), 검색·플롯보드·백업과 복구·가져오기 · 내보내기, 원고(부 폴더 → 장면, 상태 점), 설정집(인물·기술·장소 아이콘), 메모 · 리서치, 맨 아래 저장 상태와 테마 버튼.
- **편집 창:** 창마다 뒤로·앞으로·탭·새 탭·분할 버튼이 있는 44px 줄, 그 아래 40px 서식 도구(오른쪽 끝에 글자 수와 AI 검토). 원고 위 영역은 84px로 줄인다(현재 187px).
- **문서 정보:** 오른쪽 입력칸 패널 대신 제목 아래 칩으로 둔다: 상태, 시점 인물(인물 문서로 이어지는 칩), 작중 시간, 연결된 설정 수, 속성 추가. 제목은 원고 위에서 바로 고친다.
- **설정 링크:** 마우스를 올리면 분류·제목·설명·"옆에 열기"·등장 수가 있는 미리보기 카드를 띄운다(현재는 Ctrl+클릭).
- **플롯보드:** 진행 상태 열 대신 부·장 열을 기본으로 하고 진행 상태·작중 시간 보기를 전환한다. 카드에 인물·설정·작중 시간 칩과 글자 수를 둔다.
- **색:** 공개 페이지와 같은 역할 규칙. 라이트 바닥 #ebebf1·패널 #ffffff·사이드바 #f6f6f9·글자 #1d1c26·보조 글자 #67667a, 다크 바닥 #0f0f14·패널 #18181f·글자 #e9e8ef·보조 글자 #8e8d9c. 주요 버튼 Ultra Violet(다크 #a594dc), 링크·선택 Very Peri(다크 #a3a6ee).
- **글꼴:** UI는 IBM Plex Sans KR 13px, 원고는 Gowun Batang 18px / 2.

## 9. 카세트 퓨처리즘 테마

1970–80년대 녹음기·컴퓨터 콘솔 느낌의 두 번째 색 계열이다. 독자가 공개 페이지 헤더나 읽기 설정에서 고르며, 보라와 마찬가지로 라이트·다크가 있다. 라이트는 베이지 종이(#F5F5DC)에 오렌지(#E5632D), 다크는 콘솔 검정에 밝힌 오렌지다. 캔버스의 Cassette 아트보드 네 개(집필실·독서 × 라이트·다크)가 시안이다.

**주황은 면이 아니라 신호다.** 주황은 주요 버튼 하나, 줄무늬, 선택된 고르기 버튼, 분류 글자, 링크에만 쓴다. 본문·카드·패널 바탕을 주황으로 칠하지 않는다. 베이지 위 넓은 주황 면은 긴 글을 읽는 눈을 피로하게 하고, 주요 버튼과 줄무늬가 눈에 띄지 않게 만든다. 더 강조하고 싶으면 읽는 영역 밖(표지, 헤더 줄무늬, 선택 상태)에서 늘린다.

**카세트에서 달라지는 것** (`globals.css`의 카세트 줄, `public-info.module.css` 끝)

- 헤더 아래 1px 선 대신 3px 줄무늬 네 줄(사이 1px)을 깐다. 줄무늬는 헤더 아래와 표지 아래 6px 띠에만 쓴다.

- 보조 버튼(`.book-wiki`, 독서 막대 버튼)과 테마 버튼은 위쪽에 흰 줄이 있는 하드웨어 키 모양(`--pub-key`·`--pub-bevel`)이다. 주요 버튼과 선택된 고르기 버튼은 주황 키다.

**아직 집필실 시안에만 있는 것:** 카세트 라벨 모양의 작품 카드(SIDE A, 릴 두 개), 테이프 카운터 모양 글자 수(00418), 사각 LED 상태 점, LED 막대 진행 표시. 집필실 개편([8절](#8-집필실-목표-시안-미구현))과 함께 다룬다.

## 10. 새 기능 체크리스트

- [ ] 공개 페이지는 `public-site` 안에 있고 헤더에 `ThemeControls`가 있다.
- [ ] 색은 `--pub-*` 토큰만 썼고, 보라·카세트 × 라이트·다크 네 조합을 확인했다.
- [ ] 제목은 `--pub-title`, 분류 글자는 `--pub-kicker-font`, 조작·설명은 `--pub-sans`다. 색 계열 이름으로 분기하는 대신 모양 토큰을 썼다.
- [ ] 주요 버튼은 화면당 하나이고 보라 역할 규칙(2절)과 카세트 주황 규칙(9절)을 지켰다.
- [ ] 슬로건·영문 장식 제목이 없고 숫자에는 단위가 있다.
- [ ] 700px 이하와 360px 폭에서 가로 스크롤이 없다.
- [ ] 새 토큰·패턴을 만들었다면 이 문서와 [변경 기록](../CHANGELOG.md)을 갱신했다.
