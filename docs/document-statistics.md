# 문서 통계와 표시 설정

도구 모음의 숫자를 클릭하거나 키보드로 실행해 숫자 아래에 **문서 통계** 창을 연다. 바깥을 누르거나 Esc로 닫는다. 세부 집계 규칙은 창 아래 **집계 기준**을 펼쳐 본다. 공백 포함·제외 글자 수, 단어(어절), 문단, 200자 원고지 환산 중 하나를 도구 모음에 표시한다. 기본값은 **공백 포함**이다. 분할 편집도 각 창의 문서 숫자를 제공한다. Escape·닫기로 닫으면 원래 통계 버튼에 초점이 돌아온다.

본문을 드래그하거나 키보드로 선택하면 도구 모음은 선택 영역의 수치를 즉시 표시하고 ‘선택’이라고 구분한다. 선택을 해제하면 현재 문서 전체 수치로 돌아간다. 글자 수뿐 아니라 선택한 표시 기준(어절·문단·원고지)도 같은 규칙을 따른다. 분할 창은 각각 자신의 본문 선택을 사용한다.

상세 표는 현재 문서와 이 작품의 전체 원고를 비교한다. 본문을 선택하고 열면 선택 영역 열도 표시한다. 전체 원고는 종류가 `scene`인 문서만 합하며 설정집·메모·다른 작품은 제외한다. 폴더·대분류는 집계 종류를 바꾸지 않는다.

| 항목 | 기준 |
|---|---|
| 글자 수 · 공백 제외 | 본문의 공백·탭·줄바꿈 등 공백 문자를 제외. Unicode grapheme 단위로 이모지·결합 문자를 한 글자로 계산 |
| 글자 수 · 공백 포함 | 띄어쓰기·탭을 포함하고 줄바꿈은 제외. 문단 경계·화면 자동 줄바꿈은 글자를 늘리지 않음 |
| 단어 수 (어절) | 공백·줄바꿈으로 나눈 묶음 중 문자나 숫자가 있는 묶음. 문장부호만 있는 묶음은 제외. 형태소 분석은 아님 |
| 문단 수 | 내용이 있는 `paragraph`. 목록·인용 안의 문단 포함, 빈 문단·heading 제외 |
| 200자 원고지 환산 | 공백 포함 글자 수 ÷ 200을 올림. 작품 합계는 글자 수를 모두 더한 뒤 한 번 올림. 실제 조판 매수는 아님 |
| 각주 수 | 본문 각주 노드 개수. 각주 표시·각주 본문은 글자·단어 수에 넣지 않음 |

문서 제목 속성·요약·작중 시간 등 메타데이터는 집계에 넣지 않는다. 본문의 제목 서식 글자는 글자·단어 수에 포함된다. 코드·설정 링크의 실제 본문 글자도 포함된다. 노트 글자 수, 사이드바 작품 합계, 플롯보드 카드·합계와 게시 준비의 문서 글자 수는 공백 포함으로 표시한다. 도구 모음 기준을 직접 바꿔도 이 고정 표시는 유지한다. 모두 같은 Unicode 글자 집계를 사용한다.

보기 설정은 기존 `orbis-editor-preferences`의 `countMetric`에 글꼴·크기와 함께 저장한다. 같은 브라우저의 창·탭에서 반영되며 새로고침 후 유지한다. 계정 동기화·원고·공개판·ZIP에 넣지 않는다. 이전 공백 제외 저장값과 누락·손상된 기준은 공백 포함으로 전환하며 글꼴·크기는 보존한다. 어절·문단 등 다른 기존 선택은 유지한다. 이번 변경 후 직접 선택한 공백 제외는 `countMetricVersion: 1`과 함께 저장되어 새로고침 후에도 유지한다. 저장 공간이 차단되면 현재 페이지에서 선택을 유지하지만 재실행 후 보장은 없다.

[집계 코드](../src/lib/text-statistics.ts)는 변경되지 않은 본문 객체의 계산 결과를 WeakMap에 보관한다. 원고는 불변 객체 교체 규칙을 따르며, 상세 작품 합계는 창이 열린 동안만 계산한다. 선택 영역은 편집기의 문서 조각을 집계한다. 인터넷 요청·AI 호출은 없다.
