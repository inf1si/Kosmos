# 책으로 내보내기

**설정 → 저장 · 백업 → 책으로 내보내기**에서 PDF·EPUB·단일 HTML 파일을 만든다. 기존 **가져오기 · 내보내기 → 내보내기**에서도 같은 창을 연다. 파일을 만든 다음 **파일 저장** 링크를 누른다. 외부 서점에 업로드하거나 서재에 게시하는 기능은 아니다.

## 선택과 순서

작품을 고르면 본문이 있는 원고 문서를 기본 선택한다. **문서 N개**를 펼쳐 설정집·메모를 포함하거나 문서를 뺄 수 있다. **전체 / 원고만 / 선택 해제**도 여기 있다. 문서 순서는 집필실 문서 트리 순서다. 순서를 바꾸려면 트리에서 먼저 옮긴다. 제목 없는 문서는 본문에 제목을 인쇄하지 않고 목차에 순번만 표시한다.

파일에는 선택 문서의 제목·발행 섹션·본문·각주를 담는다. 각주는 문서 끝에 모으고 본문 번호와 왕복 연결한다. 비공개 `@` 참조는 제목·ID까지 제거한다. 기존 설정 링크는 표시 글자만 남긴다. 외부 웹 링크는 클릭 가능한 주소로 보존한다. 첨부 파일·독립 개인 노트·AI 대화·복구 이력·휴지통·기존 공개 판본은 넣지 않는다. 그 자료까지 옮길 때는 [전체 백업](backup-restore.md)을 쓴다.

책 제목은 작품명, 저자는 설정의 작성자 이름을 기본값으로 쓰며 이 창에서 바꿀 수 있다. 이메일은 쓰지 않는다. 원고 저장을 마친 시점의 사본으로 파일을 만들고 원본·공개 판본·기기 보기 설정은 바꾸지 않는다. 책 설정(형식·글꼴·용지·크기 등)은 작품별로 이 기기에 기억해 다음에 창을 열면 그대로 쓴다. 책 제목·저자·문서 선택은 기본값과 다를 때만 기억하고, 그 사이 지운 문서는 빠진다. 계정 동기화·백업에는 들어가지 않으며 최근 작품 50개까지 남긴다. 작품·문서·설정을 바꾸면 이전 미리보기와 파일 링크를 비운다.

## 형식

| 형식 | 배치와 파일 |
|---|---|
| PDF | 직접 생성한 `.pdf`. 한글 글꼴을 포함하며 텍스트 검색·선택, 외부 링크, 목차·각주 이동을 지원한다. 인쇄 창에서 PDF 저장을 요구하지 않는다. |
| HTML | 글꼴까지 포함한 `.html` 한 파일. 인터넷 없이 열 수 있다. PDF와 같은 쪽 배치를 SVG 텍스트로 표시하며 인쇄 시 지정 용지 크기를 쓴다. 기존 문서 교환용 HTML ZIP과 별개다. |
| EPUB | EPUB 3 `.epub`. 문서별 XHTML·목차·spine·글꼴을 넣는다. 글자 크기·용지·단수·쪽 번호는 독서기가 정하므로 PDF 설정을 강제하지 않는다. |

공통으로 마루부리/원티드 산스, 줄 간격, 왼쪽/양쪽 정렬, 제목 표지와 목차를 고른다. 표지는 제목·저자만 담은 표지다. PDF·HTML은 A5/신국판/A4, 세로/가로, 1단/2단, 글자 크기 8–20pt, 여백 10–30mm, 쪽 번호를 고른다. **가로 2단**은 한 쪽 안에 열 두 개다. 미리보기의 **한 쪽/두 쪽**은 화면에 펼칠 쪽 수만 바꾼다. 두 쪽은 제본한 책처럼 1쪽(표지)이 오른쪽에 혼자 오고 2–3, 4–5쪽이 펼쳐진다. 가로 용지의 두 쪽은 위아래로 쌓고 미리보기 칸 비율을 쪽 배치에 맞춘다.

PDF·HTML은 **미리보기**를 눌러 쪽 수와 실제 글 배치를 확인하고 화살표로 쪽을 넘긴다. 같은 조판 결과를 PDF·HTML 저장에 사용한다. 문서마다 새 쪽에서 시작하고 표지는 번호를 숨긴다. 문서의 **부 · 장** 칸은 앞 문서와 달라질 때만 장 위에 인쇄한다. 목차는 그 부 이름을 굵게 한 줄 넣고 아래 장을 들여 쓴다. EPUB 목차도 부 아래 장을 묶는다. 목차와 본문의 번호는 표지를 포함한 실제 파일 쪽 번호다. EPUB은 독서기에서 배치를 확인한다.

## 서식과 제한

문단·제목·굵게·기울임·밑줄·취소선·위/아래첨자·상대 글자 크기·목록·인용·구분선·병합 표를 변환한다. 큰 글자가 섞인 줄은 가장 큰 글자에 맞춰 기준선과 행 높이를 잡고 표 셀 안쪽 여백을 유지한다. 종이 출력의 강조와 표 제목 배경은 옅은 회색이며 앱 테마가 책 색을 바꾸지 않는다. 원고 보기 글꼴·폭을 그대로 복사하지 않고 책 설정으로 조판한다. PDF·HTML 목록 번호는 숫자/점으로 정규화하고 EPUB은 원래 목록 종류를 CSS로 남긴다. 코드의 글자는 보존하며 PDF·HTML에서 별도 고정폭 글꼴을 넣지 않는다. 쪽 아래 각주·머리말·사용자 꼬리말·이미지 표지·재단선·인쇄소용 PDF/X·접지/중철 배치는 지원하지 않는다.

문서 500개·본문 합계 200만 자·PDF/HTML 5,000쪽까지다. PDF·HTML 표는 행 단위로 넘기며 병합 구간은 같은 쪽에 둔다. 병합 구간이 한 쪽보다 크거나 셀 글자가 열보다 넓으면 생략하지 않고 오류를 표시한다. 용지/단수/글자 크기를 바꾸거나 EPUB으로 저장한다. EPUB에는 이 고정 쪽 제한을 적용하지 않는다.

마루부리·원티드 산스에 없는 한자·가나·전각 기호 등은 보조 글꼴로 채운다(마루부리는 Noto Serif KR, 원티드 산스는 Noto Sans KR). 보조 글꼴은 그런 글자가 있을 때만 내려받고, 책에 쓴 글자만 잘라 PDF·HTML에 넣는다(한자 몇 자면 수십 KB). EPUB은 원문 유니코드를 유지하므로 독서기 대체 글꼴에 따라 보인다. 보조 글꼴에도 없는 문자(이모지 등)가 있으면 PDF 생성을 막고 그 문자와 문서 이름(최대 3곳, 나머지는 "외 N곳")을 알려 준다. HTML·EPUB으로는 저장할 수 있다. 문단의 일부 수동 서식은 책 배치에 맞춰 간격·들여쓰기를 제한한다. 전문 출판 조판기를 대체하는 형식은 아니다.

## 글꼴·저장·개인정보

마루부리·원티드 산스의 npm 원본 WOFF2 보통/굵은 파일을 수정 없이 `/book-fonts/`에서 제공한다. 두 글꼴은 기존 감사 대상 OFL 1.1 글꼴이다. PDF를 만들 때만 원본 TTF 두 파일과 고지가 든 압축 묶음을 추가로 받는다. PDF는 두 원본 TTF를 전체 임베딩하고 HTML·EPUB은 WOFF2를 사용한다. 보조 글꼴 묶음(`maruburi-fallback.zip` 약 6MB, `wanted-fallback.zip` 약 4MB)은 @expo-google-fonts/noto-serif-kr·noto-sans-kr 0.4.4의 OFL 1.1 TTF에서 기본 글꼴에 없는 글자만 남긴 것이다. 글자 모양은 바꾸지 않았다. 책마다 쓴 글자만 남기는 일은 HarfBuzz 부분집합 WASM(harfbuzzjs 1.6.4, `harfbuzz-subset.wasm`)으로 브라우저에서 한다. pdf-lib 자체 부분집합은 이 글꼴의 글리프를 잃어 쓰지 않는다. 부분집합 변환에서 한글 복합 글리프가 손상되어 전체 임베딩을 선택했다. 이 때문에 PDF 글꼴 용량이 약 2MB(원티드 산스) 또는 4MB(마루부리) 추가된다. 저작권·예약 글꼴명·라이선스 전문인 [fonts.txt](../public/licenses/fonts.txt)를 PDF 첨부, HTML의 숨긴 텍스트, EPUB의 `licenses/fonts.txt`로 동봉한다. [감사 기록](font-license-audit-2026-10-23.md).

조판·변환·다운로드는 브라우저에서 수행한다. 원고를 새 출판 서버에 전송하지 않으며 외부 링크/이미지를 미리 내려받지 않는다. 파일 생성 전에 현재 기기의 대기 중인 저장을 마친다. 클라우드 동기화는 기존 저장 흐름을 따른다. DB/워크스페이스 스키마와 전체 백업 형식은 유지한다. 이 파일은 완전한 복원용 백업이 아니며 고정 배치 HTML을 다시 가져와 원래 문서 구조를 복원하는 왕복 계약도 없다.

고정 날짜로 압축하는 [패키징 스크립트](../scripts/package-book-fonts.mjs)로 원본 네 WOFF2, 두 PDF 글꼴 ZIP, 두 보조 글꼴 ZIP, HarfBuzz WASM을 재생성할 수 있다. 보조 글꼴은 npm 레지스트리 tarball의 sha512를 확인한 뒤 자른다. npm 원본과 글꼴 바이트가 같은지 검사한다.
