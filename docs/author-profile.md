# 자기소개

메인 화면 오른쪽 아래 **About Me**는 `/about`의 개인 소개로 이어진다. 페이지 제목과 브라우저 탭 제목은 **Who I Am**이다. 사이트 사용 안내와 별개로 작가가 직접 적은 이름·필명과 소개 글을 보여준다. 로그인 계정의 실명·이메일·사진을 자동으로 가져오지 않는다.

## 작성과 공개

1. 집필실 또는 노트 사이드바의 **설정 → 자기소개**를 연다.
2. **이름 · 필명**(선택, 최대 80자)과 **소개 · 마크다운**(최대 10,000자)를 적는다. 초안은 작업 공간에 자동 저장한다.
3. **자기소개 공개**를 누르면 현재 글만 공개한다. 빈 소개는 공개할 수 없다.
4. 나중에 고친 초안은 **공개 내용 갱신**을 누를 때 반영한다. **자기소개 페이지 보기**로 확인한다. 버튼 위 상태 줄은 초안이 공개 내용과 같은지와 공개 날짜를 함께 보여준다(예: "공개된 내용과 같습니다 · 2026. 10. 9. 공개").
5. **공개 취소**를 누르면 바로 내리지 않고 아래에 확인 상자를 연다. 상자의 **공개 취소**를 눌러야 공개 페이지에서 소개가 내려가며, 기본 초점은 **그대로 두기**다. 편집 초안은 남는다. 초안이 공개 내용과 다르면 지금 공개된 글은 되살릴 수 없다고 미리 알린다.

공개 소개가 없으면 등록되지 않았다는 안내만 보인다. 소개 글은 마크다운으로 표시한다. 굵게·기울임·취소선·링크(주소만 적어도 링크)·목록·인용·코드·구분선을 쓸 수 있고, 빈 줄은 문단, 한 줄 바꿈은 줄바꿈이다. HTML 태그는 실행하지 않고 글자 그대로 보이며, 이미지·제목(#)·표는 서식으로 바꾸지 않는다. `javascript:` 같은 위험한 주소는 링크가 되지 않고 링크에는 `rel="nofollow noopener noreferrer"`를 붙인다. 공개 전 모양은 공개 후 **자기소개 페이지 보기**로 확인한다. 처리 중 입력과 공개 버튼을 잠그며 실패는 창 안에 표시한다. 동기화 충돌 중에는 편집·공개·취소를 막는다.

## 저장과 권한

초안은 선택 필드 `Workspace.authorProfile = {name,bio}`로 기기 IndexedDB와 기존 계정 동기화에 포함한다. 전체 ZIP·Drive 작업본·복구 이력에도 들어간다. 해당 필드가 없는 이전 백업을 복원하면 현재 초안을 보존하고, 명시된 빈 객체 값 `{name:'',bio:''}`는 초안을 비운다. 작품별 내보내기에는 포함하지 않는다.

공개 내용은 `public.author_profile`의 별도 스냅샷이다. 사이트당 한 행(`id=true`)이고 최초 공개한 허용 작가만 수정·취소한다. 익명 방문자는 이름·소개·공개 시각만 읽으며 소유자 ID·작업 공간·초안은 읽지 못한다. 작업 공간 복원은 공개 스냅샷을 바꾸지 않는다. Drive/ZIP에는 공개 스냅샷이 없고 전체 DB 백업 범위에는 테이블이 포함된다. 공개 취소는 기존 백업 파일을 지우지 않는다.

앱 배포 전에 [마이그레이션](../supabase/migrations/20261009121112_author_profile.sql)을 적용한다. 새 환경 변수나 인증 제공자는 필요 없다. [설정](settings.md)·[저장](synchronization.md)·[백업](backup-restore.md)·[배포](setup-deployment.md).

## 검증

[Node 검사](../tests/author-profile.test.ts)는 스키마·ZIP 왕복과 실제 로컬 PostgreSQL의 익명 읽기/쓰기 금지·허용 작가 공개/갱신/취소·다른 계정 소유권 변경 금지를 확인한다. [브라우저 검사](../tests/browser/author-profile.mjs)는 합성 Auth/작업 공간과 실제 로컬 SQL 역할을 연결해 초안 자동 저장/새로고침·공개 실패/재시도·수정 후 갱신·취소·익명 읽기·텍스트 이스케이프·메인 링크와 여섯 테마/두 폭을 확인한다. 실행 환경 변수는 [개인 노트](personal-notes.md)의 브라우저 검사와 같다. 실제 운영 DB 적용/익명 권한과 앱 배포 증거는 [검증 기록](../VERIFICATION.md)으로 구분한다.
