# 원고 편집 도구

기준: 2026-10-04. 원고·설정집·메모와 분할 편집창에서 같은 도구를 쓴다. 상단은 기존 한 줄 도구 모음을 유지하며 작은 설정은 버튼 옆 팝오버에서 연다.

## 글꼴·크기

16가지 표시 글꼴: 고운바탕, 본명조, 나눔명조, IBM Plex 고딕, 본고딕, 나눔고딕, 함렛, 고운돋움, 고딕 A1, 나눔고딕코딩, 나눔손글씨 펜·붓, 바탕·맑은 고딕·굴림, 시스템 글꼴. 앞의 12가지 웹폰트는 Next Font가 빌드 때 내려받아 사이트에서 제공하며 preload하지 않는다. 기기 글꼴은 설치되어 있어야 하고 없으면 대체 글꼴을 쓴다.

크기는 **10~72px, 0.5px 단위**로 직접 입력하거나, 입력칸 옆 화살표(**글자 크기 목록**)를 눌러 일반 크기 16개 목록에서 고른다. 목록은 현재 크기로 스크롤되어 열린다. Enter 또는 다른 곳 클릭으로 입력을 마치고, 잘못된 값이나 Esc는 마지막 유효 크기로 되돌린다.

- **글자를 선택하지 않았을 때:** 원고 전체의 **본문 크기**(이 기기의 보기 설정)를 바꾼다. 좁은 화면·분할 창에서도 선택한 크기를 유지한다.
- **글자를 드래그해 선택했을 때:** 입력칸 이름이 **선택한 글자 크기**로 바뀌고, 고른 크기는 **선택한 부분에만** 적용된다. 선택 부분의 크기가 섞여 있으면 입력칸이 `–`로 비고, 목록의 **기본 크기로**는 선택 부분의 크기를 지운다. **문자 서식 지우기**도 크기를 지운다. 이 크기는 본문 서식이라 원고·동기화·백업·공개 장면에 저장된다. 독서 화면에서는 기준 18px에 대한 비율(예: 27px → 1.5배)로 독자의 글자 크기를 따라 커지고 작아진다.

다른 웹페이지에서 붙여넣은 글자의 크기는 가져오지 않는다. 이 편집기에서 지정한 크기만 복사·붙여넣기로 유지한다.

글꼴·본문 크기·통계 기준은 기존 orbis-editor-preferences에 저장하는 **이 브라우저의 보기 설정**이다. 계정 원고·백업·공개 판본·교환 파일에 넣지 않는다. 아래 문자·문단·표 서식은 본문 JSON에 저장하므로 기기 저장·계정 동기화·전체 백업과 공개 장면에 포함된다.

## 문자·문단

- **문단 스타일:** 본문, 제목 1·2·3. 문서 제목·부·장과 별개다.
- **문자 서식:** 취소선, 위첨자, 아래첨자, 강조 표시, 문자 서식 지우기. 위첨자와 아래첨자는 함께 켜지지 않는다. 서식 지우기는 각주·일반 링크·설정 링크를 보존한다.
- **문단 서식:** 왼쪽·가운데·오른쪽·양쪽 정렬, 들여쓰기·내어쓰기, 줄간격 1~3배, 첫 줄 0~4자 들여쓰기, 문단 앞·뒤 0~48px 간격, 문단 서식 초기화.

- **목록:** 도구 모음의 **목록** 버튼이 팝오버를 연다. 글머리 기호는 점(•)·빈 원(◦)·네모(▪), 번호는 숫자(1.)·가나다(가.)·ㄱㄴㄷ(ㄱ.)·소문자(a.)·대문자(A.)·로마자(i.) 중에서 고른다. 목록 밖에서 고르면 그 모양의 목록을 만들고, 목록 안에서 고르면 커서가 있는 목록(가장 안쪽)의 모양과 종류를 바꾼다. 현재 모양은 눌린 상태로 표시하고 **목록 해제**로 목록을 푼다. 기본 모양(점, 숫자)은 따로 저장하지 않으며 중첩된 글머리 목록은 점 → 빈 원 → 네모 순으로 바뀐다. 번호 목록은 이전에 문단 서식에 있던 버튼을 이 메뉴로 옮겼다.

문단 설정은 선택한 문단들에 적용한다. 전체 문단 들여쓰기는 한 단계 1.5em, 최대 8단계다. 목록 안에서는 들여쓰기·내어쓰기로 목록 수준을 바꾼다. 기본 줄간격은 2배이고 기본 첫 줄·문단 간격은 기존 편집기 스타일을 따른다. **문단 서식 초기화**는 정렬·간격·들여쓰기를 기본으로 돌리며 글자와 링크를 지우지 않는다.

## 각주 미리보기

원고의 각주 표시(*)에 마우스를 올리면 설정 링크 미리보기와 같은 카드가 표시 바로 아래에 뜬다. 카드에는 문서 안 순서대로 매긴 **각주 번호**(독자에게 보이는 번호와 같다)와 각주 내용 전체가 나오고, 긴 내용은 카드 안에서 스크롤한다. 포인터를 카드로 옮겨도 유지되며 벗어나면 잠시 뒤 닫힌다. 브라우저 기본 말풍선(title)은 카드와 겹치므로 쓰지 않는다.

## 표

**표 → 행·열 → 표 삽입**으로 만든다. 생성 시 1~20행·1~12열을 고르고 제목 행을 선택한다. 셀 안에 커서를 놓고 표 버튼을 다시 누르면 행·열을 앞뒤로 추가·삭제하고 셀 병합·분할, 제목 행 전환, 표 삭제를 실행한다. 여러 셀을 선택해야 병합할 수 있고 불가능한 동작은 비활성화한다. 셀 경계를 드래그해 열 너비를 조절한다. 실행 취소로 되돌릴 수 있다.

공개 장면에도 표가 표시된다. 넓은 표는 본문 안에서 가로로 스크롤한다. 셀 텍스트는 통계와 검색에 포함하며 셀 사이 어절은 이어 붙이지 않는다.

## 특수문자

문장 부호, SF·수학, 화살표·기호 **53개**를 골라 커서에 삽입한다. 따옴표·낫표·말줄임표·대시, 그리스 문자·∞·±·℃ 등을 제공한다. 문자 그대로 삽입하며 수식 계산·LaTeX 조판은 아니다.

## 찾기·바꾸기

**찾기와 바꾸기**, 편집기 안의 **Ctrl/⌘ F·H**로 연다. 입력하면 일치한 곳을 강조하고 개수를 표시한다. Enter·다음 결과로 앞으로, Shift+Enter·이전 결과로 뒤로 이동하며 끝에서 처음으로 돌아온다. **대소문자 구분**, **어절 일치**를 선택할 수 있다.

**바꾸기**는 선택된 검색 결과를 바꾼다. 아직 선택하지 않았다면 먼저 다음 결과로 이동한다. **모두 바꾸기**는 현재 문서의 일치를 한 번에 바꾸고 실행 취소 한 번으로 되돌린다. HTML 태그·달러 기호 등도 문자 그대로이며 HTML·정규식으로 실행하지 않는다.

서식 경계를 넘는 단어도 찾는다. 문단·셀·강제 줄바꿈·각주 노드 경계는 넘지 않으며 각주 설명은 검색 대상이 아니다. 어절 일치는 한글·영문·숫자·결합 문자·밑줄을 경계 기준으로 쓴다. 검색어 500자, 치환 입력 5,000자까지다. 팝오버를 닫으면 검색 강조를 지우고 원고에 초점을 돌린다.

도구 모음의 팝오버(글자 크기 목록·문자 서식·문단 서식·표·특수문자·목록·찾기·바꾸기)는 하나가 열린 상태에서 다른 버튼을 누르면 곧바로 그 팝오버로 바뀐다. Esc나 빈 곳을 눌러 닫으면 원고로 초점이 돌아가고, 다른 버튼·입력칸·원고를 눌러 닫으면 누른 곳에 초점이 남는다. 읽기 전용 상태에서는 치환할 수 없다. 작품 전체 치환·정규식·선택 범위만 치환은 제공하지 않는다.

## 보관·호환 경계

표·새 문자 서식·선택한 글자 크기·목록 모양·문단 간격은 [전체 백업](backup-restore.md)에 그대로 남는다. 공개판은 게시 시점의 사본이며 이후 초안 수정으로 바뀌지 않는다. Markdown은 표·별도 문단 서식·글자 크기가 있는 문단·모양을 고른 목록에 raw HTML을 섞고 HTML ZIP은 HTML 서식을 사용한다(크기는 `data-font-size`, 목록 모양은 `data-list-style`로 다시 가져온다). ENEX는 표·위/아래첨자·문단 서식과 강조, 글자 크기·목록 모양의 화면 표시를 전달하지만 Orbis Tertius로 다시 가져올 때 크기와 목록 모양은 기본값이 되며, 각주·설정 링크의 관계와 정확한 열 너비 메타데이터는 보존하지 않는다. [교환 상세](import-export.md). 실제 외부 앱 업로드 호환성은 별도 검증 대상이다.

DB 마이그레이션은 필요 없고 작업 공간 형식 1을 유지한다. 예전 원고도 기본값으로 열린다. 새 노드가 들어간 원고를 수정·복원할 때는 최신 집필실을 사용한다. 이전 앱은 새 노드의 가져오기를 거절할 수 있다. 기존 클라우드 버전 충돌 검사는 유지하며 동시 편집의 자동 병합은 추가하지 않았다.
